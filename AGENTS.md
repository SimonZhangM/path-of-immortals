# Path of Immortals

## 新线程启动必读（2026-09-18，置顶规则）

适用于在本项目内开始处理任务的每个新线程，也适用于上下文恢复后缺少项目状态的任务。不要依赖其他线程的记忆；在规划或修改项目之前，主动读取：

1. 本文件 `AGENTS.md`：当前协作约束；下方历史说明有冲突时按较新明确决定处理。
2. `PROJECT_PROGRESS.md`：先读顶部最新记录，再检索并阅读本次任务相关的历史记录，确认已完成、未完成、验证结果和下一步；不能只凭文件名或旧对话推断进度。
3. `docs/project-startup.md`：按文档索引读取本次任务所需的最新设计；原文、建议、确认版和已实现状态必须区分。
4. `README.md`：当前运行入口和操作方式，并核对相关代码／配置与 `git status --short`，保留已有本地修改。

第一次进度说明中简短说明已读到的当前状态和本次范围；真正读完后才可称“已读取”。所需文档缺失或输出截断时继续定位／分段读取，有影响任务的歧义才询问。每次任务结束追加进度记录；新增／替换最新设计时同步维护启动索引。默认不提交或同步Git。

此为项目级启动阅读流程，不是定时任务；不在没有用户任务时自行执行开发。将本节保持在历史记录之前，避免长文件截断隐藏启动规则。
