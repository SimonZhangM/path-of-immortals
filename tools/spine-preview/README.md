# Spine 特效预览室

本机素材浏览工具，按配置读取以下两个目录，不扫描整个 `E:\games\素材`。桌面浏览器每页同时播放九个特效，底部翻页；素材文件只读，不导入游戏、不生成转换副本。Node.js 标准库服务＋原生 HTML／JS＋单个 WebGL 画布，无需 npm 安装，安装好的工具运行时无需联网。

| 素材库 | 目录 | 当前数量 |
| --- | --- | --- |
| 原始 Spine 特效 | `E:\games\素材\spine特效` | 809 个特效、867 段动画 |
| 141套Spine高级特效 | `E:\games\素材\141套Spine高级特效` | 141 个特效、294 段动画 |

## 启动与关闭

双击项目根目录的 [启动特效预览.cmd](../../启动特效预览.cmd)。启动器会在后台启动本机服务，自动用默认浏览器打开 <http://127.0.0.1:8765>；重复启动会复用现有服务。电脑当前已有 Node.js，换电脑时需要 Node.js 18 或更新版。

关闭浏览器标签后服务仍保留。无需继续使用时，双击 [关闭特效预览.cmd](../../关闭特效预览.cmd)。下次使用重新双击启动即可。日志与进程号位于工具自己的 `.local/`，已排除出 Git。

也可在本目录执行 `node server.mjs`，然后打开上述网址；命令行方式用 Ctrl+C 停止。

## 操作

- 每页九个，底部上一页／下一页、数字页码、首末页和指定页跳转；桌面为 3×3，小屏自动两列。
- 左侧先选择素材库，再点击文件夹；目录计数和预览包含其子文件夹，箭头可展开下级目录。“查找文件夹”可快速定位目录；“全部素材”合并显示两个库。
- 顶部输入名称或子目录关键词筛选，多关键词以空格分隔；可单独查看 Spine 2.1、3.6 或 3.8。搜索与分页都限定在当前素材库／文件夹，切换范围回到第一页。
- 默认循环播放，顶部可暂停、重播、调速度（0.25／0.5／1／2倍）、背景和缩放。
- 每张卡下方可选该素材的动画；点预览区域或右上角放大，放大窗口也可暂停、重播、切动画、调速和缩放。
- “复制路径”复制该效果的 JSON 或 SKEL 完整路径，用于发给开发者或定位素材。
- 左右方向键翻页，空格暂停，`/` 聚焦搜索，Esc 关闭放大；在输入框或控件中操作时不抢键盘。
- 自动记住素材库、文件夹、筛选、页码、背景、速度和缩放。首次使用新版默认查看新增高级库；以后恢复上次位置。
- 在已配置目录中新增素材后按“重新扫描”，当前文件夹仍有效时会保留选中。缺图或不支持的版本在对应卡片显示错误，不影响其他卡片；某个库不可用时其他库仍可浏览。

修改 [config.json](config.json) 的 `libraries` 可增加／更换素材库，每项填写唯一 `id`、显示名称 `name` 和完整目录 `root`；ID仅使用英文字母、数字、短横线或下划线。`port` 可换端口，修改配置后关闭并重新启动。旧单目录 `root` 配置仍兼容，命令行 `SPINE_ROOT` 环境变量可临时覆盖为一个自定义库。

扫描递归查找带 skeleton／bones 的 JSON 及 `.skel` 二进制，配对同名 atlas 与图集页 PNG；不把拆分原图逐张当作特效。已验证原库的 Spine 2.1.x／3.6.53 JSON，以及新增库的 141 份 Spine 3.8.75 SKEL。不直接打开 `.spine` 编辑工程，不承诺其他导出版本或任意 3.8.75 文件兼容。

## 实现与检查

`server.mjs` 负责本机只读索引和素材传输，`public/runtime.js` 选择 2.1／3.6／3.8 时间轴运行时，处理二进制解析、路径约束和裁剪；`renderer.js` 负责区域、普通网格、加权网格与混合绘制，`app.js` 负责目录导航及筛选分页。动画全程采样估算固定取景范围；画面留边、避免随帧抖动，可再手动缩放。只保留当前页图像与纹理，翻页释放；浏览器隐藏时暂停画面推进。UI与原游戏场景、模拟、存档完全独立，`.gdignore` 防止 Godot 扫描此工具。

在本目录执行 `node check.mjs` 检查当前素材库：JSON／SKEL／图集页、动画解析、循环采样顶点和三角形、各库独立ID与HTTP读取、只读方法、本机Host及目录越界拒绝。`node check.mjs --library advanced141` 仅采样新增库，同时检查多库HTTP边界。

2026-10-22 验证：多库接入后 950 份素材、1161 段动画解析／采样通过；补充裁剪支持后针对新增 141 份／294 段再次采样通过。浏览器验证两个库切换、文件夹及后代隔离、范围内分页（新库16页、末页6项）、二进制动画切换与放大、裁剪样例、刷新／重新扫描保留目录、空搜索、3.8筛选及2560×1440九宫格，无页面错误。没有逐个人工观看全部动画，也未与 Spine 编辑器做逐帧像素对照；不涉及游戏回归。
