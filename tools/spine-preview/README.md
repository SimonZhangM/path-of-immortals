# Spine 特效预览室

本机素材浏览工具，默认读取 `E:\games\素材\spine特效`。桌面浏览器每页同时播放九个特效，底部翻页；素材文件只读，不导入游戏、不生成转换副本。Node.js 标准库服务＋原生 HTML／JS＋单个 WebGL 画布，无需 npm 安装，安装好的工具运行时无需联网。

## 启动与关闭

双击项目根目录的 [启动特效预览.cmd](../../启动特效预览.cmd)。启动器会在后台启动本机服务，自动用默认浏览器打开 <http://127.0.0.1:8765>；重复启动会复用现有服务。电脑当前已有 Node.js，换电脑时需要 Node.js 18 或更新版。

关闭浏览器标签后服务仍保留。无需继续使用时，双击 [关闭特效预览.cmd](../../关闭特效预览.cmd)。下次使用重新双击启动即可。日志与进程号位于工具自己的 `.local/`，已排除出 Git。

也可在本目录执行 `node server.mjs`，然后打开上述网址；命令行方式用 Ctrl+C 停止。

## 操作

- 每页九个，底部上一页／下一页、数字页码、首末页和指定页跳转；桌面为 3×3，小屏自动两列。
- 输入名称或子目录关键词筛选，多关键词以空格分隔；可单独查看 Spine 2.1 或 3.6。
- 默认循环播放，顶部可暂停、重播、调速度（0.25／0.5／1／2倍）、背景和缩放。
- 每张卡下方可选该素材的动画；点预览区域或右上角放大，放大窗口也可暂停、重播、切动画、调速和缩放。
- “复制路径”复制该效果的 JSON 完整路径，用于发给开发者或定位素材。
- 左右方向键翻页，空格暂停，`/` 聚焦搜索，Esc 关闭放大；在输入框或控件中操作时不抢键盘。
- 自动记住筛选、页码、背景、速度和缩放。新增素材后按“重新扫描”。缺图或不支持的版本在对应卡片显示错误，不影响其他卡片。

修改 [config.json](config.json) 的 `root` 可换素材目录，`port` 可换端口；修改后关闭并重新启动。扫描递归查找带 skeleton／bones 的 JSON，配对同名 atlas 与图集页 PNG。支持本素材库实际使用的 Spine 2.1.x／3.6.x JSON；不直接打开 `.spine` 编辑工程或 `.skel` 二进制，不承诺其他 Spine 版本兼容。

## 实现与检查

`server.mjs` 负责本机只读索引和素材传输，`public/runtime.js` 选择两个版本的时间轴运行时，`renderer.js` 负责区域、普通网格、加权网格与混合绘制，`app.js` 负责筛选分页。动画全程采样估算固定取景范围；画面留边、避免随帧抖动，可再手动缩放。只保留当前页图像与纹理，翻页释放；浏览器隐藏时暂停画面推进。UI与原游戏场景、模拟、存档完全独立，`.gdignore` 防止 Godot 扫描此工具。

执行 `node check.mjs` 检查当前素材库：所有 JSON／图集页、动画解析、循环采样顶点和三角形、HTTP 索引、只读方法、本机 Host 及目录越界拒绝。

2026-10-12 验证：809 份素材（795份2.1、14份3.6），867段动画解析／采样通过；浏览器检查了九格显示、暂停画面冻结与继续播放、首末页／尾页8项、搜索与空结果、版本筛选、加权网格放大、动画切换、设置持久化。没有逐个人工观看全部动画，也未与 Spine 编辑器做逐帧像素对照；不涉及游戏回归。
