## 运行

若当前是Godot项目管理器的项目列表，先点“编辑”进入项目编辑器，再按F5。地图主场景已配置好。查看新修改时先F8停止旧运行，保存后再F5。

**F5现在进入地图预览。** 使用原始gamemap-qingshihewan.webp背景，38个mapdot标记（含右侧道路末端）由41段带深色阴影的金色发光虚线连接。以图宽铺满屏宽为100%，初始125%，范围100%～175%，最小时左右无黑边。按住左键拖动地图，滚轮向上放大、向下缩小，围绕鼠标位置缩放。路线仅保留较窄单层阴影和金色光晕。已加入玩家移动：初始站在右侧道路末端，单击节点按最短路线前往；不含起点，1～2节点全程walk，3个及以上节点全程run，到站idle，三种动作均逐帧循环。途中改目标，到下一节点后改道；拖图不触发移动。怪物或遇敌切换尚未实现。微调请打开 `scenes/maps/qingshihewan_layout.tscn`，移动Points标记或编辑Routes曲线，保存后F5查看。详细步骤见[地图预览与微调指南](docs/map-editing-guide.md)。

**进入原有战斗：**打开 `scenes/main/main.tscn`，按F6运行当前场景。以下为保留的战斗界面和操作说明。

**地图对话：**从东侧起点点击大桥西端N37（过桥后的第一个节点），等待主角停稳，再次点击同一路径点。map-dialogue对话框中心在屏幕高度75%处（新版圆框底板按既有屏宽比例显示，头像填满圆框，1080p使用31px楷体），左侧为player-1-1头像。任意位置左键逐句查看5段文字，最后再点一次完成。之后前往中央小屋旁N20，停稳再点节点，先同时显示事件框和插画，下一次点击开始20段双人对话，头像按说话者切换。插画在放大三分之一的基础上再等比放大25%，以原底边中心为锚点向上扩展，保持与对话框的间距且不重叠。事件期间地图移动、拖动及缩放锁定；完成只隐藏对应路标与内部图案，路径点保留，本次运行不重复，F8→F5重启可重测。其余路标事件尚未配置。设计与数据入口见[地图节点互动](docs/map-interaction-design.md)。

储物袋现在完整遮住敌方信息，阵盘不再显示黄色矩形选框。从储物袋按下物品即显示阵盘实际大小的拖拽预览，包含CD圆圈和数量样式；进入阵盘后按物品中心提示最近占格，可放为绿色、冲突为红色，放置位置与提示一致。库存仅在成功放入时扣除。

底部主按钮战前显示“开始战斗”，大图标与文字整组居中。三处按钮点击采用轻缩后平滑恢复，已去掉亮度闪动和松开后二次缩放；音效保留。

状态条使用高度108px的半透明深灰横向底板，上下边缘明确，仅右端渐隐消失。随从技能仅保留各自圆框周围10px宽的阴影，内侧稍深、外缘淡出，没有成片底层。

进入战斗界面即自动循环播放assets/battle.mp3，战前整理、打开储物袋、战斗暂停和倍速都不影响音乐；整曲结束从头播放，离开界面或退出时停止。

1. 战前可直接整理我方阵盘。战前或战斗暂停时，点中列底部左侧“置换”，开关右侧共享储物袋；Esc关闭。运行中按钮禁用，不自动暂停。战斗暂停时仍需打开此面板才能整理，关闭面板不恢复战斗。
2. 所有物品放入辰宇的唯一阵盘；右键储物袋物品随机放入合法位置，或拖动到具体格位。同种丹药自动叠放。
3. 阵盘内拖动换位置保留全部进度；右键收回1件/1瓶，拖回收回全部未开瓶，已开瓶无法收回。拖拽图像居中跟随鼠标。配角没有阵盘。
4. 空格开始/暂停/恢复。开战或恢复自动关闭储物袋并锁定编辑；战斗进行时调整按钮置灰。
5. 右上依次为暂停、0.5x、正常播放、2倍图标；正常播放可开始/恢复并设为1倍，半速/2倍只设速度。F1/F2/F3仍对应0.5/1/2倍速。状态在居中计时下方；底部主按钮显示“战斗开始／战斗暂停／战斗继续”，暂停操作配icon-wait，开始/继续配icon-battle，继续时保留当前倍速。下排“置换／撤退”使用新图片，三处按钮均有按压回弹及合成点击声。日志数据保留，旧可见入口已替换。
6. 前后排阵型机制已取消，配角不能被攻击或作为物品放置目标。战斗结束后重新运行项目可开始新测试。
7. 战斗中点击“撤退”，准备3战斗秒，期间战斗照常继续。屏幕中央3s/2s/1s逐秒放大、模糊淡出；随倍速变化，暂停冻结。若提前或同刻分出胜负/平局，则取消撤退。成功后弹框提供“战斗复盘”（暂留入口）和“退出战斗”（当前关闭游戏，以后接地图）。

## 配角特质

每方最多两名配角，每名最多两个特质槽，主动/被动任意组合。配角无气血、体力、灵力，不受击、不耗资源，没有独立阵盘；本轮未开发招募或特质编辑界面。

| 配角 | 主动测试特质 | 被动测试特质 |
| --- | --- | --- |
| 角色2（炼气） | 回春诀：每6秒为主角恢复5气血，满值也轮转 | 护元：主角防御+1 |
| 角色3（筑基） | 离火诀：每4秒造成5普通法术伤害，不引发反击 | 培元：主角气血上限及初始气血+20 |

随从头像高为主角的2/3；随从1技能槽依序使用skill01.webp、skill02.webp，随从2使用skill03.webp、skill04.webp，通过icon_texture设置图标；主动技能下方仅显示黑底数字CD，被动不显示倒计时。物品仍用五行进度环。

特质由data/traits定义，角色JSON的traits数组引用稳定ID；相同特质在不同槽位独立计时。被动按来源重建，不重复叠加；等级本身不提供属性加成。五行属性在data/elements中配置，金黄、木绿、水蓝、火红橙、土黄，无属性白；本轮无克制。物品JSON可指定element，未指定默认为无属性。玄火剑/赤霄剑标火，青锋剑标金，其余现有物品无属性。

## 物品与CD

- 原装备：辰宇玄火剑1×2、铁甲2×2。新增库存：青锋剑、赤霄剑各1；玄铁甲、青鳞甲各1。
- 回春丹回复气血、蕴灵丹回复灵力、益气丹回复体力，各10瓶，1×1；每瓶2次，每次3秒内回复5对应资源，不超上限。
- 已开瓶完成第二次发动后消耗1瓶；已发动的回复继续完成。满资源不启用下一瓶。第一次实际生效才开瓶，首次轮转计时中仍可收回，开瓶后禁止收回。
- **入场冷却CD：**战斗中从储物袋放入后的3游戏秒等待，浅灰层显示3s/2s/1s。收回再放入总是重新计时；战前配置没有冷却。
- **轮转CD：**每次生效前计时，测试武器和丹药均3游戏秒；小圆环显示剩余秒数，颜色按五行属性，无属性白色；数量角标和圆环互不遮挡。阵盘内换格保留入场/轮转进度及防御；追加同种丹药不打断原有瓶，新瓶单独等待入场。
- 暂停冻结玩法计时，倍速只影响模拟时间。例：第1秒暂停装剑，恢复后第4秒入场冷却结束，第7秒首次攻击。
- 新剑与原剑均轮转3秒、10伤害、消耗5体力；爪子为3秒、5伤害、消耗5体力。铁甲防御1，玄铁甲基础2加进场2，青鳞甲防御3且受击反击1。

所有攻击指向对方主角，主角气血归零立即判负并停止所有事件。体力不足等待，丹药恢复后能继续。双方无可发动物品、无待结算回复和有效伤害特质时平局，只有治疗或被动不会无限空转。默认新配置在24秒胜利，辰宇剩余114/120气血。

## 防御、详情与阵盘

防御可叠加，普通伤害减防御后最低0。玄铁甲进场共提供4防御，卸下移除，反复装卸不累积；战中冷却期间不生效。青鳞甲在普通攻击后反击1，无视防御、不耗体力；零伤害也反击，致死不反击，反击不触发反击。冷却完成与攻击同刻时，先进场再攻击。配角法术伤害扣防御，但不触发装备反击。

储物袋每行5件，图片严格居于卡片中央，数量跟随图片右下角；竖排名称、靠右占格小图和圆角标签。悬停储物袋或阵盘物品可查看真实数值与轮转/进场/即刻效果。

物品实际轮转生效时同步淡白闪光和轻微放大/回缩，持续0.24展示秒，最后一瓶消耗也有反馈。气血/体力/灵力状态条改为圆润两端及斜向明暗层，颜色与居中数值保持。居中计时增加棕色框，60秒前显示12.34，之后显示01:12.34，两位小数，状态仍在下方。

辰宇阵盘使用bag-bg-1.webp，野狗使用bag-bg-2.webp；另外两种皮肤配置继续保留供未来内容使用，不再绘制旧格子底色/边框。data/boards/记录各背景的原图尺寸与格线坐标，图像、鼠标和占格共用映射，支持不同尺寸与边距。见[阵盘配置说明](docs/board-layout-authoring.md)。物品说明只保留自定义详情框，默认外层半透明底板已移除。

## 架构

JSON → ContentRegistry → SharedStorage / InventoryState / PartyMemberState / CompanionState → BattleSimulation / GameState → UI。

纯模拟以微秒事件堆处理攻击、插入冷却和持续回复。装备调整用版本号拒绝旧激活事件；每瓶以稳定ID与剩余次数保留状态。UI只读状态并发命令，速度不修改Engine.time_scale。GameState.teams每方只能有一个主角，companions每方最多两名。旧FormationRules脚本仅保留为历史辅助文件，不再被战斗代码调用。TeamPanel负责单阵盘和配角布局。

分类/品质/uses_per_unit及效果来自JSON；普通物品共用脚本。category预留weapon、armor、pill、item、talisman。现有JSON的cooldown字段对应轮转CD，不改名。

地图玩家最新参数：行走200、跑步360原图像素/秒，显示尺寸为最初的2倍。新版idle为4帧/3fps；run为7个源姿势，按4→5→6→7→6→5→4→3→2→1→2→3组成12步循环，16fps（每轮0.75秒）；walk为5个源姿势组成8步循环，8fps。walk/run均按独立区域切分不等距图片；鼠标平时为箭头，悬停节点为链接手形，仅拖图时为移动光标。支持各动作不同的素材分辨率，切换时保持脚底对齐。
