# 修仙之路 · Path of Immortals

Godot 4.7.2 / GDScript / Mobile Renderer。当前 **V0.7：物品流转与战斗反馈**。

接手先读 [项目开发进度](PROJECT_PROGRESS.md) 和 [工程规则](AGENTS.md)。新玩法有歧义先与用户确认，再修改。

## 运行

Godot打开project.godot，F5运行。1920×1080，最小1280×720。默认辰宇在右侧前排，角色2/3在左侧后排；野狗单人居中。

1. 战前可直接整理我方阵盘。战前或战斗暂停时，点中列底部“背包调整”，打开右侧共享储物袋；Esc关闭。战斗暂停时仍需打开此面板才能整理，关闭面板不恢复战斗。
2. 点击我方角色/阵盘选择目标；右键储物袋物品随机放入合法位置，或拖动到具体格位。同种丹药自动叠放。
3. 阵盘内拖动换位置保留全部进度；右键收回1件/1瓶，拖回收回全部未开瓶，已开瓶无法收回。拖拽图像居中跟随鼠标。主角大阵盘、队友小阵盘大小固定。
4. 空格开始/暂停/恢复。开战或恢复自动关闭储物袋并锁定编辑；战斗进行时调整按钮置灰。
5. F1/F2/F3对应0.5/1/2倍速。状态在居中计时下方；底部“战斗记录”查看隐藏日志。
6. 阵型规则保留供未来大地图设置，当前战斗界面没有切换或重新布阵按钮。战斗结束后重新运行项目可开始新测试。

## 物品与CD

- 原装备：每人玄火剑1×2、铁甲2×2。新增库存：青锋剑、赤霄剑各1；玄铁甲、青鳞甲各1。
- 回春丹回复气血、蕴灵丹回复灵力、益气丹回复体力，各10瓶，1×1；每瓶2次，每次3秒内回复5对应资源，不超上限。
- 已开瓶完成第二次发动后消耗1瓶；已发动的回复继续完成。满资源不启用下一瓶。第一次实际生效才开瓶，首次轮转计时中仍可收回，开瓶后禁止收回。
- **入场冷却CD：**战斗中从储物袋放入后的3游戏秒等待，浅灰层显示3s/2s/1s。收回再放入总是重新计时；战前配置没有冷却。
- **轮转CD：**每次生效前计时，测试武器和丹药均3游戏秒；半透明白色实线上移，无上方灰色蒙版。阵盘内换格保留入场/轮转进度及防御；追加同种丹药不打断原有瓶，新瓶单独等待入场。
- 暂停冻结玩法计时，倍速只影响模拟时间。例：第1秒暂停装剑，恢复后第4秒入场冷却结束，第7秒首次攻击。
- 新剑与原剑均轮转3秒、10伤害、消耗5体力；爪子为3秒、5伤害、消耗5体力。铁甲防御1，玄铁甲基础2加进场2，青鳞甲防御3且受击反击1。

前排存活目标优先，同排从上到下；阵亡停止攻击。体力不足等待，丹药恢复后能继续。敌方全灭胜利、我方全灭失败；双方均不能再发动且无待结算回复时平局。默认原装备战斗仍在12秒胜利。

## 防御、详情与阵盘

防御可叠加，普通伤害减防御后最低0。玄铁甲进场共提供4防御，卸下移除，反复装卸不累积；战中冷却期间不生效。青鳞甲在普通攻击后反击1，无视防御、不耗体力；零伤害也反击，致死不反击，反击不触发反击。冷却完成与攻击同刻时，先进场再攻击。默认原装备战斗结束辰宇88气血。

储物袋每行5件，图片严格居于卡片中央，数量跟随图片右下角；竖排名称、靠右占格小图和圆角标签。悬停储物袋或阵盘物品可查看真实数值与轮转/进场/即刻效果。

物品实际轮转生效时同步淡白闪光和轻微放大/回缩，持续0.24展示秒，最后一瓶消耗也有反馈。气血/体力/灵力状态条改为圆润两端及斜向明暗层，颜色与居中数值保持。居中计时增加棕色框，60秒前显示12.34，之后显示01:12.34，两位小数，状态仍在下方。

三个我方阵盘使用bag-bg-1/2/3.webp，野狗使用bag-bg-2.webp，不再绘制旧格子底色/边框。data/boards/记录各背景的原图尺寸与格线坐标，图像、鼠标和占格共用映射，支持不同尺寸与边距。见[阵盘配置说明](docs/board-layout-authoring.md)。物品说明只保留自定义详情框，默认外层半透明底板已移除。

## 架构

JSON → ContentRegistry → SharedStorage / InventoryState / PartyMemberState → BattleSimulation / GameState → UI。

纯模拟以微秒事件堆处理攻击、插入冷却和持续回复。装备调整用版本号拒绝旧激活事件；每瓶以稳定ID与剩余次数保留状态。UI只读状态并发命令，速度不修改Engine.time_scale。阵型和双方排版继续复用FormationRules / TeamPanel。

分类/品质/uses_per_unit及效果来自JSON；普通物品共用脚本。category预留weapon、armor、pill、item、talisman。现有JSON的cooldown字段对应轮转CD，不改名。
