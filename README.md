### 独立观察书术

打开`scenes/main/cultivation_preview.tscn`，选择GameManager节点，在检查器修改`preview_spell_id`与可选`preview_branch`，按F6运行。默认庚锋剑；例如`base.spell.metal_03`＋`返剑`观察剑幕，`base.spell.metal_07`＋`返锋`观察兵甲化元转伤。也可从终端启动：

```powershell
& 'E:\games\Godot_v4.7.2-stable_win64.exe' --path . res://scenes/main/cultivation_preview.tscn -- --preview-spell=base.spell.water_02 --preview-branch=裂冰
```

场景临时习得所选法术所需重数，放入法术、原书及青石短剑；点击开始后查看状态与战斗记录，悬浮法术查看当前分支。使用真实3×3阵盘和基础50／50／50，木桩及预备式触发条件为观察夹具；不读写玩家库存或学习存档，也不是正式获取／成长玩法。全部56术已在这一GameManager入口实际发动。

正式学习状态单独保存在原库存路径加`.cultivation.json`的文件；旧存档没有学习文件时正常载入，不自动赠送全部书术。学习／选书／模式完整界面后续，现有GameManager命令见第二批清单。

## 架构

JSON → ContentRegistry → SharedStorage / InventoryState / PartyMemberState / CompanionState → BattleSimulation / GameState → UI。
