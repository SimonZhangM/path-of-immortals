- **轮转CD：**按各物品定义，每次生效前计时；小圆环显示剩余秒数，颜色按五行属性，无属性白色；数量角标和圆环互不遮挡。阵盘内换格保留入场/轮转进度及护甲；追加同种丹药不打断原有瓶，新瓶单独等待入场。
- 暂停冻结玩法计时，倍速只影响模拟时间。例：第1秒暂停装剑，恢复后第4秒入场冷却结束，第7秒首次攻击。
- 野狗爪子为3秒、5伤害、消耗5体力。历史回归模式另保留旧剑3秒／10伤害／耗体5、铁甲防御1、玄铁甲基础2加进场2、青鳞甲防御3且受击反击1；这些固定防御数值不用于实际入口。

所有攻击指向对方主角，主角气血归零立即判负并停止所有事件。体力不足等待，丹药恢复后能继续。双方无可发动物品、无待结算回复和有效伤害特质时平局，只有治疗或被动不会无限空转。战斗结果取决于保存装备；主角基础气血50，现有随从培元仍额外提供20气血。

## 护甲、详情与阵盘

实际战斗没有固定减伤。初始护甲0、基础上限0，装备提供的上限叠加；攻击先扣当前护甲，溢出伤害再扣气血。轮转补甲不超上限，提高上限不凭空补甲，卸下防具会把当前护甲截断至新上限。上限与衣甲甲型在装备时生效；战中从储物袋新装入后，等3秒入场冷却，再开始完整轮转CD。主角状态组下方显示护甲当前值／上限及甲型。目前不加入甲型伤害倍率或雷盾。旧固定减伤通过tests/legacy_combat_fixture.gd隔离保存，仅用于历史回归。

储物袋每行5件，图片严格居于卡片中央，数量跟随图片右下角；竖排名称、靠右占格小图和圆角标签。悬停储物袋或阵盘物品可查看真实数值与轮转/进场/即刻效果。

物品实际轮转生效时同步淡白闪光和轻微放大/回缩，持续0.24展示秒，最后一瓶消耗也有反馈。气血/体力/灵力状态条改为圆润两端及斜向明暗层，颜色与居中数值保持。居中计时增加棕色框，60秒前显示12.34，之后显示01:12.34，两位小数，状态仍在下方。

张辰宇和野狗阵盘均使用zhenpan-bag.webp（3×3）；原4×4皮肤配置继续保留供历史内容使用，不再绘制旧格子底色/边框。data/boards/记录各背景的原图尺寸与格线坐标，图像、鼠标和占格共用映射，支持不同尺寸与边距。见[阵盘配置说明](docs/board-layout-authoring.md)。物品说明只保留自定义详情框，默认外层半透明底板已移除。

## 架构

JSON → ContentRegistry → SharedStorage / InventoryState / PartyMemberState / CompanionState → BattleSimulation / GameState → UI。

纯模拟以微秒事件堆处理攻击、插入冷却和持续回复。装备调整用版本号拒绝旧激活事件；每瓶以稳定ID与剩余次数保留状态。UI只读状态并发命令，速度不修改Engine.time_scale。GameState.teams每方只能有一个主角，companions每方最多两名。旧FormationRules脚本仅保留为历史辅助文件，不再被战斗代码调用。TeamPanel负责单阵盘和配角布局。

分类/品质/uses_per_unit及效果来自JSON；普通物品共用脚本。category预留weapon、armor、pill、item、talisman。现有JSON的cooldown字段对应轮转CD，不改名。

所有新增物品必须提供有效图片资源，并在Godot导入设置中开启mipmap；目录加载会拒绝未生成mipmap的物品图。物品主图统一使用线性mipmap过滤。

地图玩家最新参数：行走200、跑步360原图像素/秒，显示尺寸为最初的2倍。新版idle为4帧/3fps；run为7个源姿势，按4→5→6→7→6→5→4→3→2→1→2→3组成12步循环，16fps（每轮0.75秒）；walk为5个源姿势组成8步循环，8fps。walk/run均按独立区域切分不等距图片；鼠标平时为箭头，悬停节点为链接手形，仅拖图时为移动光标。支持各动作不同的素材分辨率，切换时保持脚底对齐。
