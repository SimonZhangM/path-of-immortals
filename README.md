5. 右上依次为暂停、0.5x、正常播放、2倍图标；正常播放可开始/恢复并设为1倍，半速/2倍只设速度。F1/F2/F3仍对应0.5/1/2倍速。状态在居中计时下方；底部“日志”查看隐藏记录。

## 配角特质

每方最多两名配角，每名最多两个特质槽，主动/被动任意组合。配角无气血、体力、灵力，不受击、不耗资源，没有独立阵盘；本轮未开发招募或特质编辑界面。

| 配角 | 主动测试特质 | 被动测试特质 |
| --- | --- | --- |
| 角色2（炼气） | 回春诀：每6秒为主角恢复5气血，满值也轮转 | 护元：主角防御+1 |
| 角色3（筑基） | 离火诀：每4秒造成5普通法术伤害，不引发反击 | 培元：主角气血上限及初始气血+20 |

随从头像高为主角的2/3；随从1技能槽依序使用skill01.webp、skill02.webp，随从2使用skill03.webp、skill04.webp，通过icon_texture设置图标；主动技能下方仅显示黑底数字CD，被动不显示倒计时。物品仍用五行进度环。

特质由data/traits定义，角色JSON的traits数组引用稳定ID；相同特质在不同槽位独立计时。被动按来源重建，不重复叠加；等级本身不提供属性加成。五行属性在data/elements中配置，金黄、木绿、水蓝、火红橙、土黄，无属性白；本轮无克制。物品JSON可指定element，未指定默认为无属性。玄火剑/赤霄剑标火，青锋剑标金，其余现有物品无属性。

## 物品与CD

- 原装备：辰宇玄火剑1×2、铁甲2×2。新增库存：青锋剑、赤霄剑各1；玄铁甲、青鳞甲各1。
- 回春丹回复气血、蕴灵丹回复灵力、益气丹回复体力，各10瓶，1×1；每瓶2次，每次3秒内回复5对应资源，不超上限。
- 已开瓶完成第二次发动后消耗1瓶；已发动的回复继续完成。满资源不启用下一瓶。第一次实际生效才开瓶，首次轮转计时中仍可收回，开瓶后禁止收回。
- **入场冷却CD：**战斗中从储物袋放入后的3游戏秒等待，浅灰层显示3s/2s/1s。收回再放入总是重新计时；战前配置没有冷却。
- **轮转CD：**每次生效前计时，测试武器和丹药均3游戏秒；小圆环显示剩余秒数，颜色按五行属性，无属性白色；数量角标和圆环互不遮挡。阵盘内换格保留入场/轮转进度及防御；追加同种丹药不打断原有瓶，新瓶单独等待入场。
- 暂停冻结玩法计时，倍速只影响模拟时间。例：第1秒暂停装剑，恢复后第4秒入场冷却结束，第7秒首次攻击。
- 新剑与原剑均轮转3秒、10伤害、消耗5体力；爪子为3秒、5伤害、消耗5体力。铁甲防御1，玄铁甲基础2加进场2，青鳞甲防御3且受击反击1。

所有攻击指向对方主角，主角气血归零立即判负并停止所有事件。体力不足等待，丹药恢复后能继续。双方无可发动物品、无待结算回复和有效伤害特质时平局，只有治疗或被动不会无限空转。默认新配置在24秒胜利，辰宇剩余114/120气血。

## 防御、详情与阵盘

防御可叠加，普通伤害减防御后最低0。玄铁甲进场共提供4防御，卸下移除，反复装卸不累积；战中冷却期间不生效。青鳞甲在普通攻击后反击1，无视防御、不耗体力；零伤害也反击，致死不反击，反击不触发反击。冷却完成与攻击同刻时，先进场再攻击。配角法术伤害扣防御，但不触发装备反击。

储物袋每行5件，图片严格居于卡片中央，数量跟随图片右下角；竖排名称、靠右占格小图和圆角标签。悬停储物袋或阵盘物品可查看真实数值与轮转/进场/即刻效果。

物品实际轮转生效时同步淡白闪光和轻微放大/回缩，持续0.24展示秒，最后一瓶消耗也有反馈。气血/体力/灵力状态条改为圆润两端及斜向明暗层，颜色与居中数值保持。居中计时增加棕色框，60秒前显示12.34，之后显示01:12.34，两位小数，状态仍在下方。

辰宇阵盘使用bag-bg-1.webp，野狗使用bag-bg-2.webp；另外两种皮肤配置继续保留供未来内容使用，不再绘制旧格子底色/边框。data/boards/记录各背景的原图尺寸与格线坐标，图像、鼠标和占格共用映射，支持不同尺寸与边距。见[阵盘配置说明](docs/board-layout-authoring.md)。物品说明只保留自定义详情框，默认外层半透明底板已移除。

## 架构

JSON → ContentRegistry → SharedStorage / InventoryState / PartyMemberState / CompanionState → BattleSimulation / GameState → UI。

纯模拟以微秒事件堆处理攻击、插入冷却和持续回复。装备调整用版本号拒绝旧激活事件；每瓶以稳定ID与剩余次数保留状态。UI只读状态并发命令，速度不修改Engine.time_scale。GameState.teams每方只能有一个主角，companions每方最多两名。旧FormationRules脚本仅保留为历史辅助文件，不再被战斗代码调用。TeamPanel负责单阵盘和配角布局。

分类/品质/uses_per_unit及效果来自JSON；普通物品共用脚本。category预留weapon、armor、pill、item、talisman。现有JSON的cooldown字段对应轮转CD，不改名。
