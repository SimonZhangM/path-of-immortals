## 物品与CD

实际物品参数来自08分类正文及`data/maps/inventory_items.json`。武器轮转消耗体／灵；1／2／3／4／5把武器所有原有耗体分别100%／125%／150%／175%／200%，以后每把增加25个百分点，零耗体不额外生费，灵力费不乘此倍率。两件攻击法器命中95%、五暗器90%，均无武器普通暴击。

## 架构

JSON → ContentRegistry → SharedStorage / InventoryState / PartyMemberState / CompanionState → BattleSimulation / GameState → UI。
