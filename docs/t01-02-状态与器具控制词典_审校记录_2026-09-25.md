## 已确认并直接落实

| 事项 | 本轮现行规则 |
| --- | --- |
| 反馈3.1 | **不采纳“Debuff按承受者容量”**。Debuff可施加上限按施加者计；自身Buff按自身容量。基础境界数值、各状态独立与来源资格不改。 |
| 蓄势 | 用户后续全局撤销蓄势。两词典保留旧编号与原文出处，但现行条目标为停用，不进入生成器候选。 |
| 扰乱 | 用户后续撤销打断蓄势／单件CD重开双分支；现为敌方全阵盘道具及法术CD倒数速度降低25%（0.75倍），持续8秒。 |
| 冻结 | 在途动作暂停而非废止；冻结前计数／进度保留，冻结期间事件不记录、不补记，解除不补播。 |
| 禁用 | 敌方全阵盘的道具类禁用3秒，可废止其进行中的动作；满3秒结束时受控道具完整CD重开。 |
| 沉默 | 敌方全阵盘的法术禁用3秒，可废止其进行中的动作；满3秒结束时受控法术完整CD重开。 |

已独立生成的状态、药效、护甲／盾等按自身生命周期处理；停止来源运行不等于撤销过去的一切结果。被禁用／沉默废止的动作不因解控自动复活，已扣灵力／体力不退；其他费用与预留读取t01-01 M08。扰乱只改变合格CD倒数速度，不打断动作或重置CD。
