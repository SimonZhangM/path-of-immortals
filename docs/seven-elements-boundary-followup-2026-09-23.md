## 1. 护盾分层与来源：当前处理项

### 已确认

1. 多层雷盾可以叠加；先求本次总吸收量，再按生成先后扣除各层，先生成的先扣。
2. 基础总吸收量＝min（各层剩余盾值合计，本次进入雷盾阶段的伤害×60%）。每层不重新对余伤乘60%；同一次攻击共用这一个吸收额度。
3. 每10层雷蕴消耗并生成一层雷盾，余层保留。用户例子“16层，生成雷印后扣10剩6”依此前造盾规则暂按“16层雷蕴→生成一层雷盾→剩6层雷蕴”理解；原文保留，不把雷印改成造盾资源。
4. **所有特殊护盾只能保留一种类型。**同类雷盾允许多层叠加；剑幕出现会替换全部雷盾，雷盾出现也会替换剑幕。重新生成剑幕直接替换旧剑幕。被替换的盾值直接作废；用户随后补充明确**雷盾被替换也要触发麻痹**，覆盖上一轮不触发麻痹的记录。剑幕被替换仍不据此触发返剑；雷盾被替换后相应内鸣等效贡献随之移除。普通灵障仍按已有防护规则处理，不因特殊盾换型而被定义为新增特殊盾层。
5. 法器修改吸收率时，必须明确作用的护盾名称，例如“灵障吸收率”“雷盾吸收率”或“剑幕吸收率”；不能默认一个修正作用于所有护盾。

### 结算例子

先生成雷盾A，剩50；后生成雷盾B，剩50。承受100点伤害，基础吸收率60%。本次总吸收为60：

| 步骤 | 结果 |
| --- | --- |
| 扣先生成的A | 扣50，A破裂，触发一次破盾麻痹 |
| 扣后生成的B | 扣剩余吸收额度10，B剩40 |
| 后续防御 | 其余40伤害进入护甲／气血阶段 |

雷盾全部耗尽后才允许灵障从下一次攻击接替，击破雷盾的本次攻击不再接续灵障。每个尚存雷盾仍按10层参与内鸣，每层被击破分别触发麻痹；同刻多次普通麻痹沿用刷新规则。

### 互斥范围已由用户澄清

用户明确选择：“所有特殊护盾只能保留一种：雷盾可叠层，但剑幕出现会替换全部雷盾，反之亦然。”

| 当前特殊护盾 | 新获得 | 处理 |
| --- | --- | --- |
| 一层或多层雷盾 | 新一层雷盾 | 增加一层，按生成先后承伤 |
| 一层或多层雷盾 | 剑幕 | 全部旧雷盾作废，只保留新剑幕；仍触发麻痹 |
| 剑幕 | 雷盾 | 旧剑幕作废，只保留新雷盾；不触发返剑 |
| 剑幕 | 新剑幕 | 旧剑幕作废，以新剑幕替换；不触发旧剑幕返剑 |

第1项最新补充：雷盾被替换触发麻痹已确定；多层同时被替换的麻痹事件次数及是否关联其他破盾监听，集中列在主清单第3.1节，不自行泛化为全部破盾效果同时触发。雷盾总容量与满容量时如何生成仍属未来容量设计；16→6说明产盾后余下雷蕴保留，不自动定义满容量时的消耗。最大攻击取值已由用户给出，不再要求重复确认；按主清单核对表继续剩余问题。
