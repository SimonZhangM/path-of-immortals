# 复盘物品悬浮说明｜610方形卡片

日期：2026-11-13。状态：已接入并按用户截图细化。尺寸为2K原生610×610，背景使用UI-battle-item-info。最新要求为套用原物品抬头的排版，在新容器内部独立构建，保持整圈边框；第三行描述删除。下方边框贴合素材内细线，两栏标题统一任务小菱形及金色左对齐，统计图标统一可见大小及垂直中心线。[战后阵盘统计](battle-replay-design.md)保留整体流程与归因边界。

## 已确认的核心点

1. 各类卡片保留右侧圆环，分别表示该物品对应的伤害、恢复、防护等贡献占比。
2. 分母采用同阵营本场同类总量，包含离阵、用尽物品及其他来源。
3. 第一圆环按固定主用途展示，不随本场数值最大项改变。2026-11-13最新追加：恢复类存在第二恢复资源时，第二圆环独立展示该资源；其他效果仍完整列在表格。此项覆盖此前所有混合物品仅单圆环的要求。

## 双恢复占比卡（2026-11-13最新）

右侧174px宽，按明细区可用高度均分上下两卡位，中间10px间距。当前常规抬头下两卡各174×198.5原生单位，精确等宽等高；底卡右边及底边与大容器内细线重合。单指标物品只画上卡，下方不画空框。删除“占我方伤害”等阵营底部文字，分母仍为同阵营完整同类总量。圆环统一128×128，在标题下方内容区水平／垂直居中；无数据／无效果的简短提示移入空环内，不增加卡片高度。

恢复类依静态效果、周期恢复、生机／润脉和实际恢复记录识别第二资源。第一指标沿原主用途；第二指标按气血→体力→灵力顺序取不同的恢复资源，最多显示两卡，更多项目仍列明细。现有调息玉显示气血／灵力，温玉佩、回元散、培元丹显示气血／体力。实际恢复为0时仍保留定义中的第二资源；每卡分别取对应资源的阵营总量，不混用主指标分母。

本轮统计专项130项、静态渲染103项0失败；覆盖不同分母、零恢复、四件双恢复物品、单卡留白、上下等宽等高、10px间距、底部贴线及128方形圆环居中。初版VBox产生198／199高度及0.5px中心误差，已改用anchors均分，最终通过。1080p／2K画面已目视；[调息玉2K样张](../artifacts/replay-dual-share-20261113/profile-fixture-recovery.png)、[温玉佩1080p样张](../artifacts/replay-dual-share-20261113/profile-fixture-recovery_stamina-1080.png)为固定数值排版夹具。日志位于artifacts/replay-dual-share-20261113，未跑鼠标交互或全量玩法回归，真实存档未改。

## 分类与固定排序

物品身份沿用武器、防具、法器、丹药、掷具、法术及敌方器官。统计模板按实际用途选择，例如法器分别进入输出、恢复或辅助模板，器官也按效果复用相应模板。

| 用途与现有例子 | 主数字／圆环分子 | 同阵营分母 | 明细顺序 |
| --- | --- | --- | --- |
| 输出武器、攻击法术、掷具、攻击器官，例如赤纹剑 | 归属本物品的总伤害 | 本阵营全部实际伤害 | 主指标 → 命中、暴击、未命中、免疫 → 发动／费用／触发 → 伤害构成及附带效果 → 状态明细 |
| 回血法器、丹药、治疗法术，例如回春玉、回春丹 | 实际恢复气血 | 本阵营全部实际气血恢复 | 主指标 → 其他资源恢复 → 发动／费用／触发 → 构成及状态明细 |
| 体力／灵力恢复，例如养息珠、聚灵珠 | 固定主资源实际恢复 | 本阵营同资源实际恢复 | 主指标 → 其他资源恢复 → 发动／费用／触发 → 构成及状态明细 |
| 衣甲、头盔及补甲物品 | 实际提供护甲 | 本阵营全部实际提供护甲 | 补甲 → 可量化减伤 → 其他效果。纯上限类按常驻效果展示 |
| 灵盾、雷盾、剑幕等护盾来源 | 实际护盾承伤 | 本阵营全部护盾承伤 | 实际生成盾量 → 各类盾承伤 → 替换失效盾量 → 破盾附带效果 |
| 增益辅助 | 成功施加增益次数 | 本阵营成功施加增益次数 | 按状态分别列施加次数 → 实际参与次数 → 可量化增伤／减伤 → 其他效果 |
| 减益、控制 | 成功施加减益次数 | 本阵营成功施加减益次数 | 按状态分别列施加次数 → 已生效控制 → 实际附带伤害 → 主动解除等其他效果 |
| 纯净化辅助 | 主动解除次数 | 本阵营主动解除次数 | 解除总次数 → 发动／费用／触发 → 被解除状态明细 |
| 多效果物品 | 由固定主用途配置指定 | 与指定主指标同口径 | 主用途明细在前，其余按伤害 → 恢复 → 护甲／护盾 → 增益 → 减益顺序 |

气血、体力、灵力分别计量。提供护甲、生成护盾、护盾承伤分别计量。量化增伤和减伤是辅助明细，其来源归属遵循现行统计规则。

丹药和掷具的“使用×次”沿用已确认的实际发动口径。当前离阵／用尽物品仍参与分母，其历史查看入口沿用现行后续范围。非战斗材料、任务物品和功法书沿现有物品说明展示。

样张由隔离测试阵盘进行真实模拟并渲染，使用赤焰刀两件同名实例展示独立统计。第一件伤害22.2、同阵营总伤害33.3，占比66.7%；切换另一件为33.3%。这些数值是测试场景结果，不是玩家存档或物品固定数值。

主指标只在表格首行突出一次。直接伤害等于总伤害时省去重复分项；状态明细已完整覆盖的状态伤害／非主施加汇总也不重复。多个状态各占一行，同一状态的伤害、恢复、施加与参与合并，长内容换行。御兵类参与武器的原图缩略图和名称放在明细末尾。恢复同时有直接和持续两部分时才拆分构成。

默认省去“每次发动均伤”。伤害、治疗和盾量保留1位有效小数，整数省去小数点，次数为整数。圆环保留1位小数，按未显示舍入的原值计算。

## 统计语义与零值

- 伤害采用实际气血、护甲及护盾损失之和，归属本物品的状态与额外攻击已包含在总伤害内。
- 气血及资源恢复采用实际恢复值。主指标为0时仍显示，次要无效零项省略。
- 同阵营总量大于0且本物品为0时圆环显示0.0%；微小非零占比显示“<0.1%”。同阵营总量为0时显示“—”及“本场无此类效果”。旧内存快照没有阵营总量时显示“占比数据未记录”，不推算分母。
- 纯上限、常驻属性等无发动且无累计的物品显示空环和“常驻效果”。发动次数为0仍保留；零恢复且有原因时显示资源已满、物品上限或恢复受抑制等实际原因。抵抗／免疫和解除由状态行或攻击行分别说明。
- 成功施加按每目标、每状态的一次成功新增／叠层／有效续时计一次。单次多层仍为一次，叠层兼续时去重。抵抗、免疫及主动解除进入明细，对成功施加计数贡献为0。
- 被动参与次数与物品转轮／发动次数分别展示。命中和暴击按直接攻击的实际目标、独立段次统计，持续伤害跳数及状态派生另列。首版简化展示次数，暴击率留待明确相同攻击样本口径后使用。
- 无法量化的辅助贡献在对应状态行显示“辅助量未量化”，仅附在确有此记录的项目上。
- 常规同类明细按固定规则排序，状态按配置中的稳定顺序，同名实例各自统计。

| attack_hits／attack_crits／attack_misses／attack_immune | 与旧混合计数并存，状态跳伤不混入攻击命中；未命中与免疫独立。旧命中数据不重新命名成攻击次数 |

| 固定主用途 | 复用BattleReplayFormat.profile，支持combat.replay_primary显式覆盖；默认按静态效果选择主指标，与本场数值无关 |

阵营总量每次真实结算只记一次，共同来源的数值按既有权重分配。成功施加等次数型指标需要沿原始动作／目标／状态键去重，并让物品分子与阵营分母采用相同计次单位。未知归属不分配给可见物品。
