# V0.2 战前背包与对阵界面

用户本轮已授权：参考附图的左右对阵结构，玩家 4×4 背包，玄火剑固定垂直 1×2，新增铁甲 2×2，两件装备可移动；先布阵再开战，战斗中空格暂停/恢复，F1/F2/F3 对应 0.5/1/2×，默认 1×；参考分辨率 2560×1440。

实施决定：

- 新增独立 `InventoryState`，保存稳定实例 ID、内容 ID 和左上角格坐标。尺寸来自 JSON，不把布局保存在 UI 节点中。放置检查边界与矩形重叠，失败不修改原位置；不旋转、不堆叠、不交换，也不丢弃到背包外。
- 游戏状态增加 PREPARATION / BATTLE / FINISHED。布阵期间时钟不推进，开始后锁定背包，暂停时仍锁定；再次布阵保留布局，恢复生命、时间与默认速度。结束时冻结在击破时刻。
- UI 仅提供原生拖放预览和命令转发。拖动保留鼠标抓取的格偏移，目标合法绿色、非法红色；增加点击选中后点击目标格的等价操作。
- 铁甲目前只实现装备占格与移动，未指定的防御数值、敌方攻击和双方伤害暂不扩展。数据允许无主动效果的被动装备，冷却为 0、effects 为空，绝不把它排入攻击队列。
- 战斗仍由原玄火剑驱动。仅一个主动攻击实例，无需提前实现多武器战斗系统。
- 原生 Godot 布局参考截图的玩家左侧、敌方右侧、中央计时和开战按钮。使用简洁的自制矢量占位图与山形背景，不复制参考游戏素材。窗口与设计分辨率均为 2560×1440，允许缩放。
- 输入映射统一放在项目 InputMap，处理按下且非重复事件；按钮不获取键盘焦点，避免空格同时触发按钮。若正在拖动，暂停操作不把拖放变成布局写入。

验收包括尺寸数据校验、4×4 放置边界/重叠/自重叠、非法落点回退、拖动第二格的偏移、战斗及暂停期间禁改布局、布局不走时、开战/重开、键盘输入与速度精度，以及 2K 实际渲染与较小窗口布局。
