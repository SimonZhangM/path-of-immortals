# 主角物品画风与占格绘图规范

2026-11-05。适用于[物品汇总](../output/imagegen/物品汇总/README.md)中的主角各类物品图片及后续新绘、修订。

## 用户确认

- 所有物品采用同一套画质与美术风格。
- 武器、防具具有明确占格，图片形态根据占用格数设计。

占格沿项目既定的**列×行**约定。制作时同时明确列数、行数、总格数及朝向。以下画风描述来自现用原图观察，作为后续执行口径。

## 共同画风

整体为精细手绘的仙侠游戏物品插画，结合概括、利落的造型与较写实的材质光影。以清晰外轮廓、明确大色块和可读的结构组织细节，缩小后仍能辨认物品种类。

| 方面 | 现图特征与后续绘制口径 |
| --- | --- |
| 主体与构图 | 独立、完整的物品主体，透明背景，主体周围留适量透明余量。按物品定义表现单件或成组物件，轮廓与附件清楚可辨 |
| 体积与视角 | 使用能交代厚度和结构的轻度透视。金属刃面、甲片折面、书脊与书页、瓶口、护臂内腔均有明确体积；衣甲偏正面略侧，书本略倾斜，细长武器按占格安排主轴 |
| 线条与边缘 | 外轮廓及结构缝隙有清楚的深色收边，细线和内部明暗共同界定形体。外沿保持平滑，装饰有完整边界 |
| 光影 | 主亮面、高光、暗面关系明确。金属以窄而亮的刃口／棱边高光显硬度，布与皮革过渡更柔和，玉石采用润泽高光与内部层次 |
| 材质 | 铁有灰银色面与轻微磨痕，铜金有暖色包边；木有顺纹与结节；皮有缝线、绑带及磨损；布有褶皱和织物层次；玉石有通透纹理；纸书有页层和封面厚度 |
| 色彩 | 主材质色承担大面积，元素色集中于纹样、染色、嵌饰或有依据的微光。水纹偏青蓝，雷纹偏紫蓝，火纹偏朱红橙，木纹偏青绿，各类图沿共同的明暗与精细程度 |
| 仙侠装饰 | 云纹、回纹、流苏、绳结、铜扣、玉珠与刻纹是现有常见语言。装饰服务于物品身份、结构和已定属性，保持主体轮廓清楚 |
| 品级表达 | 下品多用朴素材料与简洁结构，凡品可增加元素纹样和装饰。各品级共享绘制完成度，普通物品同样具有清晰材质和边缘 |

书籍的题签使用准确书名。阵盘的格线属于底图自身结构，另遵循[阵盘格线标定说明](board-layout-authoring.md)。物品卡框、品质底板与占格提示由现有界面组合，制作物品主体时以独立透明素材交付。

## 占格决定武器、防具的形态

先从物品定义取得`footprint_columns`与`footprint_rows`，再确定主轴方向、长宽感、姿态、构件展开方式及留白。两格物品也有横排与竖排之分，绘图任务需写完整的列×行。

| 当前占格 | 构图与形态 | 已有武器参考 | 已有防具参考 | 当前数量 |
| --- | --- | --- | --- | --- |
| 1×1 | 适配单格的紧凑构图。刀匕可沿对角线展开，印类集中成块，头具、护臂、护腿等表现为独立部件，附件适度收束 | 铁刀、匕首、石印 | 旧铁盔、木圆盾、布护臂、水纹护腿 | 武器12、防具26 |
| 1×2 | 以纵向为主，拉开上下结构，横向轮廓收束。保持剑／弓／锤的器型，衣甲和长盾完整纵向展开 | 青石短剑、猎弓、短柄铁锤 | 粗布甲、铁甲、水纹衣、包铁木盾 | 武器12、防具10 |
| 2×1 | 以横向为主，头部与柄部沿左右展开，整体具有横向宽度 | 柴斧、开山斧、金刚斧、厚土斧 | 当前目录暂无 | 武器4 |
| 3×1 | 长轴沿横向延伸。枪保留细长枪杆与完整枪尖，鞭以自然弯曲呈现长度，附件融入横向整体轮廓 | 长枪、青木枪、赤焰枪、皮鞭、藤鞭 | 当前目录暂无 | 武器8 |

当前统计为36件武器、36件防具。具体条目以[武器表](../output/imagegen/物品汇总/武器/README.md)和[防具表](../output/imagegen/物品汇总/防具/README.md)的逐项占格为准。木圆盾采用最新1×1配置。

占格提供可用空间与构图方向，物品保持自身自然比例。例如3×1长枪的枪杆仍很纤细，护臂在1×1内仍可呈斜向长条。使用自然造型、视角和姿态适配格区，完整呈现物品轮廓。

源图画布可包含适量透明边缘，具体输出分辨率随制作任务确定。核对时同时观察透明画布、可见主体的长宽和实际格区中的效果。

## 原图与界面朝向

武器、防具原图以阵盘占格方向作为构图依据。当前阵盘内普通物品使用等比适配，并按可见主体居中。

储物袋卡片与悬浮说明会把非1×1的横向武器旋转为竖向展示，1×1保留原图方向。因此查占格与制作朝向时，应对照原始图片和运行配置；卡片中的竖放效果由显示层完成。现行取景与采样规则见[储物袋设计](map-inventory-design.md)，实现入口为[MapItemArtwork](../scripts/map/map_item_artwork.gd)。

## 后续绘图任务写法

每件武器、防具的制作记录同时包含物品名、稳定ID、品级、材质、已有属性、占格、原图朝向、形态要求、实际参考图和版本状态。优先选同类同占格参考，再补一张需要匹配材质的参考。

```text
用途　苍澜界主角物品图，用于储物袋与阵盘
物品　名称、稳定ID、类别、品级
占格　C列×R行，共N格
形态　与占格相应的主轴、长宽感、姿态和构件展开方式
材质　主体材料、连接结构、已定元素纹样
参考图1　同类同占格参考，匹配器型与构图
参考图2　材质和画风参考
画风　精细手绘仙侠物品插画，清楚轮廓，明确体积，细腻且可读的材质
构图　完整主体，周围适量透明余量，附件随整体轮廓组织
文字　需要时填写准确书名或既定文字
输出　透明PNG，使用物品名与版本号归档
```

完成后核对物品身份、统一画风、占格朝向、完整轮廓、可见主体比例、透明通道及小尺寸辨识度，再记录生成稿／确认稿／现用图状态。制作记录与文件归档沿[物品汇总约定](../output/imagegen/物品汇总/README.md)。
