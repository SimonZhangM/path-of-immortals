# 金系整体设计方案

## 一、金系核心定位

金系的核心不是单纯“攻击高”，而是：

> **兵锋、御器、反击、伤痕、肉身创伤、武器兑现。**

它天然和**兵器、物理攻击、御剑、装备联动**关系最深。

金系既能作为纯属性法修，也特别适合：

> 金系法术 + 高质量武器 + 阵盘器具

的混合Build。

目前属性克制按最新2克2方案：

> **金克：木、风**
> **金被：火、雷克**

另外具有种族针对：

> **金对器灵具有额外针对优势。**

---

# 二、金系三种核心状态

| 类型       | 名称     | 核心作用                                      |
| -------- | ------ | ----------------------------------------- |
| Buff     | **反锋** | 积累反弹伤害，受到真正打入护甲/生命层的物理伤害时，一次性反弹全部积累的金属性伤害 |
| Debuff ① | **锋痕** | 积累伤害加深，下一次受到物理/武器攻击时追加对应金属性伤害并清空          |
| Debuff ② | **流血** | 伤及气血后形成持续创伤，每层每秒损失1点气血，持续5秒，重复施加刷新持续时间    |

### 反锋

每层：

> +1待反弹伤害。

只有：

> 物理攻击真正穿过护盾并进入护甲/生命结算

才触发。

哪怕这次只受到：

> 1点物理伤害，

也会完整释放当前所有反锋。

反锋产生的是：

> 金属性派生伤害。

默认不能继续递归触发新的反锋、锋痕等机制。

---

### 锋痕

每层：

> +1待追加金属性伤害。

下一次：

> 真正的物理/武器攻击

命中时兑现。

武器型法术虽然可以带斩击、穿刺等标签，但默认仍属于：

> 法术攻击来源，

所以不触发锋痕。

除非明确标记：

> **视作武器攻击。**

---

### 流血

主要代表：

> 兵刃真正伤及肉身以后留下的持续创伤。

因此特别适合：

* 剑；
* 刀；
* 暗器；
* 穿透护盾/护甲直接伤气血的特殊攻击。

金系后期可以自然发展：

> 锋痕负责“下一击”；
> 流血负责“后续持续”；
> 反锋负责“挨打还击”。

三个方向互不重复。

---

# 三、金系属性共鸣

主动金属性攻击发出前：

> 读取攻击者自己的金系Buff层数
> +目标身上的全部金系Debuff层数。

也就是：

> 反锋 + 锋痕 + 流血

共同进入金属性共鸣读取。

例如：

> 自己反锋4层
> 敌人锋痕6层
> 敌人流血5层

理论有效层数：

> 15层。

若未超过当前境界的属性读取上限：

> 金属性主动伤害 +15%。

快照发生在：

> **攻击发出前。**

即使攻击之后被闪避：

> 本次伤害快照也已经完成。

但反锋、锋痕、流血本身产生的派生伤害：

> 不再次读取属性共鸣。

---

# 四、金系装备设计语言

## 武器

金系武器重点适合：

> 斩击、兵器强化、锋痕、流血、状态兑现、物理爆发、御兵联动。

其中：

> **剑明确属于斩击型武器。**

以后金系剑类法术如果属于“武器型法术伤害”，原则上也采用：

> **法术来源 + 斩击型 + 金属性**

除非某一招明确属于剑尖贯刺之类的特殊攻击。

金系武器很适合设计：

* 造成锋痕；
* 伤及气血后造成流血；
* 利用已有锋痕提高攻击；
* 消耗某些状态换爆发；
* 成为剑阵组件；
* 被御兵类法术调用。

---

## 防具

金系防具可以重点偏：

> 物理承伤 → 反锋 → 防守反击。

例如：

* 真正受到物理伤害时获得反锋；
* 护甲被攻击以后强化下一次反击；
* 与武器联动；
* 保护高攻击兵修；
* 把防御资源重新转为兵器攻击。

不要求所有金甲都这么做，但这是金系最自然的防具语言。

---

## 法器

金系法器可以重点发展：

* 武器监听；
* 多武器构筑；
* 锋痕/流血生产；
* 武器领域强化；
* 御兵；
* 剑阵；
* 武器CD操作；
* 调用阵盘武器发动攻击。

所以金系非常适合：

> **“一堆兵器围绕一个核心法器运行”**

这种阵盘体系。

**【群兵】**

> 提高其他每一件武器的贡献。

适合：

> 多武器阵盘。

---

# 十一、金系法术总表

最终金系8个可独立上阵法术：

| 功法      | 法术        |
| ------- | --------- |
| 《玄庚剑诀》  | **庚锋剑**   |
|         | **分光剑雨**  |
|         | **回锋剑幕**  |
|         | **玄庚归一剑** |
| 《百兵御灵诀》 | **附灵术**   |
|         | **御兵术**   |
|         | **兵甲化元**  |
|         | **百兵归元**  |

它们学会以后：

> 可以独立放入阵盘。

不要求：

> 原功法同时上阵。

---

# 十二、金系阵法延伸

金系天然适合一个非常有代表性的阵式：

## 【大庚剑阵】

阵法知识可通过阵法系统获得。

实际战斗需要：

> 一个【大庚剑阵阵眼】。

阵眼在阵盘中的布局要求：

> 上、下、左、右四个相邻阵位各放置一把剑。

剑属性：

> 不限。

但剑本体属于：

> 斩击类武器。

满足条件以后：

> 大庚剑阵才能正常运行并发动大型剑阵攻击。

因此它和《玄庚剑诀》《百兵御灵诀》都有很好的组合潜力，但又不是任何一本金系功法的附属技能。

---

# 十三、金系可以形成的主要Build

最终金系至少自然形成这些方向：

**御剑流**

> 《玄庚剑诀》+金系法术。

**百兵流**

> 《百兵御灵诀》+大量高品质武器。

**锋痕流**

> 先铺锋痕，再靠物理武器兑现。

**流血流**

> 不断真正伤及气血，维持持续肉身创伤。

**反锋流**

> 防具、法器与《金煞藏锋经》结合，靠挨打形成反击。

**大庚剑阵流**

> 多剑+阵眼+御兵/剑系法术形成大型阵式。

**无属性兵修混金**

> 使用高质量无属性武器，由金系御兵法术和炼器体系强化其物理表现。

所以金系最终不会只是：

> “剑修属性”。

它真正的完整身份是：

> **以兵器为核心，能够铸器、御剑、御兵、藏锋、留痕、见血，并通过阵盘把多件兵器组织成完整战斗体系的属性。**

我觉得这套已经可以作为金系当前的**正式第一版设计基线**。后面做另外六系时，不需要机械模仿金系，但最好都达到同样程度：五本功法之间职责清晰、8个法术彼此不重复，并且能和该属性的Buff、双Debuff、武器、防具、法器真正连成一个生态。
