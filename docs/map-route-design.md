# 青石河湾：第一步地图走线（2026-09-14）

2026-09-15后续已获授权接入玩家点击移动及逐帧动画，规则与架构见[地图玩家设计](map-player-design.md)。下文“不实现移动”仅描述最初走线阶段；仍不接遇敌、怪物或存档。

2026-09-15：百分比基准改为地图宽度铺满视口宽度=100%，范围100%～175%，初始125%。滚轮向上放大、向下缩小，鼠标锚点和平移限位保持，最小比例左右无黑边。按宽度缩放时上下可能裁切或留边，仍保持等比；不以高度缩放而在左右留边。去掉最宽的外层深色阴影笔画，保留内层阴影和金色光晕。下文旧范围、方向与整图适配描述为历史。

最新微调：路线阴影Alpha由0.60减至0.42；EastExit从隐藏Marker2D改为显示mapdot的MapRoutePoint，保留原位置、稳定ID与路线连接，现在共38个可见标记。下文37个可见点/隐藏端点为历史。F5入口仍为地图预览，在Godot项目编辑器中使用；项目管理器需要先点“编辑”进入编辑器。

2026-09-14浏览调整：初始以完整适配比例的125%显示，mapdot布局Scale从0.28缩为0.224（80%），在初始视图中保持原有屏幕尺寸。MapScreen仅管理视图平移和缩放：按住左键拖动，滚轮向下放大、向上缩小，以鼠标位置为缩放中心；暂设100%～250%、每格倍率1.1。限制平移到地图边缘，小于视口的轴保持居中，窗口改变时保留中心观察位置。浏览状态不修改布局源坐标，不进入战斗或移动模拟。路线增加可编辑的深色阴影提高土路对比度。以下完整适配描述为上一版初始视图，缩至100%时仍适用。

本轮按用户标注实现可编辑的地图背景、节点与金色发光虚线路径。背景直接使用gamemap-qingshihewan.webp，不改源图；红勾位置使用mapdot.webp。保留现有战斗原型，暂不实现角色移动、遇敌、寻路、保存或地图与战斗状态衔接。

地图原图为3220×1830，标注参考为1610×915，走线坐标按2倍映射。地图元信息放在data/maps/qingshihewan.json；美术位置与曲线保存在独立Godot场景，供2D编辑器直接修改。点与路径有稳定命名ID；路径显式关联两端节点，避免仅靠线条交叉推断连接。无圆圈的最右侧路线末端仅作隐藏端点，不额外添加mapdot。

地图展示使用独立场景作为F5入口，完整等比适配1080p视口。原scenes/main/main.tscn战斗场景不改，可以F6直接运行；这不是新的遇敌流程。节点为可拖动Node2D，路线为可在Godot中编辑Curve2D的Path2D，通过轻量@tool脚本预览发光虚线并跟随端点。只有几何/视觉编辑逻辑在编辑器更新，没有战斗或玩法时钟参与。

运行时使用场景内的布局快照；用户在编辑器修改后Ctrl+S即可保留。后续获准做移动时，再将节点ID、路径连接及曲线转为移动系统的输入，不在本轮擅自确定移动速度、遭遇规则或怪物配置。
