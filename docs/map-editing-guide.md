# 青石河湾地图预览与微调

2026-09-15：地图使用原始背景图、38个可见标记（含右侧道路末端）和41段金色发光虚线，已加入玩家点击寻路与idle/walk/run动画。怪物及遇敌切换尚未接入。

## 怎么查看

地图顶部状态栏始终可见，固定于屏幕，与地图平移/缩放分离；MapContent位于MapViewport裁切区，紧贴顶部栏横向金线（1080p约91px），线下无额外深色填充，head3源图装饰自然延伸；事件及对话期间也保留。显示主角头像、姓名张辰宇、炼气 · 一层、年龄15岁、寿元80年、气血／体力／灵力，修为暂为测试0/100。配置入口data/maps/status_header.json，基础属性取ContentRegistry中的角色数据。当前地图状态独立于F6战斗，不自动消耗、增长或升级。布局入口scripts/map/map_status_header.gd：1920基准下head3宽562.68、位置(-35.32,-19.12)，保持源比例；head2右饰高43并较原贴边位置右下各移1px，接线对齐head3内部横线（y约90.942）、宽1.2，左端嵌入3px、右端延伸至屏幕边缘，背景填至水平线；LEFT_TIP/RIGHT_TIP标记两图接线尖头；填充沿源图不透明下轮廓，保持原图比例。常规浏览点击/拖动/滚动顶部栏不操作地图，对话打开时在顶部栏点击仍推进台词。

1. 用 Godot 4.7.2 打开项目的 `project.godot`，等待新图片导入完成。
2. 按 **F5** 运行项目，直接显示青石河湾地图，玩家站在右侧道路末端。单击其他节点即可移动。
3. 按 **F8** 停止运行。需要检查原有战斗时，打开 `scenes/main/main.tscn`，按 **F6** 运行当前场景；战斗操作保持原样。

**如果看到项目列表和“编辑／运行”按钮，那是项目管理器。** 在这里先选中Path of Immortals，点“编辑”（或双击项目），进入有场景树和文件系统面板的项目编辑器，再按F5。项目管理器的“运行”也能启动同一个地图，但不是编辑器的F5操作环境。项目主场景已配置为 `res://scenes/maps/qingshihewan.tscn`，不需要每次重新指定。要看新修改，先F8停止旧运行，保存后再F5；在编辑器外修改场景后，如出现重新加载提示请选择重新加载磁盘版本，避免用旧内容覆盖新改动。

地图场景为 `scenes/maps/qingshihewan.tscn`。窗口默认1920×1080，以 **图片宽度正好铺满屏幕宽度为100%**，初始 **125%** 并定位到玩家起点；边缘区域通过拖动查看。之后视图不自动跟随角色，可自行拖图观察。没有生成新的游戏导出包，旧exe不会自动获得这些修改。

**游戏内浏览：**按住鼠标左键拖动，松开停止；滚轮向上放大、向下缩小，以鼠标所在位置为中心。当前范围 **100%～175%**，每格变化约10%。地图边缘有限位，无法拖离屏幕；缩至100%左右正好铺满，没有两侧黑边。等比缩放下，上下超出的部分可拖动查看；若窗口较高、图片高度不足，则只在上下留边。窗口大小改变时尽量保留当前中心观察位置。浏览操作仅改变镜头显示，不移动路线节点，也不会保存到布局源场景。

## 桥西端对话测试与微调

2026-09-16圆框参数：新map-dialogue源图1835×470，background_region=[10,33,1807,409]；portrait_slot=[62,20.5,368,368]、portrait_max_size=368、text_rect=[475,95,1250,220]，均为裁切后坐标。主角player-1-1使用portrait_region=[22,18,448,448]，青岚宗弟子npc-qlzdz-1使用[27,27,664,664]。每张头像先按实际有效圆心裁去透明留白，再等比填满窗口、裁圆，头像先画在圆框金边下方；不能对不同尺寸头像套相同原图裁切。更换新头像时，校准portrait_region使圆孔边缘对应的像素不透明，并保留约4源像素的金边覆盖量，避免漏图。不要直接拉伸横纵比例。

目前大桥西端N37和中央小屋旁N20配置互动。从最右侧起点点击N37，等主角走到并停稳后，再点同一路径节点才显示第一句。对话打开后任意位置左键单击进入下一句，显示第5句后再点一次关闭并完成。完成N37后才可触发N20：到达停稳再点击节点，先显示事件框和插画，再点一次显示第一句，20句按说话者切换头像，末句后再点一次完成。期间不能移动角色、拖图或缩放；关闭点击不会穿透。完成后仅对应节点的Sign和StoryIcon一起隐藏，节点和路线保留，其他路标不受影响。同次运行重新进入地图也不重复；F8→F5重启可重新测试，没有写入存档。

事件配置：`data/map_events/qingshihewan_bridge_dialogue.json`及`qingshihewan_wounded_disciple.json`，由地图JSON的event_files引用。lines为逐段文本；presentation为背景、头像及区域参数；speakers和line_speakers指定各句头像，requires_completed指定前置完成事件。对话背景按可见区域等比显示，中心为屏幕宽50%、高75%，美术整体在旧版“宽88%窗口/高不超过34%”基准上再等比乘2/3；文字使用系统楷体KaiTi，字号按旧版基准计算后减1，1920×1080时为31px。portrait_slot和text_rect以裁切后的背景原图坐标为准，portrait_max_size控制圆头像最大边，保持头像原始比例和圆框中心。更换图尺寸或边距后须核对这些区域。

N20的presentation.illustration配置事件框、插画及image_slot内窗。实际框素材名为map-event-frame.webp；插画为map-event-1-1.webp，等比覆盖内窗并少量裁边。`scripts/map/map_event_picture.gd`的layout_for先计算旧版顶部30%及距对话框16逻辑像素的基准尺寸，再以旧底边中心为锚点将框和内图等比放大5/3（先乘4/3，再乘1.25），向上扩展，保持底边及对话间距；`scripts/map/map_dialogue.gd`控制对话中心75%。两者均使用屏幕坐标，不随地图缩放。新版对话框按原始比例显示为1126.4×254.95，边界约y682.52～937.48；事件图相应适配为918.47×570.87，顶部约95.65、底部约666.52，保持16px间隔。后续微调这两处布局参数即可，不必修改源图。通用结构见`docs/map-interaction-design.md`；其他事件类型等待后续开发。

## 调整路线弯曲

1. 展开 **Routes**，选择对应的 `Path2D`。例如 `R18_N37_N20` 表示大桥西端至中央小屋岔口。
2. 使用2D视图上方的 **Path2D曲线编辑工具**，拖动中间控制点；调整贝塞尔手柄可改变弯曲程度，也可以使用曲线工具增删中间控制点。
3. **路线首尾位置由Points节点决定**。移动端点请改对应标记，不要只拖动曲线的第一个或最后一个点，否则会被自动跟随逻辑还原。首尾点的贝塞尔手柄仍可调，用来改变出入方向。
4. Ctrl+S保存，F5预览。每段路线都有独立Curve2D，修改一段不会改变另一段。

布局源场景适合编辑，不负责窗口适配。预览整张地图请用F5，或打开 `qingshihewan.tscn` 后F6；不要把布局源场景F6的原尺寸显示误当作最终效果。

## 调整发光虚线

选中Routes中的路线，检查器可直接调整：

| 属性 | 当前值 | 用途 |
| --- | --- | --- |
| Dash Spacing | 18 | 相邻亮点的间距，越小越密 |
| Dash Length | 6 | 每一小段亮线的长度 |
| Line Width | 4 | 亮线粗细 |
| Light Color | fff2af | 中心亮色 |
| Glow Color | ffbf42 | 周边金色光晕 |
| Shadow Color | 深棕黑，Alpha为0.42 | 路线下方阴影颜色及浓度，降低Alpha可减淡 |
| Shadow Width | 5 | 阴影比亮线多出的宽度，阴影向下偏移2原图像素 |

长度单位均为原图像素，随地图整体缩放。可多选路线批量改这些属性。光晕由半透明笔画叠加绘制，在编辑器和Mobile渲染器内可见，无需开启全屏Bloom。图片文件没有被涂改。
