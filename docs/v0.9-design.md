# V0.9 战斗控制、排版与撤退

2026-09-08，实现前记录；用户已确认全部待定规则。

- 顶部控制顺序为暂停、0.5x、正常播放、2倍。四个横排正方形按钮底色2d261f，边长为计时器高度一半；计时器略缩窄且保持全屏居中。保留空格和F1/F2/F3。正常播放可以开始/恢复并设1倍；速度按钮选择速度，暂停保持原速度。底部日志与撤退并排。
- 移除头像组合中的常驻名称/境界；保留等级数据与边框映射、阵盘标题。资源组与头像垂直居中，队友不显示资源名称并略缩窄；主角资源条右端通过容器与阵盘右端对齐，不绘制辅助线。
- GameState保存撤退截止模拟时间。BattleSimulation接收request_retreat，排入3模拟秒后的撤退事件；暂停/倍速沿用模拟时钟。期间攻击、回复、装备规则不变。胜负/平局优先于撤退，包括同刻结算，正常结果清理撤退状态。重复请求不重置计时；仅战斗阶段接受。
- 撤退成功通过现有finished事件发布retreat结果，冻结模拟并清理未来事件。GameManager关闭整理并锁定编辑。UI显示中央3s/2s/1s，按该秒模拟进度放大、模糊及淡出，显示动画不驱动玩法。
- 成功后模态框提供战斗复盘（预留信号，当前提示尚未开放）及退出战斗（暂时退出应用，未来接地图）。不实现复盘数据存储/播放、地图或存档。测试通过退出请求信号验证按钮路由，并独立启动进程验证真正退出。
- 完成后运行纯逻辑、headless UI、启动及渲染验证，记录本地结果；不提交或同步Git。
