## 五重书学习条件与记录

七系共21本五重功法的每重选项共用该重学习进度条件。按钮下方剩余空间的中心为源图y=1198，勾／叉中心x=120，沿用法术页学习条件的水平位置及30.6×30.6尺寸。文字从x=152开始、字号23，以可见字形垂直居中并保持完整一行：满足时“已达到所需的修炼进度。”，否则“未达到所需的修炼进度。”。

条件只读`state.knowledge.level(book_id) >= selected_rank`，不以浏览选中态、其他书进度或演示记录授予资格。正式成长达到该重阈值后会登记已完成重数；进度不足时按钮禁用、显示“无法强化”、保持黑底白字与普通光标，无悬浮变金或按压缩放。达标恢复“确认强化”及既有反馈，当前仍不提交学习；这条只表示修炼进度已满足，不自动开放待实现的技艺／连携。两本八重书的按钮与法术条件显示沿原行为。

已有权威账本为[核心学习记录](../scripts/core/cultivation_knowledge.gd)：`practice[book_id]`存该书当前阶段修炼度，`learned[book_id].level`存已完成重数，`learned[book_id].branches[重数]`存正式选择。`CultivationGrowth.award_book`按阈值推进并将阶段内修炼度归零。账本通过`MapLoadoutState.snapshot().learning`嵌入`user://inventory_loadout.json`，由`MapLoadoutStore`保存／恢复。当前法术已学列表由`learned_spells()`按书重数与法术解锁重数推导，修炼会话自动入袋、防重复；没有另设“已完成重数但未点击法术学习”的独立账本。右栏`preview_choices`仅为界面预览，与上述正式记录分开。
