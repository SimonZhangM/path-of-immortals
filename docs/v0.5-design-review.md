# V0.5 共享储物袋、战斗调整与丹药

2026-09-07，实施前记录。用户已确认最新CD定义，覆盖旧版本暂停锁包规则。

## 确认范围

- 保留战前准备，空格开始，战斗中空格暂停/恢复。准备与暂停可打开右侧储物袋；恢复自动关闭。只有调整面板打开时编辑阵盘。
- 移除中列阵型、开始、暂停、重新布阵按钮和左上角状态文字。保留标题；状态位于严格居中的计时下方。中列底部放背包调整、战斗记录按钮。日志默认隐藏，可弹出查阅。
- 阵型数据/API保留供未来大地图调用，战斗UI不提供切换。选中我方人物/阵盘只确定物品放入目标，不改变固定排版大小。
- 共享储物袋只展示未上阵物品。支持拖入、右键随机合法位置装入、从阵盘退回。武器防具各两种沿用现有素材；三种丹药各10瓶，分别回复气血、灵力、体力。
- 冷却CD为战斗开始后装备调整引入的等待，默认2游戏秒；战前装入/移动没有冷却。轮转CD为每次生效前计时，测试主动物品均3游戏秒。暂停冻结两种计时，倍速仅改变模拟时间。
- 新装入、移动、换角色重新冷却再轮转；同格落下不重置；同种丹药追加数量不打断原进度。灰色物品中央显示冷却剩余2s/1s，其后使用现有轮转揭示。
- 丹药每瓶两次，每次生效在随后3游戏秒回复5点（整点1/2/2），轮转独立继续。第2次发动扣除该瓶，已发动的回复事件继续完成。满资源不启用新瓶；已开瓶的第2次照常完成，不允许通过移动重置次数。无复活/超上限回复。

## 架构

- JSON ItemData增加分类、品质、可堆叠/每瓶次数；效果增加通用restore_over_time(resource,value,duration)，不为普通道具创建脚本。预留法器/防具/丹药/道具/符箓分类。
- InventoryState保留4×4占位，以堆叠记录包含独立瓶ID与剩余次数，避免转移丢失已用次数。新增SharedStorage保存未上阵实例；唯一归属由GameManager的转移命令维护，失败不扣物品。
- BattleSimulation保留事件队列，动态登记/移除装备以版本号使旧轮转事件失效；独立回复事件绑定施用时角色，装备移动不取消已生效回复。资源变化后唤醒等待的丹药和恢复体力的武器，不逐帧扫描物品。
- UI只读库存/模拟状态，发送选择、转移、移动命令。右键随机落点由管理层选择，模拟自身不调用随机数/时钟/场景。
- 右侧储物袋覆盖敌方区域而不压缩我方阵盘；类别筛选与滚动物品卡片参考用户结构。日志独立可关闭浮层。

## 验证计划

沿用战斗/阵型/定时回归；新增总量守恒、无空间/错误来源原子拒绝、堆叠与部分使用往返、战前无冷却、战中冷却与旧事件失效、暂停/倍速、资源上限与满值等待、两次消耗、持续治疗、体力恢复唤醒、UI右键/拖放/面板锁定和多分辨率截图。运行headless与启动及渲染检查。没有存档/大地图/防御效果/正式素材扩展。
