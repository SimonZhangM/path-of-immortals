# V0.7 操作与战斗反馈设计

2026-09-07，依据本轮十项需求及随后确认，在实现前记录。

- 战前放入没有入场冷却；战中从共享储物袋放入，每次重新等待3游戏秒，包含尚未冷却完成就收回再放入。阵盘内部移动仅更改格位，不重新attach、不重置轮转、不移除防御、不重触发进场。
- 丹药第一次实际轮转生效才开瓶，轮转计时中的未开瓶可以收回。右键只收回一瓶未开瓶；拖回收回所有未开瓶，已开瓶留下。没有未开瓶时拒绝收回。拆分保留原阵盘实例和事件进度，返回瓶使用独立瓶ID，避免跨角色冲突。
- 追加丹药保留已有瓶的轮转进度，新瓶单独记录3秒入场截止时间；轮到新瓶时必须已完成它的入场等待，再进行轮转。单瓶截止时间属于模拟运行态，不依赖UI或墙钟。
- 模拟发送通用item_activated事件，包含来源与格位快照；UI据此做同步的0.24秒淡白闪光和轻微缩放。最后一瓶消耗后仍可通过快照完成反馈。动画只使用展示时间，不参与战斗结算。
- 五列卡片缩小，图片在完整卡片正中央，数量跟随等比缩放后的图片右下角；占格示意在2×2框内靠右。保留名称和圆角类别/品质标签。
- 入场灰层更透明；轮转仅保留半透明白色实线，去掉上方灰层。资源条圆润并加入斜向明暗层；保留颜色、宽度及居中数值。
- 中央计时增加棕色框和两侧短线，无图标；显示两位小数，60秒前如12.34，之后如01:12.34。状态保持下方，时间继续严格水平居中。

不新增大地图、存档或普通物品专用脚本；Data → Registry → Simulation → State → UI边界保持不变。
