## 1. 当前五页设置：按功能分类

页面分为“游戏／操作／画面／声音／其他”五类，共17个可调项目和1项只读版本信息。以下均已接到对应运行行为，默认值来自用户本轮明确答复及[默认配置](../data/settings/defaults.json)。存档列表、读取和手动保存继续使用独立存读档页面。

### 游戏：7项

| 设置项 | 现行行为 | 默认值／可选项 |
| --- | --- | --- |
| 对话文字速度 | 控制新发言的逐字显示；不改变剧情、战斗和修炼计时 | 默认中；慢15／中30／快60字每秒／立即显示 |
| 对话自动播放 | 当前发言完整显示后等待2秒，继续允许推进的连续发言；不代选话题、分支、物品、交易或战斗命令 | 默认关闭；开启／关闭 |
| 默认战斗倍速 | 新建下一场战斗时使用所选倍速；战中仍能临时切换，临时值不反写默认偏好 | 默认1倍；0.5／1／2倍 |
| 后台自动暂停 | 应用失焦时暂停地图、战斗和修炼；回到前台撤销本设置产生的暂停，保留原有主动暂停 | 默认开启 |
| 自动存档 | 独立控制02定时自动快照；关闭不删旧档、不影响手动保存和内部会话记录 | 默认开启 |
| 自动保存间隔 | 控制定时自动档的现实游玩时间间隔；自动存档关闭时此项灰显，所选值保留 | 默认10分钟；5／10／15／30分钟 |
| 快速存档 | 独立控制01动作完成／战前快照，不受定时保存间隔影响 | 默认开启 |

后台自动暂停与声音页的后台静音独立控制玩法和声音。关闭后台暂停时允许游戏继续运行；关闭后台静音时允许后台继续出声。

### 操作：3项

| 设置项 | 现行行为 | 默认值／可选项 |
| --- | --- | --- |
| 自定义按键 | 点击键位后录入一个普通按键；每动作只有一个绑定，冲突会拦截；Esc取消录入 | 初始映射见第7节；无备用键或组合键 |
| 地图缩放滚轮反向 | 反向游历地图、世界地图画布及世界地图缩放条接受的滚轮缩放；不改变其他列表滚动、拖动或加减按钮 | 默认关闭 |
| 快捷键提示 | 已接入的操作提示显示当前绑定键；关闭仅隐藏快捷键部分，保留功能名和必要状态文字 | 默认开启 |

本轮只接已有动作，没有新增WASD镜头移动、概览、图鉴或手柄操作。输入与提示统一读取当前InputMap；详细冲突范围见第7节。

### 画面：3项

| 设置项 | 现行行为 | 默认值／可选项 |
| --- | --- | --- |
| 显示模式 | 切换窗口／无边框全屏 | 初始沿本次启动的实际显示状态；不提供独占全屏 |
| 分辨率 | 窗口模式按显示器工作区筛选可用尺寸；无边框全屏使用显示器原生尺寸，此项灰显并提示原因 | 初始沿当前状态；候选基线1280×720、1366×768、1600×900、1920×1080、2560×1440、3840×2160，实际列表按当前屏幕筛选 |
| 帧率上限 | 通过引擎绘制上限限制地图、角色及UI帧率，不改变战斗倍速或修炼计时 | 默认60帧；30／60帧 |

逻辑画布保持2560×1440，最小窗口保持1280×720；不改变桌面分辨率，不引入独立渲染比例。已使用的窗口尺寸可保留在候选列表；从全屏切回窗口时，若原生尺寸不适合窗口工作区，则选可用列表中的最大尺寸。恢复画面默认使用本次启动时的显示状态，不是固定覆盖为某一种模式。垂直同步没有玩家设置项。

### 声音：4项

| 设置项 | 现行行为 | 默认值／可选项 |
| --- | --- | --- |
| 总音量 | 控制Master总线，叠加音乐和音效分类增益 | 默认100%；0～100% |
| 音乐音量 | 控制开始页、地图、战斗及胜利音乐的Music总线 | 默认100%；0～100% |
| 音效音量 | 控制攻击、法术、恢复及按钮点击、拾取、放置、无效操作等Effects总线 | 默认100%；0～100%，不设独立界面音量 |
| 后台静音 | 应用失焦时静音，回到前台撤销本设置产生的静音；不清除外部已有静音状态 | 默认开启 |

三类音量保留素材和播放器原有相对响度，100%不等于把每个播放器改成相同分贝。滑条可即时预听；取消或Esc返回时恢复应用前的音量。音效分类只控制已接入的声音，不代表未制作的独立音效已全部补齐。

## 2. 界面、入口与应用方式

用户指定采用横向页签方案1，素材与布局配置集中在[system_settings.json](../data/ui/system_settings.json)：

- 背景使用UI-game-systemsetup，内容画布沿用UI-start-saveload中心及适配基准；最新按用户要求，仅背景图片下移20源像素，内容保持。游戏抬头与地图吊牌在页面蒙版下保留。
- 普通按钮默认使用UI-start-button3，悬浮使用UI-start-button2；开关按用户最新修订，在大胶囊左侧嵌较短的小胶囊轨道并缩小圆钮，关闭时圆钮在左、开启时在右，点击后平滑位移。
- 各页小标题前使用UI-map-scrollstar；五页标题与第一行内容共用起点。“其他”页同样左对齐，不沿概念图单独居中。
- 不再显示“系统设置”大标题、标题装饰线或右上角叉号；删去后已重新排版。
- 最新微调：下拉框默认改用UI-start-button1并放大向下箭头，五分类加粗且字号＋2；操作页键位框和内部文字以原中心缩小20%；画面三项新样式下拉框移至左半部，最新保持右边缘／高度、宽度从400收窄三分之一至266.67源px。用户已取消整体下移10px，页签与内容保持原纵向位置。

| 操作 | 当前行为 |
| --- | --- |
| 切换分类 | 保留本次草稿，不立即提交其他设置 |
| 恢复默认 | 仅恢复当前分类的草稿，不改其他分类或角色进度；声音页可预听恢复后的值 |
| 应用并关闭 | 先校验完整草稿；有效时统一提交并返回入口，无效时保留面板和错误提示 |

地图中设置从系统菜单进入，关闭后回系统菜单；菜单期间保持暂停，音乐可继续并响应音量调整。界面消费本次按键，关闭不会顺带触发底下的对话、移动或开战。战斗右上设置齿轮仍是独立后续入口，本轮没有扩大该入口范围。

## 7. 当前行为细节

### 对话文字速度与自动播放

当前剧情对话与NPC连续发言共用[逐字与自动推进组件](../scripts/dialogue/dialogue_playback.gd)：慢15／中30／快60字每秒或立即显示，自动推进等待固定2秒。完整文本先参与气泡排版，再控制可见字符，避免逐字过程导致布局跳动。已有聊天历史直接完整显示，多气泡的新发言按顺序揭示。

手动继续时，尚未显示完先补全，下一次才推进；自动播放只推进当前允许继续的发言。话题、分支、领奖、交易等选择仍由玩家操作；自动播放不合并“显示全文”和“选择分支”。关闭、隐藏或挂起对话会停止／重置等待，后台暂停开启时不会靠失焦时长连续跳过多段。对话速度不改变模拟时间、战斗速度或剧情完成条件。

### 默认战斗倍速

新建战斗模拟时读取默认0.5／1／2倍，初始为1倍，仍停在战前准备等待开始。战中按钮／快捷键只改变本场速度，不反写下一场默认值；不使用Engine.time_scale联动全局UI与音乐。

### 自定义按键

| 动作 | 初始键位 |
| --- | --- |
| 打开储物袋 | I |
| 打开功法 | G |
| 打开任务 | T |
| 打开世界地图 | M |
| 继续对话 | 空格 |
| 战斗暂停／继续 | 空格 |
| 战斗0.5倍速 | F1 |
| 战斗1倍速 | F2 |
| 战斗2倍速 | F3 |

录入新键会替换该动作的旧绑定，不累加备用键。Esc保留取消／返回，组合键和单独修饰键不接受。冲突按真实输入上下文校验：

- 地图：储物袋、功法、任务、世界地图不能重键。
- 对话：继续对话可与地图或战斗动作跨上下文复用。
- 战斗：储物袋、暂停／继续、三档倍速不能重键；储物袋在战斗中也会消费输入，不能遗漏其冲突检查。

无效草稿不会部分写入InputMap或已应用设置。文本输入和模态界面继续拦截不该触发的玩法快捷键；已接入的提示随当前绑定刷新。

### 滚轮反向与快捷键提示

滚轮反向只改变两类地图及世界地图缩放条上的滚轮缩放方向，地图定位锚点、缩放步长与上下限保持。储物袋、功法、聊天历史和存档列表的滚动方向不变，拖动缩放条和加减按钮不反向。

快捷键提示控制已接入的世界地图关闭提示、战斗储物袋／开始／暂停／倍速等操作提示中的键名。功能名称、剧情内容和必要状态信息保留，不能将关闭快捷键提示解释为隐藏所有说明。

### 自动与快速存档设置

- 自动开关只控制02定时快照，快速开关只控制01动作／战前快照；二者独立，允许只开一种或两种都关。已有快照和手动存档保持。
- 定时默认10分钟，可选5／10／15／30分钟。应用自动开关或间隔变更时，重新开始倒计时并清除旧挂起请求／重试等待；关闭期间不累计，也不会重新开启后立即补存旧请求。
- 到点遇战斗、剧情、交易、修炼等非安全状态只挂起一次，回到安全状态再保存。系统／存档菜单及后台暂停不计入定时自动档的有效游玩时间。
- 关闭快速存档时清除待重试的快速快照，后续动作不再触发快速写入；不取消交易、修炼、移动或战斗，不关闭内部事务记录，也不删除之前的快速档。
- 已应用的保存偏好保留在当前进程，读取旧角色档不会把设置重新打开。退出仍不额外生成快速／自动快照。

### 声音、后台与显示

Music／Effects分类和Master总音量相乘，源播放器的相对分贝不变。后台静音与音量预听分别管理，不通过修改每条素材响度实现。失焦暂停只暂停场景处理，前台恢复仅撤销本设置持有的暂停，不取消玩家本来暂停的战斗；原本已经静音的状态也保留。

画面设置只作用于本游戏窗口及绘制上限。无边框全屏使用原生尺寸；窗口分辨率按工作区筛选，不修改桌面显示模式。设置没有显示倒计时回退；取消只放弃尚未应用的草稿，应用成功后直接关闭。
