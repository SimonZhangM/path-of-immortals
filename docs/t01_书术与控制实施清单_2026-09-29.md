## 实施前差异与最小设计

首批已有115资产、21状态、基础费用／命中／甲盾、冻结麻痹、一次性入库。书术只有映射，缺学习账本、独立法术实例、剩余CD调速与条件待发；这些属于代码缺口，不能描述成“初学参数未定”。

采用 Data → Registry → Simulation → Game State → UI：JSON注册普通内容，学习账本与成长进度分开；模拟层集中处理书术和控制，事件队列按微秒工作量、代际凭证及固定阵盘顺序调度。UI显示权威状态并调用命令，未引入每帧全盘玩法轮询或Engine.time_scale。连携相关分支明确标注暂缓。

## 现在怎样观察

1. 原115件继续用F5地图I与scenes/main/main.tscn的F6入口，操作和保存沿用README。
2. 单独打开scenes/main/cultivation_preview.tscn，选GameManager节点，在检查器设置preview_spell_id、可选preview_branch，再按F6。默认庚锋剑；例如base.spell.metal_03／返剑观察剑幕，base.spell.metal_07／返锋观察灵盾转伤。完整ID见映射表。
3. 也可使用Godot用户参数 --preview-spell=base.spell.water_02 --preview-branch=裂冰 运行该场景。每次只临时习得目标法术所需重数、放入法术＋原书＋青石短剑。使用真实3×3阵盘与基础50／50／50，原阵盘、随从加成另计。
4. 点击开始，查看状态栏和战斗记录；悬浮法术显示当前分支效果。预备式观察入口延后木桩首次攻击，并按需要临时配置护甲、雷盾或受伤条件。该场景不读写玩家库存或学习存档；它是观察夹具，非正式获取、成长或平衡配置。
