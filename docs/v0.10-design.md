# V0.10 单阵盘与配角特质（2026-09-08）

用户已确认：每方一个主角、一个4×4阵盘、零至两个纯辅助配角。配角无阵盘/资源、不受击，不耗资源；主角死亡即判负，取消前后排。每配角最多两个特质，主动/被动任意组合。角色2、3沿用头像/等级，野狗无配角。未启用旧配角装备不再作为初始装备生成（无存档迁移）。

## 数据与模拟

增加 JSON 特质、五行属性注册表，保持原角色/物品ID。CompanionState仅含身份、等级和特质定义；GameState将主角teams与companions分开，队伍入口拒绝多主角/超过两配角/重复身份。原FormationRules退出当前战斗调用链。

测试内容：角色2「回春诀」木，每6秒立即为己方主角恢复5气血（满血照常轮转，不溢出）；「护元」土，被动防御+1。角色3「离火诀」火，每4秒对敌主角造成5普通法术伤害（扣防御；配角不可受击，法术不触发装备反击）；「培元」木，被动气血上限+20，同时初始气血+20。所有被动在模拟创建时按来源应用，重建前清除旧贡献，不叠加。

主动特质使用同一个微秒事件队列，开战开始完整轮转；同刻装备进场优先、装备激活随后、特质按side/配角/槽位稳定顺序，撤退最后。暂停/倍速只影响模拟。主角阵亡或撤退后清空特质事件。只有治疗/被动且无装备可发动时允许平局；有效伤害特质可保持战斗。没有配角编辑/招募/资源消耗机制。

## 展示

双方阵盘各一个且居中；上方主角头像/资源，下方紧邻两张小配角头像与各两个特质槽（空槽可展示）。复用等级边框与头像裁剪。配角不显示资源条。物品与主动特质共用小圆环：显示轮转剩余秒数，一位小数；环随剩余时间缩短。战前显示完整时长，等待资源/结束显示就绪；入场3秒仍用原灰层中央倒数，不叠加轮转圈。数量角标与圆环分开放置。

五行颜色只作标识：金黄、木绿、水蓝、火红橙、土黄，无属性白。无克制。速度按钮顺序暂停、0.5x、正常、2x，放大到36px正方形，深棕底/金边，位于右上；Space/F1/F2/F3保留。不新增设置。
