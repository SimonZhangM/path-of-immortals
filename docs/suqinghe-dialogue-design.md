### 人物身份与两项愿望

苏清禾在故事开始时18岁，比15岁的张辰宇大3岁；是叶松年的外孙女、辰宇从小相识的伙伴，也是青石镇医馆主人。年龄是开局背景，后续不能用固定“十八岁／十五岁”的台词覆盖游戏时间。她温柔细心、认真求证，有独立的医学追求，也有尚未说出口的好感。

她正式成为第一位长期队友，成长路径为**凡俗医者 → 青岚宗医修 → 丹医兼修 → 研究天地生态的高阶丹师**。宗门阶段才逐渐学习灵药、丹道和治疗法术，不把医馆时的她写成成熟丹师。医馆是这条道路的起点，既有与陆怀真共同商议用药、追踪医案的合作仍成立。

两项长期愿望同样重要：学到更高明的医术，帮助反复发病、凡药难以应付的病人；与辰宇一起见识更广阔的世界。她不会只因喜欢辰宇就放弃自己的生活，也不会为了关系路线放弃医学志向。

### 早就存在的修行可能

采用这次稿中的背景：几年前青岚宗下山招收弟子时，她接受过灵根初测，知道自己具备学习基础修行功法的资质；当时没有继续参加正式入宗考核。初测不等于已经入宗，也不确定灵根属性、品级或当前境界。

她随长辈学医多年，已能独立处理常见病症；熟悉的病人仍需照看，医馆事务与对外公的牵挂让她不断往后推。这不是临时设置的阻碍，也不新增家庭悲剧。辰宇成功引气、获得求学机会以后先走一步；她为他高兴，也逐渐意识到自己需要作出选择。不得把这种不舍写成要求辰宇留下的压力。

### 促成决定的病例

辰宇离镇后，医馆接诊一位反复发病的村民。清禾认真诊治，对方一度好转，却又回来。她重新核对诊断、用药及调养记录，没有发现明显差错，开始怀疑只在医馆中处理症状不足以找到病因。

早期「医馆近况」仍只提供恢复较慢、部分药材气味较淡、须核采收／晾晒／存放与来处的线索；**不能提前宣告药性已证实下降，也不能宣告疾病必由水土或药材造成**。后续剧情逐渐验证药效、生活环境与生态变化的联系。新病例不是现有某份医案已好转就永不复发，也不否定前轮对话中的阶段性进展。

辰宇带回灵药、丹术见闻，让她看见进一步学习的可能。求医的愿望与一起远行的心情共同促成一句“这次，我也想试试。”不需要激昂宣言、突然成熟的丹术或提前查明世界真相。

### 药堂轮诊、医馆运营与实际在场

青岚宗药堂设正常的山下轮诊制度，与山下医馆合作，服务弟子实践、百姓诊疗，以及附近伤病、药性、水土变化的观察；不为清禾单独破例。她熟悉本地病人，入宗后适合承担青石镇的轮诊任务。

外出期间由坐堂医者接诊；采用原有医馆人员与百草门医修合作的安排方向，不另外创造重要NPC。百草门与青岚宗药堂不是同一机构，不擅自写成隶属关系；具体合作人员、交接与轮诊日程留正式剧情落实。交接未成立前，不演出“已经安排好”。

正式同行后通常与主角同行，地图上仍只控制主角。轮诊安排在章节间、休整或明确剧情节点；只有明确的“暂时离队”事件才暂时停用她的战斗辅助，且不频繁打断玩家培养。将来接入人物在场状态时，医馆营业与清禾本人在场分开：她随队远行时，医馆可由代诊人员营业，但不能同时把清禾作为坐堂对话者；替班者也不能使用她的个人欢迎、童年对话或代她作承诺。

## 欢迎词分类与正式话题关系

| 类型 | 条件 | 处理 |
| --- | --- | --- |
| 首次欢迎 | 第一次进入交谈 | 固定剧情欢迎，只出现一次 |
| 日常欢迎 | 普通回访，剧情未变化 | 简短词库轮换，可重复使用，避免连续两次完全相同 |
| 状态欢迎 | 受伤、疲倦等符合条件的情况 | 根据实际状态选取，优先于普通日常欢迎，不随机冒充状态 |
| 剧情欢迎 | 主线进入新阶段 | 阶段专属欢迎；区分一次性的重大剧情欢迎与该阶段后续常规欢迎 |

欢迎是见面的问候，正式话题是有内容进度和历史记录的交流。日常欢迎不消耗闲聊库、不进入正式话题记录、不重置已完成话题。三个话题全部完成后仍有自然问候；完成话题的按钮继续查看历史，新剧情显示“新”，新的闲聊仍通过“闲聊”进入。

进入交谈后先判断尚未播放的首次或重要剧情欢迎；没有时，再按当前状态与剧情阶段适用的常规词库选择。欢迎结束后显示医馆近况、叶伯近况、闲聊三个话题。阶段常规欢迎替换原日常词库，不等同于重演入宗后首次回镇的长篇剧情。

同一次进入医馆，普通“诊治／交谈”页签切换不重复播放欢迎；离开后再次到访才重新触发。现有医馆默认进入交谈页，本方案不要求新增一次点击交谈的前置操作。

**用户已确认并接入的例外：**成功诊治后首次返回交谈时，额外播放一次“好了，伤已经处理妥当……”专用欢迎；之后切换页签不再重复。仅查看诊治页、取消或诊治失败不触发。首次欢迎尚未结束时先读完，保留末句可见，下一次继续才播放诊治后问候。
