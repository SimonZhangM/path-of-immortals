本轮用户要求：功法可放入作战行囊；功法/法术、丹药可选手动或自动，武器亦支持手动；自动丹药可接续行囊内下一瓶，手动到期等待发动。用户征询组合技构想与护甲是否有必要手动。已提出要求见[确认记录](combat-rules-confirmed-2026-09-12.md)，下文均为策划建议，名称、效果、触发条件和参数尚未批准，不授权修改原型。

## 建议的操作基线

- 保留自动战斗的可用性，关键器具切手动以选择资源、敌方防护和敌方CD窗口；同一技能的数值不因手动/自动模式而不同。
- 手动CD转好后保持一次待命，不继续空转，也不积攒多次发动。等待会推迟下次轮转，有输出/恢复频率代价。
- 切换模式保留当前CD、入列进度、瓶内次数及已发动效果；不通过切模式刷新或额外触发。切回自动且已就绪时，在下个合法结算点按发动条件处理，不在暂停中推进战斗。
- 普通自动攻击到期资源不足仍沿用已确认的空转完整CD。手动点击资源不足如何处理属于新增衔接：建议提示不足并保留待命，不消耗资源、不重置CD，避免反复点击惩罚；尚未获用户确认。
- 暂停操作适合休闲玩家策划组合。可考虑暂停中记录少量待命技能的施放顺序，恢复后在合法结算点依次校验成本和执行；这是待选交互方案，不能擅自加入原型，也不能让暂停期间发生伤害或恢复。
- 界面应可辨识入列、轮转、手动就绪及自动模式；手动技能不宜每次先开菜单再找发动。建议选择模式后记忆，直接点就绪图标发动，模式菜单单独进入，具体交互待设计。
- 功法的常驻属性与可主动发动招式可以分别定义；手动开关控制主动招式，不把甲型、上限或功法常驻加成变成必须反复点击的效果。功法如何占格及承载多个招式尚未定。

## 组合技候选

优先做效果条件的配合，让同类器具可以替换搭配。先验证两步配合，再考虑三步或更长连携；自动也能通过CD配比自然形成配合，手动负责选择更合适的窗口。

| 构想（暂名） | 动作与收益 | 时机和代价 |
| --- | --- | --- |
| 凝劲诀 → 重武器 | 沿已有“冲势”思路，强化指定武器的下一次成功发动，再用重击兑现 | 等目标武器就绪且体力足够再强化；不让另一把快武器误消耗指定强化，保留原冲势条件 |
| 破障术 → 淬毒飞针 | 先消耗敌方灵障，再命中施毒 | 本次施毒伤害后灵障仍有剩余就不能附毒；已生效毒不受后来获得的灵障影响 |
| 回灵丹 → 高耗灵法术 | 待药效实际补足灵力，再释放预留的大法术 | 药品资源与一个行囊格支持爆发；持续恢复药不能把点击当成全部恢复已到账；手动大招依然支付灵力 |
| 施毒 → 催毒术 | 新法术可按当前每跳毒伤提前结算限定跳数，并清除当前整份中毒 | 在继续持有持续伤害与立即收尾间选择；不直接兑现无限刷新后整段剩余毒伤；混毒按现行共同中毒记录处理，具体伤害结算待定义 |
| 自动积甲 → 卸甲诀 | 防具正常产甲，主动招式消耗一定当前护甲以增强本次攻击 | 消耗的是现有护甲，不是上限；可在敌方长CD空隙换取爆发，之后会更脆弱；由主动招式承担手动时机 |
| 缠枝诀 → 赤焰术 | 特定木系招式留下藤印；特定火系招式命中时消耗藤印，产生一次额外法术伤害 | 设置有限标记时窗或单次标记，具体数值后定；属于这两个效果的明确联动，不扩展为所有五行攻击默认相生克制 |

以上不要求全部同时制作。首批建议先试凝劲重击、破障施毒、回灵爆发，复用现有资源与效果；催毒、卸甲及藤印点燃属于后续新增内容候选。无实战模拟支持其平衡结论。

## 普通防具与特殊主动防御

建议普通防具保留自动产甲，甲型与上限常驻。现有护甲无自然到期，一般提前获得可以承受更多伤害，普遍增加手动开关容易把常规补甲变成重复操作。

仍存在真实的等待收益：达到护甲上限时，保留一次产甲，受击后立刻补回，会比溢出浪费后等下一轮更强；若产甲消耗稀缺资源，也可能需要安排时机。是否要优化自动溢出处理应结合数值验证，不把“护甲手动毫无用处”当结论，也不在本轮自动加满甲待命规则。

特殊防具可附带独立的主动能力，基础产甲仍自动。例如“玄武守势”在短窗口内减免一次攻击，“逆鳞反震”在短窗口内受击后反击，或带消耗当前护甲的爆发能力。这些能力可提供手动/自动选择；临时窗口只属于特殊效果，不改变普通护甲的无持续时间规则。不增加必须卡帧的格挡反应要求。

## 实现前尚需固定的衔接

首次丹药准备是否仍从手动启动后开始轮转，自动模式何时开始第一轮；手动丹药按次发动对旧瓶内自动规则的覆盖；手动资源不足处理；手动就绪后被CD延迟能否退回冷却；暂停施放顺序与同刻控制、资源恢复、死亡判定的关系；防具模式最终选择。这些不是本轮代码任务，先保留清晰的已定方向与建议即可。
