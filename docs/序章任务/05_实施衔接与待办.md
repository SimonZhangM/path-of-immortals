## 开场与医馆备药的实施衔接

1. [现有采集](../../data/ui/gathering_options.json)按1／2／3游戏日结算；晨起只规定开场时刻，返程不锁定同一天或某个时辰。
2. [叶松年](../yesongnian-dialogue-design.md)和[苏清禾](../suqinghe-dialogue-design.md)的既有日常包含药材差异等线索；新开场接入时应核对开放阶段，保留普通寒暄和旧档已读记录。
3. 开场须衔接主角自己的房间；不能仅换对白却仍从旧地图起点出发。药篓等叙事动作不另增玩家必须操作的步骤。
4. 两项任务分别保存接取、交付与完成；第一项已完成后才发生清禾来访，不能因为备药尚未完成就撤回主线完成状态。重读对话、往返地图不能重复扣药或支付报酬。奖励沿01中开场与医馆备药任务的已认可数值。
5. 第二项主线现按2026-10-29用户新流程编入[河湾后续任务稿](01_序章任务正文.md#主线二-河湾逢险)，以沈砚舟送达医馆结束，取代旧稿救助顺序。本文的医馆备药仍独立结算，清禾出诊时暂停本人交付，回馆后恢复。
6. 瀑布洞穴只绑定用户蓝框标示的现有节点，具体稳定ID在正式接入时核对；不凭截图创造新路径或入口。本轮不扩展洞内场景。
7. 止血草来源对应[现有林间草坡采集事件](../../data/map_events/qingshihewan_gathering_n04.json)。后续救助如也使用止血草，不能重复交付同一份；支线以可提交的当前库存为准，消耗后可按正常药材来源补足，不依赖重启刷新。
8. 清禾来药铺仅为一次短事件，取药后回医馆；不能同时在两个地点演出。她在医馆的交付只处理这条支线，不替代已有日常话题，也不擅自知道主角尚未告知的河湾经历。若主角受伤，沿用既有受伤欢迎和诊治入口，交任务不自动治疗。

[分段调整前的完整旧稿](../sources/prologue-quest-before-first-task-split-2026-10-28.txt)保留追溯，其中任务拆分与数值不作定案。

## 照尘镜与旧祠知情边界

古镜后续暂定名为**照尘镜**，沿用旧工作名照界镜的真实残录规则。初次拾取仍称「残缺古镜」，主角没有提前知道它的正式名称；以后识名只改显示，不另发第二件。

[旧祠探索与配图稿](02_日常探索与事件配图.md#无名旧祠探索与镜中配图)包含：参考图位置表、蜘蛛巢可选救狐与出祠放生、左上旧阵、上锁木门、上部石门的节点正文，以及三幅镜中静态插图说明。玩家侧的小狐狸全程不讲话、不揭阿璃之名；旧阵未来为古传送阵，木门后通向万灵南域，石门后为大型密室，均留待以后开放。

镜中画面只提供难解的真实局部，不预言、不出现导师讲解，也不直接告诉主角这些门和旧阵的用途。

## 河湾三项任务的实施对照

| 事项 | 当前口径 |
| --- | --- |
| 不能靠动画交代的事情 | 全部转成角色括号正文；制作说明与条件另列，不混进玩家台词 |
| 旧祠首次不能离开 | 外坡山兽经过，主角先在祠内取药避让；取药返程发现镜后确认兽群远去，从原门离开 |
| 可选救狐 | 不占任务栏、不要求主线救狐；已救则正常出祠时放生，先后两次分别记事 |
| 医术分工 | 主角应急处置，清禾诊察并安排转移，沈砚舟的经脉伤留待自己调息及宗门后续处理 |
| 沈砚舟受伤 | 伤人者为寻找阿璃的筑基狐妖，其真实身份只见幕后设定；玩家仅知不是普通野兽，与普通狼猪遭遇分开 |
| 医馆备药 | 请医优先，清禾离馆时暂停本人交付，回来后恢复；救援用掉的材料不能再交支线 |
| 钱万顺出行 | 出门取药闲聊时提到回程试走近路；叶伯问清河湾险情后自然想起这句话 |
| 悬赏 | 公告板接取，镇长所在处问明详情，带掉落物回镇长处交付；不再按纯击杀次数报验 |
| 人物在场 | 清禾出诊时不同时在医馆，钱万顺进货途中不同时守店；回来再恢复个人交谈 |
| 任务结尾 | 主线止于医馆安置，商人支线止于送到商铺，悬赏止于镇长处提交凭证并结算 |

### 已有资料与接入差异

1. [受伤弟子事件](../../data/map_events/qingshihewan_wounded_disciple.json)在河湾N20，沿用人物稳定ID与温玉佩物品ID；正式接入须更新姓名、旧桥头前置、受伤缘由与借还记录，关闭任务中的测试重领。玩家在听过自报姓名后才见到沈砚舟的名字。删除旧稿受惊兽群／落石致伤说法，采用[河湾逢险正文](01_序章任务正文.md#主线二-河湾逢险)中强大异兽停手离去的有限叙述。
2. [药材表](../../data/maps/herbs.json)、[采集资料](../../data/ui/gathering_options.json)已有青藤根／祠后石隙设定，止血草沿用[河湾N04](../../data/map_events/qingshihewan_gathering_n04.json)。旧祠节点尚未制作，按参考图布置可达后墙与供案拾镜点，不借用未开放木门、石门；这些位置不是现有已注册ID。
3. 首次进祠先播放门外兽群文字并记录阶段；取药返程经过供案拾镜，静态三图完成后才确认可出。已获镜后不重复限制出口；菜单退出和读档保留，恢复时继续真实阶段。满行囊与中断领取不能使主线卡死。不得通过可选救狐、旅行入口或加载恢复绕过首次拾镜。
4. [翻车商道N17](../../data/map_events/qingshihewan_encounter_n17.json)现在只有普通野猪遭遇，救援需一次性阶段。不能因早前杀过同地点或别处的野猪，直接判钱万顺已获救。实际返镇前不播救后店内对话。
5. 医馆安置后写入 `base.story.qingshihewan.cultivator_rescued`；钱万顺送至商铺后写入 `base.story.qingshihewan.rescue_completed`。参照[陆怀真](../luhuaizhen-dialogue-design.md)与[钱万顺](../qianwanshun-dialogue-design.md)的独立事实，其他人须经报信或交谈得知。
6. 钱万顺互通姓名沿用既有三句与 `base.story.qianwanshun.knows_name`；正式感谢长段留下一次回访。其中旧“碰上了，总不能不管”拟改为“听说您准备从河湾回来，我就想去看看，幸好赶上了”；旧“对你来说是碰巧”拟改为“你是惦记着我的安危才去的。这份心意，我记着”。涉及回程路线的旧闲聊也按新事件核对，已读历史不伪造重写。本轮不改运行JSON。
7. 镇长沿本轮命名周秉和，公告板和本人驻点为不同入口，节点后定。凭证使用 `base.material.shanlang_fang` 与 `base.material.cslz_tusk`，来源见[山狼](../../data/enemies/huiji_shanlang.json)、[獠猪](../../data/enemies/chisong_liaozhu.json)及[兽材表](../../data/maps/enemy_materials.json)。提交需核对实际可用库存、原子扣物发奖；交谈不代替交付，失败不扣物，重读不重复结算。
8. [照尘镜世界规则](../human-realm-story-summary.md)与[清禾人物时序](../suqinghe-dialogue-design.md)保持。出诊不等于正式入队，获《引气诀》不等于自动引气或入宗。古阵、木门和石门只记录用户指定的后续用途，不在本轮开放。

### 幕后因果与玩家知情边界

2026-10-29用户补充：阿璃偷偷跑出来玩，被蜘蛛抓走。她的母亲是筑基期狐妖，因女儿失踪而焦急寻找；初遇沈砚舟时误以为是他抓走女儿，将其打伤后察觉误会，没有继续害人，随后离开继续寻找。沈能生还源于对方停手，并不是他遭到普通野兽围攻，也不是凡人主角击退了这位狐妖。

这是编写者掌握的真实原因，不作为本次对话、任务引子、配图或图鉴解锁信息。察觉误会的具体依据暂不展开；沈与谢云舒都只知其强大且反常停手，不知道阿璃的身份。狐妖离开时还未找到阿璃，不替玩家完成可选救狐，也不默认离祠放生后已经母女团聚。后续见[旧祠探索的关联说明](02_日常探索与事件配图.md#无名旧祠探索与镜中配图)。

普通河湾狼猪、祠外兽群及蜘蛛仍是各自遭遇，不因这段身世统一升级为筑基敌人；镇长悬赏也不承担追杀狐妖的目标。不将河湾全部异常都直接归因于寻女。

2026-10-29用户认可河湾三项任务与旧祠探索的现有内容，保留门外避兽、三幅镜影、短剧情采药及各任务数量报酬；悬赏仍用现行25%普通掉率，不凭认可文稿擅加掉落保底。任务系统、地图、配图和运行对话尚未接入。新编的[第三、第四项主线](01_序章任务正文.md#主线三-潮声归处)接续渔村归家、母亲指导引气、辞别与战斗考核入宗，新增细节供下一轮审阅。

## 归家与入宗的实施清单

### 现有设定如何接续

1. [人界主线](../human-realm-story-summary.md)原「出身青石镇药铺」调整为「出身沿海渔村，在青石镇药铺学艺并居住」。母系是照尘镜旧主后代，是家世联系；不自动变为特殊血脉、前世身份或功法资格豁免。
2. 母亲来自北陆高原，现为炼气修士，遭海妖、落海获救、相爱定居的经历按用户新设定；她未透露所属宗门，具体层数、姓名及原家族另定。父亲只是出海未归，不预设尸骨、死因真相或隐藏大能身份。先人属于哪一时代、古镜如何流落旧祠均留后续线索。
3. 照尘镜仍遵守真实残录规则，母亲知道名称与家传来历，不等于知道三幅图的完整真相；她与主角都不知道主动使用的方法。认镜不播放新的全景回忆，也不授予鉴定一切古物的能力。
4. 《引气诀》在医馆获赠后可自行翻阅；正式的系统指导与首次引气主线移至渔村，由母亲承担。覆盖更早「必须在青石镇自己的房间完成首次引气」的安排，不要求返镇再突破一次。
5. [清禾人物时序](../suqinghe-dialogue-design.md)保持炼气篇中段入宗、后段同行；本次道别让早有的求医愿望重新明确，后续病例仍促成她落实计划。她不因舍不得主角而立即放弃病人或获得宗门录取。
6. [谢云舒](../xieyunshu-dialogue-design.md)沿既有身份、当值地点和姓名模板。她代交信物、解释通报及考核，不代执事承诺录取，也不离岗全程陪同。
7. 沈砚舟由宗门来人接回并逐渐恢复，驻点问路时明确交代，时间可随玩家游历与修行经过，不写成同日重伤后立即痊愈。若玩家极快衔接，接入时仍需保证其转移与能走动的叙事阶段成立。伤人者的真实来历见[河湾幕后因果](#幕后因果与玩家知情边界)；沈与谢云舒只知对方强大且忽然停手，主角没有迎战这位妖物。

### 修行与考核必须由实际机制完成

现行[成长数据](../../data/cultivation_growth.json)与[运行说明](../cultivation-runtime-2026-10-19.md)已有凡人准备修为100、引气成功率100%、尝试耗时1游戏日的基线。任务引用同一规则，不另建剧情数表；100%表示条件满足后的成功率，不是听过指导便立刻炼气。

正式制作需补渔村家中修炼点，按普通初级修炼点接入已有准备、阵盘、开始、暂停、结束及成长结算；不得因母亲指导额外乘收益或免除正常投入。现有修炼页的突破按钮已撤下，因此必须为本段补齐可实际操作的引气入口，不能只写一句「请自行突破」却没有按钮。首次导引石等入门供给需复用已有一次性凭证，不能每到新点再领一份。

正式新角色要记录指导与引气的真实先后；当前高境界测试存档不能伪装刚刚炼气，也不能被任务降级。接入时提供隔离的凡人剧情验证数据；若以后允许先行突破的合法流程，则使用「母亲核对已学根基」替代成功演出，不要求重复突破。本稿默认正式开局按上述首次引气顺序体验。任务要求按「至少炼气一层」判断；若玩家正常继续修炼后才去宗门，谢云舒问询读取实际境界，沈砚舟的惊喜改为「修为又长进了不少」，不强行称其仍为一层。

考核需落地试炼对手、普通入门配装可达性、战前准备、胜负回报及重试／休整入口。首轮验证应覆盖各类正式灵根，无需特定系技能才能过；不能用当前测试角色的高境界、全法术库存证明难度合理。战斗数值本轮未定，不运行模拟或声称已验证平衡。

### 任务和对话记录

送信、指导、识名、真实引气、三处辞别／问路、领信牌、山门通报、灵根测验、考核胜利、入门登记、住处开放、两封信完成分别保存。测验只保存已核验的剧情事实，不覆盖角色灵根；中断后继续、战斗重试都不重新抽取结果。正式实施时采用稳定ID，不在本文预编运行ID。

现有 `base.story.qinglan.departure_ready` 与 `base.story.qinglan.joined` 应由主线真实决定及登记写入；前者不能等驻点全部完毕才允许叶伯／清禾的必需道别，否则会形成前置循环。谢云舒的 `knows_cultivation` 由主角告知建立，她的 `knows_joined` 则要等后续真正获知，不能因主角在远处登记而自动成立。

既有叶伯／清禾离别段与云舒出发欢迎，正式接入时整合为主线对话，避免同次重复演出。旧档已读内容留在历史，新主线不伪造当年听过母亲身世；分支和迁移按实际事实处理。本轮只更新文稿与导航，不修改运行JSON或存档。

### 开发前还需补齐的具体内容

渔村名称与布局、母亲及许长海等人物姓名／美术、家中修炼入口、通往青岚宗的山路与宗门场景、测灵石场景呈现与真实灵根读取、考核敌人数值、信牌／弟子牌素材及宗门住处交互尚待对应制作。它们不妨碍本轮剧情稿完成，但不能把文稿中出现的地点与物品当成已经实装。

下一步先审阅01中归家与入宗任务的对白与节奏，再按用户指定制作场景、人物或任务数据；序章后续主线不在本轮继续扩写。

## 旧网待潮的制作衔接
