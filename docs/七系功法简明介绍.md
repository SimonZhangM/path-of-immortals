# 七系功法简明介绍

七系各有自己的战斗风格，每系五本功法，共35本。本文先介绍各系特点，再列每本功法的主要内容；56个法术逐项简述，省去伤害数值、完整分支表和结算公式。

## 先看七系各擅长什么

| 属性 | 主要玩法 | 战斗之外的技艺方向 |
| --- | --- | --- |
| 金 | 御剑攻伐、调动武器、反击与伤痕追加 | 炼器 |
| 木 | 恢复气血、毒蚀消耗、为火雷攻击铺垫 | 御兽 |
| 水 | 冰法攻击、消耗敌方灵力与体力、冻结阵盘 | 制符 |
| 火 | 正面爆发、持续灼烧、绕甲攻坚 | 炼丹 |
| 土 | 抗暴防守、重击、反击与恢复压制 | 勘脉采矿 |
| 风 | 闪避、提高命中、武器追击与冷却干预 | 探索追踪 |
| 雷 | 积雷成盾、雷印引爆、连环闪电与麻痹 | 阵法 |

## 每系五本功法怎么分工

每系都有一部**技艺功法**、一部**属性总纲**、一部**状态专精**，再加两部不同路线的**战斗功法**。

- **技艺功法**：学习炼器、御兽等生产或探索能力。
- **属性总纲**：强化本系整体运用，需要上阵才生效。
- **状态专精**：强化本系三种核心状态，已学效果常驻。
- **战斗功法**：每本解锁四个法术，两本合计八术；法术学会后可以独立上阵。

技艺、总纲和状态专精各五重；战斗功法各八重，在第1、3、5、7重习得四个法术，第2、4、6、8重选择对应强化。下表中的“可选”介绍强化方向，**互斥分支不能同时取得**。

七系总纲都包含克制强化与受克防护、共鸣取向以及连携起手／承接选择。金系起手强化追加收益，其余六系起手延长窗口；各系特色另列在本书下。连携内容为设计介绍，当前模块暂缓，具体合法配对以后补充。

## 金系  御剑与御兵

金系擅长把法术和武器结合起来：可以用剑法直接攻敌，也可以调动阵盘中的真实武器。核心状态是**反锋、锋痕、流血**，分别偏向受击反伤、武器追加伤害和持续失血。

### 《玄金百炼录》 技艺

学习炼器，提升制作器具的能力；具体器方另行获取。

以下为已有技艺设计方向，具体规则待对应专题完成。

- 器具炼制：可偏重武器、防具或法器的制作工艺，也有强化无属性器具的方向。
- 材料运用：节省材料、处理复杂材料，并提高拆解回收能力。
- 高阶工艺：提升特殊机制的制作表现，或降低复杂器具成本；具体权限与产出留生产专题。

### 《庚金真解》 总纲

强化金属性战斗及其与兵器的配合。

- 基础路线：可选【锐金】强化主动金伤，或【兵心】强化武器本体纯物理伤害。
- 共鸣取向：强化自身反锋的贡献，或目标锋痕、流血的贡献。
- 高阶配合：金系起手／承接提高连携追加收益；可走连续金法，或金法与武器同链。

### 《金煞藏锋经》 状态

强化反锋、锋痕和流血，选择防守反击或伤痕消耗方向。

- 反锋路线：强化反伤及触发后保留；高阶可延后触发反锋的敌方武器冷却。
- 锋痕路线：强化追加金伤与保留；高阶可用锋痕层数增强触发它的武器本体。
- 流血与转化：强化流血，满足条件时续层续时；另可选反锋生锋痕、锋痕生流血或流血养反锋。

## 木系  恢复与持续消耗

木系兼顾直接攻击和持久战。**生机**恢复气血，**毒蚀**持续损伤敌人，**缠绕**让目标更容易受到火、雷属性攻击的伤害。

### 《百兽驭灵录》 技艺

围绕灵兽捕捉、培养与协同作战展开。

以下为已有技艺设计方向，具体规则待对应专题完成。

- 识兽与捕捉：辨认性情、诱饵偏好，或提升诱饵效果。
- 培养取向：精养少数灵兽或群养多兽，偏重攻击型或防御、控制、增益型助手。
- 兽群配合：同种群兽、异种搭配、核心主兽或多兽协同；具体数量和培养规则留御兽专题。

### 《青木真解》 总纲

强化木属性战斗及其跨属性配合。

- 基础路线：可选【木锋】强化主动木伤，或【木息】强化木系回血与直接生成的灵盾。
- 共鸣取向：强化自身生机，或目标毒蚀、缠绕对共鸣的贡献。
- 高阶配合：连续木法强化伤害与治疗；另一分支在自身有生机、敌方有毒蚀或缠绕时同时强化攻疗。

### 《枯荣生灭经》 状态

强化生机、毒蚀和缠绕，发展恢复、耗血与状态联动。

- 生机路线：让首次回血更早、恢复更多；高阶可将合格治疗的溢出转为灵盾，起始满血的空治疗不转盾。
- 毒蚀路线：让首次毒伤更早、每跳伤害更高；高阶可周期性免去一次耗层。
- 缠绕路线：提高再次施加的层数及火雷增伤；高阶可周期性保留触发层数，另有三状态相互配合的分支。

## 水系  冰法与资源压制

水系既能正面攻击，也能削弱敌人的持续作战能力。**润脉**恢复自身灵力与体力，**枯脉**消耗敌方这两种资源，**寒霜**配合水攻冻结敌方阵盘。

### 《灵墨玄符录》 技艺

学习制符，提升符箓制作能力；具体符方另行获取。

以下为已有技艺设计方向，具体规则待对应专题完成。

- 基础制符：调配灵墨、减少符材损耗，在单张品质和批量制作之间选择。
- 材料与用途：发挥特殊材料性质；可偏攻击、召唤符，或控制、干扰、强化符。
- 高阶路线：精品符箓或长期量产，具体符方、材料费用与制作参数另定。

### 《玄水真解》 总纲

强化水属性战斗、共鸣及相关配合。

- 基础路线：可选【水锋】强化主动水伤，或【流息】强化水系灵力、体力恢复。
- 共鸣取向：强化自身润脉，或目标枯脉、寒霜对共鸣的贡献。
- 高阶配合：连续水法路线；或自身润脉与敌方枯脉／寒霜同时存在时强化水伤及资源恢复。

### 《寒脉流转经》 状态

强化润脉、枯脉和寒霜，选择续航、资源消耗或冻结方向。

- 润脉路线：提前首次恢复、提高灵力与体力恢复量；高阶可把合法剩余恢复量转为灵盾。
- 枯脉路线：提前首次资源削减并强化资源压制，围绕耗灵与耗体展开。
- 寒霜路线：强化初次施加、保留触发层数；可选择冻结后回补润脉等状态联动。

## 火系  爆发与攻坚

火系既有直接高伤，也能先铺状态再爆发。**附炎**为攻击追加火伤，**灼烧**持续造成火伤，**破甲**让合格火伤的一部分绕过护甲。

### 《赤炉丹经》 技艺

学习炼丹，提升丹药炼制能力。

以下为已有技艺设计方向，具体规则待对应专题完成。

- 控火与提炼：稳定成丹、减少药材损耗，提取药性并调和复杂材料。
- 成丹取向：提高品质或增加一炉产量；另有持续强化类丹药与快速炼制方向。
- 高阶路线：精品丹师或高产丹师，具体丹方、成本与产出规则另定。

### 《离火真解》 总纲

强化火属性攻击及其整体配合。

- 基础路线：可选【烈火】强化主动火伤；【蓄炎】强化附炎，并加强消耗附炎的主动火攻本体。
- 共鸣取向：强化自身附炎，或目标灼烧、破甲对共鸣的贡献。
- 高阶配合：连续火法强化后续火伤，或火法与武器／法器同链提高连携追加收益。

### 《炎煞流火经》 状态

强化附炎、灼烧和破甲，发展蓄火、持续伤害与绕甲能力。

- 附炎路线：提高附炎收益，选择消耗后保留或返还层数；可让合格附炎伤血带来灼烧。
- 灼烧路线：强化持续火伤，并可由有效灼烧积累返还附炎；高阶可进一步强化生命层伤害。
- 破甲路线：强化火伤绕甲能力；可在绕甲伤血时追加灼烧，或压制敌方护甲恢复。

## 土系  稳守与反制

土系擅长承受攻击后反制，也能用重击正面压制。**坚韧**抵抗暴击，**疲惫**让敌人更容易被暴击，**重伤**提高敌方资源消耗并削弱回血。

### 《坤元地脉录》 技艺

勘查地脉、寻找矿藏、采集和识别矿材。

以下为已有技艺设计方向，具体规则待对应专题完成。

- 寻脉辨矿：发现隐蔽矿点，了解矿材种类、品质与潜在产出。
- 采集取向：提高总产量或优质矿材收获，寻找稀有、伴生及带属性的材料。
- 深层开采：偏高品质核心矿材或多种伴生材料，具体矿点与收益另定。

### 《厚土真解》 总纲

强化土属性战斗及钝击武器等配合方向。

- 基础路线：可选【坤击】强化主动土伤，或【重兵】强化钝击武器本体纯物理伤害。
- 共鸣取向：强化自身坚韧，或目标疲惫、重伤对共鸣的贡献。
- 高阶配合：连续土法强化后续土伤，或土法与钝击武器同链提高连携追加收益。

### 《镇岳沉元经》 状态

强化坚韧、疲惫和重伤，发展抗暴、暴击配合与消耗压制。

- 坚韧路线：提高抗暴能力；高阶可在坚韧成功抵抗暴击后进一步减伤。
- 疲惫路线：提高目标被暴击的概率，配合主动武器重击。
- 重伤路线：强化费用增加与回血削减；可选【伤深养韧】，由重伤实际发挥作用积累自身坚韧。

### 《不动玄岳诀》 战斗

预先进入待发，等待合适时机抗暴、强化武器重击、干扰费用或发动反震。

| 习得重数 | 法术 | 内容简述 |
| --- | --- | --- |
| 第1重 | **守岳式** | 待发后抵消下一次合格暴击并减伤；可选更强减伤或获得坚韧。 |
| 第3重 | **破岳式** | 待发后使下一次合格武器攻击保证暴击，并额外强化钝击武器；可选强化暴击或附加重伤。 |
| 第5重 | **镇脉诀** | 待发后提高敌方下一次合格发动的资源费用，并施加重伤；资源不足可截断其发动。 |
| 第7重 | **玄岳反震** | 待发后实际护甲受损且受击结束仍存活时反击，伤害取决于本次实际损甲。 |

## 风系  闪避与追击

风系擅长减少自身受击、抓住敌人破绽，并调节双方发动节奏。**轻灵**提高闪避，**失衡**让敌人更容易被命中并提供武器追击机会，**驱散**拆除敌方增益。

### 《听风寻迹录》 技艺

探索、追踪、判断路线和发现隐藏线索。

以下为已有技艺设计方向，具体规则待对应专题完成。

- 发现线索：寻找捷径、活动痕迹、秘密入口和隐藏地点。
- 行进与避险：偏向更快旅行、减少不必要遭遇，或提前察觉危险。
- 探索取向：高效率赶路或深入追踪寻秘，具体地图效果与参数另定。

### 《御风真解》 总纲

强化风属性战斗及穿刺武器等配合方向。

- 基础路线：可选【风锋】强化主动风伤；【灵行】同时改善普通闪避、主动风攻命中和失衡追击发动率。
- 共鸣取向：强化自身轻灵，或目标失衡、驱散对共鸣的贡献。
- 高阶配合：连续风法强化后续风伤，或风法与穿刺武器同链提高连携追加收益。

### 《流风无相经》 状态

强化轻灵、失衡和驱散，发展闪避、追击与增益拆除。

- 轻灵路线：提高闪避收益；可选【乘风留影】，成功闪避后短时间提高命中。
- 失衡路线：提高命中与追击配合；可选【逐影连锋】强化武器追击，穿刺武器收益更突出。
- 驱散路线：增强拆除增益的能力；可选【风过无尘】，累计实际拆层后延后敌方物品冷却。

### 《青冥破空诀》 战斗

以风矢、风枪和破空攻击持续输出，重视命中与破绽利用。

| 习得重数 | 法术 | 内容简述 |
| --- | --- | --- |
| 第1重 | **风羽矢** | 带额外命中优势的基础风属性攻击；可选降低冷却与费用或提高伤害。 |
| 第3重 | **穿云枪** | 直接风属性攻击；可选增伤，或按目标预存失衡追加风伤。 |
| 第5重 | **裂空罡风** | 造成风伤并施加失衡；可选强化伤害或增加失衡。 |
| 第7重 | **青冥贯日** | 高威力风属性攻击；可选强化本体及盾后伤害，或利用已有失衡增伤并继续施加失衡。 |

### 《听风无影诀》 战斗

以预备闪避、武器追击、冷却推进或延后干预战斗节奏。

| 习得重数 | 法术 | 内容简述 |
| --- | --- | --- |
| 第1重 | **听风步** | 进入待发后保证闪避下一次合格可闪避攻击；可选获得轻灵或推进一件合格穿刺武器冷却。 |
| 第3重 | **追风式** | 待发后在武器原始攻击命中时获得一次追击机会，追击仍另判命中；可选强化伤害或命中。 |
| 第5重 | **回风引** | 推进己方一件合格物品的剩余冷却；可选加强推进，或改为延后敌方一件合格物品，同次不再推进己方。 |
| 第7重 | **清风涤尘** | 造成风伤并施加驱散以拆除敌方增益；可选加强驱散，或通过实际拆层推进己方冷却。 |

## 雷系  引雷与雷盾

雷系把积累转化为爆发和防御。**雷蕴**积累成雷盾，**雷印**由合格雷攻引发雷击，**连环**提供额外闪电；配合麻痹限制敌方发动。

### 《玄枢阵录》 技艺

学习阵纹、阵眼与布阵；阵法可以属于不同属性。

以下为已有技艺设计方向，具体规则待对应专题完成。

- 制作阵眼：提升质量与基础效果，或减少制作材料损耗。
- 阵式运行：改善入阵准备、抵抗冷却干预，强化阵眼、阵式或参与器具的配合。
- 高阶方向：阵法参与器具连携，或发动后推进参与器具冷却；具体阵法与技艺规则留专题。

### 《天雷真解》 总纲

强化雷属性战斗及雷盾、引雷等配合方向。

- 基础路线：可选【霆威】强化主动雷伤；【雷罡】强化新雷盾值、破盾麻痹时长与雷系防守反击。
- 共鸣取向：强化自身雷蕴及雷盾等效层数，或目标雷印、连环的共鸣贡献。
- 高阶配合：连续雷法强化后续雷伤，或雷法与雷属性武器／法器同链提高连携追加收益。

### 《雷池引霆经》 状态

强化雷蕴、雷印和连环，选择防护、引雷爆发或连续闪电路线。

- 雷蕴路线：强化新雷盾及盾相关配合，发展雷盾防守反击。
- 雷印路线：强化雷击；可选引雷后返印，或高阶【双霆引印】在条件满足时引出两记雷击。
- 连环路线：强化额外闪电；可选【雷击成环】，成功引雷后留下供后续攻击利用的连环。

### 《九霄霆光诀》 战斗

以雷光、霆枪、连霆和天雷正面攻敌，发挥雷击与连环收益。

| 习得重数 | 法术 | 内容简述 |
| --- | --- | --- |
| 第1重 | **雷光指** | 基础雷属性攻击；可选降低冷却与费用，或命中施加雷印。 |
| 第3重 | **玄霆枪** | 造成雷伤并施加雷印；可选增伤或增加雷印层数。 |
| 第5重 | **连霆术** | 造成雷伤并提供额外连环机会；条件满足时可两次连环，或引雷后再连环。 |
| 第7重 | **九霄雷落** | 高威力雷属性攻击；可选强化本体对鬼、妖、魔的特攻，或强化本次成功引发的雷印雷击。 |

### 《雷罡镇狱诀》 战斗

积累雷蕴、施加雷印，配合破盾反击和麻痹延长形成防守控制。

| 习得重数 | 法术 | 内容简述 |
| --- | --- | --- |
| 第1重 | **雷罡护体** | 主动获得雷蕴，积累成雷盾；可选更多雷蕴，或降低冷却与费用。 |
| 第3重 | **引雷印** | 造成雷伤并施加较多雷印，为后续引雷铺垫。 |
| 第5重 | **雷返式** | 待发后，任一雷盾层被攻击击破并成功麻痹攻击者时发动反击；可选增伤或命中施加连环。 |
| 第7重 | **雷狱锁** | 造成雷伤并施加雷印；若目标命中前已麻痹，则延长麻痹。 |
