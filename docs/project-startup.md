## 每次开始任务

1. 读取根目录AGENTS.md的置顶规则。
2. 读取PROJECT_PROGRESS.md顶部最新记录，检索任务相关关键词，补读相关记录，核实完成情况、限制、验证结果与未完成工作。
3. 根据下表打开本轮相关文档，不能将目录索引视为已读正文。若当前任务本身是更新设计，以用户本次新稿为依据，保留旧版并更新这里的当前入口。
4. 读取[README.md](../README.md)的运行与操作说明，查看实际相关代码／配置和Git工作区状态。文档中的“规划”“建议”“独立试算”不等于Godot已实现。
5. 向用户简短说明实际读到的状态与本次范围，随后执行已经授权的工作。明确的新要求直接推进；只有影响实现的未决规则才先问，不重复询问已确认事项。
