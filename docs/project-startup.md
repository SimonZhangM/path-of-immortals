# 新线程项目阅读入口

更新：2026-09-18。由项目根目录[AGENTS.md](../AGENTS.md)要求新线程在开始处理任务时主动读取。本文只维护阅读顺序和索引；实时开发状态以[PROJECT_PROGRESS.md](../PROJECT_PROGRESS.md)的最新记录及实际代码为准，不另复制一份容易过期的进度。

## 每次开始任务

1. 读取根目录AGENTS.md的置顶规则。
2. 读取PROJECT_PROGRESS.md顶部最新记录，检索任务相关关键词，补读相关记录，核实完成情况、限制、验证结果与未完成工作。
3. 根据下表打开本轮相关文档，不能将目录索引视为已读正文。若当前任务本身是更新设计，以用户本次新稿为依据，保留旧版并更新这里的当前入口。
4. 读取[README.md](../README.md)的运行与操作说明，查看实际相关代码／配置和Git工作区状态。文档中的“规划”“建议”“独立试算”不等于Godot已实现。
5. 向用户简短说明实际读到的状态与本次范围，随后执行已经授权的工作。明确的新要求直接推进；只有影响实现的未决规则才先问，不重复询问已确认事项。

## 交接与维护

- 在PROJECT_PROGRESS.md顶部追加日期、修改、已运行／未运行的验证、未完成项与下一步，保留旧记录。
- 设计升级时维护本索引、README当前入口及旧稿的新版指向；不要仅靠历史AGENTS长段落承担最新设计入口。
- 不把写文档当作实现授权，不把修改基础配置当作已完成地图／战斗运行期状态互通。
- 不自动提交或同步Git；保留用户和其他任务已有的本地修改。
- 若必需文档缺失，先在项目中检索新位置或替代入口；无法找到且影响任务时，说明缺少什么，不编造已读内容。

本机制通过项目AGENTS阅读约定生效，范围是绑定／进入本项目的任务。不是应用级新建线程回调，不会让未绑定本项目的聊天自动访问这个目录；新线程开始处理用户消息时执行阅读。未为验证而创建额外线程或定时任务。
