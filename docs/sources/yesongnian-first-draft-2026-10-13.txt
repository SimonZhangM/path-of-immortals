# 《修仙之路》NPC对话设计：叶松年（叶伯）

青石镇 · 药材铺｜序章对话第一版

叶松年与苏清禾的对话，我建议做出明显区别。

苏清禾对辰宇的关心是温柔、亲近，带着一些尚未说出口的感情；叶松年则是一个看着辰宇长大的长辈，也是教他识药、做事的师傅。

他的关心不必经常挂在嘴边，而应该体现在具体事情上：担心辰宇进山遇险，却还是教他如何辨别野外草药；舍不得这个年轻人离开药铺，却不会阻拦他踏上修仙之路。

这将是叶伯最有分量的人物特点。

## 一、人物基线

| 项目    | 设定                     |
| ----- | ---------------------- |
| 姓名    | 叶松年                    |
| 日常称呼  | 叶掌柜；主角称「叶伯」            |
| 身份    | 青石镇药材铺掌柜，苏清禾的外公        |
| 与主角关系 | 主角的识药师傅，也是熟悉亲近的长辈      |
| 性格    | 经验丰富、做事严谨、嘴上不饶人、心里很护短  |
| 语言特点  | 朴实、略带幽默，习惯用药材和生活经验讲道理  |
| 剧情职责  | 展现主角早期生活、引出药材异常、支持主角成长 |

我建议给叶伯一个比较鲜明的习惯：遇到拿不准的事情，他从不急于下结论。

这不仅体现一个老药师的专业态度，也会让后续生态异常的线索更可信。他不是一发现药性变化，就断言天地出了问题，而是先翻账簿、核对年份、比较产地。

## 二、欢迎词设计

### 首次进入交谈

叶松年：

辰宇，来得正好。

案上新收了几包草药，我正想叫你帮忙核一核。

（看了看他）

……先不急。桌上还有温水，喝两口再说。

药柜跑不了，你小子也用不着事事赶着做完。🙂

这段欢迎词既体现药铺里的熟悉关系，又带一点叶伯式的关心。

### 普通回访欢迎词库

在剧情没有新进展时，随机或按顺序选取简短欢迎词，不触发新的正式聊天。

| 编号  | 叶松年的欢迎词                       |
| --- | ----------------------------- |
| W01 | “辰宇，来了？药柜我刚盘过，今日倒不用你帮忙。歇会儿吧。” |
| W02 | “今儿回来得早啊。山路还顺当吧？没遇上什么麻烦？”     |
| W03 | “来，帮我瞧瞧这包药。……呵，先别紧张，不是考你。”    |
| W04 | “你来得巧，水刚烧开。倒一杯喝了再忙。”          |
| W05 | “辰宇，最近认药的本事长进不少。就是做事还欠几分耐心。”  |

完成的正式对话不会重新播放；但日常欢迎词可以轻度轮换，避免NPC每次都说完全一样的话。

### 特殊欢迎词

| 触发条件           | 欢迎内容                                   |
| -------------- | -------------------------------------- |
| 主角气血较低         | “怎么弄得这般狼狈？先坐下。哪儿伤着了？别急着说没事。”           |
| 完成青石河湾受伤修士救助事件 | “听说你在河湾救了个受伤的修士？做得不错。可下次遇上危险，先掂量掂量自己。” |
| 即将加入青岚宗        | “听说仙门那边有消息了？来，坐下。你这回怕是有不少话想说。”         |
| 入宗后首次回镇        | “辰宇？回来了！先让我瞧瞧……嗯，精神倒不错。山上的日子还过得惯吗？”    |

特殊欢迎词只在满足相应条件时使用，不会把尚未发生的事情提前说出来。

## 三、初始三个话题

药铺近况

经营、药材变化、主线伏笔

请教药理

辨药、采药、前期成长

闲聊

家常、清禾、往日生活

三个话题分别承担不同作用：

\*\*左侧「药铺近况」\*\*是剧情线，最初安排3段完整交谈，以药材异常为线索，后续随河湾探索进度增加新内容。

\*\*中间「请教药理」\*\*是人物成长线，最初安排3段，以叶伯教授辰宇知识为主，不重复游戏操作教程。

\*\*右侧「闲聊」\*\*是生活关系线，首次安排2段连续闲聊，完成后进入回访闲聊库，每次有效回访新增一段。

三个话题全部独立记录进度，阶段结束后按钮恢复原名，再点击只显示历史聊天记录。以后剧情发生变化，才显示新的可聊内容。

## 四、话题一：「药铺近况」

剧情线 · 首期3段｜重点：叶伯从药材和旧账中察觉异常

### 第1段：这批草药不太一样

叶松年：

辰宇，把柜台边上那两包草药拿来。

来，你自己看看，能瞧出什么不同？

张辰宇：

嗯……都是同一种草药。

不过这一包的叶片薄些，颜色也浅一点。

叶松年：

不错，眼力倒是长进了。

（将两包草药摊开放好）

这两批药收自同一个地方，采收的时令也差不多。我原以为是晾晒出了差错，可细问下来，炮制的法子并没有变。

张辰宇：

会不会是采药的人摘得太早了？

叶松年：

有可能。所以我才要查。

叶松年：

做咱们这行的，最忌讳凭一点迹象就下定论。

药材不对，先查来处，再查采收、晾晒的过程。一处一处弄明白，心里才有底。

张辰宇：

那我帮您把这几批药的账重新对一遍？

叶松年：

嗯，这回倒不用我催了。

那就交给你。可别光顾着看药价，采收的地方和日子也得记清楚。

对话结束，中间没有强制插入玩家选项。左侧按钮更新为「对照旧账」。

### 第2段：对照旧账

张辰宇：

叶伯，我把前几年的收药账翻了一遍。

青石河湾那边送来的几批药，最近采收的数量似乎少了些。

叶松年：

哦？你再说仔细些。

张辰宇：

往年这个时节，一趟能采回不少。可今年好几批都比往年少。

叶松年：

（拿起账簿，翻了几页）

你看这里。

靠近溪流的几处采药地，变化倒是明显。可镇外山坡上的药材，暂时还看不出同样的情形。

张辰宇：

难道是河湾那边出了什么问题？

叶松年：

眼下还不能这么说。

河水有涨有落，草木也有丰年歉年。只凭几本账，还看不出个所以然。

张辰宇：

那您这些天一直翻旧账，就是为了查这个？

叶松年：

嗯。

这些年我经手的药材也算不少了。有些东西，看着只差一点，日积月累却能差出许多。

叶松年：

罢了，先把账记好。

若真有变化，总还会留下别的迹象。

按钮更新为「河湾药材」。

### 第3段：河湾药材

叶松年：

辰宇，最近是不是还打算去青石河湾？

张辰宇：

嗯，正准备再去看看。

叶松年：

那倒正好。

你若路过临溪的采药地，顺便看看水势，还有那些常见草药的长势。

张辰宇：

要不要采几株回来比对？

叶松年：

若是顺手，可以带些回来。

不过记住，采自哪处、何时采的，都要记清楚。光拿回来一把草，连出处都不知道，可查不出什么来。

张辰宇：

好，我记住了。

叶松年：

还有一件事。

张辰宇：

什么？

叶松年：

（放下手中的账簿，看了他一眼）

山里最近不大太平。你小子可别为了几株药，往那些险路上钻。

张辰宇：

放心吧，叶伯，我有分寸。

叶松年：

哼，你这话，我听了多少年了。

叶松年：

去吧。若真遇上棘手的事，回来再商量。别总想着一个人逞能。

阶段完成：记录线索「河湾药材变化」，但不强制生成新任务。左侧按钮恢复为「药铺近况」。

### 后续剧情：河湾观察结果

这一段不立即解锁，玩家实际取得相关信息后才会出现。

触发条件： 玩家在青石河湾完成了相应的水势或草木观察事件。

张辰宇：

叶伯，我这次去河湾，发现有些地方的溪水似乎比以前浅了。

岸边露出来的石头也多了些。

叶松年：

是吗？

我记得前些年，那几处水势还算丰沛。

叶松年：

不过溪水涨落本是寻常事。你只看过这一回，暂时还说不准。

张辰宇：

那我以后多留意几次？

叶松年：

嗯。日子、地点都记下来，往后再作比较。

叶松年：

有些变化，不是看一眼就能明白的。

完成后归档。只有后续实际取得新的河湾调查证据，才再解锁新阶段。

这一条剧情我建议保持克制。叶伯的作用是帮助玩家发现和记录问题，而不是过早解释问题背后的真正原因。

## 五、话题二：「请教药理」

成长线 · 首期3段｜重点：师徒交流，不照搬教程说明

### 第1段：辨药的本事

叶松年：

来得正好，考你个简单的。

若是两株药草长得相似，你会怎么辨？

张辰宇：

先看叶形、颜色，再闻闻气味。

叶松年：

嗯，还有呢？

张辰宇：

看看根茎和断面？若是晒干的，还得留意有没有受潮。

叶松年：

不错。总算没白教。

不过你要记住，药材的模样、气味、产地和采收时令，都得合在一起判断。

叶松年：

碰见不认识的草药，可别往嘴里尝。有些东西，认错一次，就够你吃苦头了。

张辰宇：

叶伯，您这些话都说过好多遍了。

叶松年：

那就再听一遍。

等哪天你真能独自分清药材，我自然懒得唠叨。

按钮更新为「采来的药怎么处理？」

### 第2段：药材不是采回来就能用

张辰宇：

叶伯，山里采来的草药，是不是越新鲜越好？

叶松年：

那可不一定。

有的药宜鲜用，有的须晒干，有的还得去掉根皮或杂质，才能妥当入药。

叶松年：

同一味药，处理得好不好，有时候比多放半钱还要紧。

张辰宇：

那若是在山里遇见有人受伤，来不及带回铺子呢？

叶松年：

你跟我学过的那些简易药粉，还记得怎么调吧？

张辰宇：

记得。先辨清药材，再按以前学过的法子研磨调配。

叶松年：

嗯。寻常的小伤，若手边有合用的药材，倒能先应急。

可碰上重伤，不能只凭一包药粉就以为万事大吉。该送医馆时，还得赶紧送。

张辰宇：

知道了。

叶松年：

记住，识药是本事，知道什么时候不能乱用药，也是本事。

按钮更新为「药材与丹药有何不同？」

### 第3段：药材与丹药

张辰宇：

叶伯，既然草药能治病，为什么修士还要花工夫炼丹？

叶松年：

因为草药和丹药虽有联系，门道却不尽相同。

寻常药散，看重辨药和调配。丹药还要讲究丹方、火候、药性如何相合。

叶松年：

你看着人家一炉丹药炼成，觉得神奇。可背后废了多少材料、费了多少心思，外人哪知道。

张辰宇：

听您这么说，炼丹倒比识药还难。

叶松年：

各有各的难处。

不识药性，炼丹便容易出错；只懂药材，却不明白丹火变化，也成不了丹师。

张辰宇：

那我以后是不是也该学学炼丹？

叶松年：

有机会自然可以学。

叶松年：

不过，别见着新本事就想一下子全学会。先把眼前的事做好，往后走得才稳当。

张辰宇：

叶伯，我怎么觉得您是在说我？

叶松年：

（笑了笑）

你听得出来，就说明还不算太笨。😄

阶段完成。按钮恢复「请教药理」。本阶段不直接奖励法术或功法，避免与炼丹房和功法系统重复。

这一条我特意让叶伯更多地教辰宇如何思考，而不是像教程NPC一样逐条介绍游戏机制。

## 六、话题三：「闲聊」

日常线 · 首次连续2段，之后逐次解锁新的闲聊内容

### 首次闲聊01：小时候的药笺

叶松年：

辰宇，你还记不记得，小时候我第一次让你抄药名？

张辰宇：

怎么不记得？抄了一下午，手都酸了。

叶松年：

那时你写的字啊，歪歪扭扭，十个里有三个我认不出来。

张辰宇：

我记得您那时候还夸过我。

叶松年：

夸你？

哦，想起来了。

我说的是“这孩子脑子倒灵光，就是手比脑子还着急”。

张辰宇：

……原来那也算夸奖啊。

叶松年：

哈哈，如今总算写得像样了。

叶松年：

时间过得真快。一晃眼，你都长这么大了。

右侧按钮更新为「说起清禾」。

### 首次闲聊02：说起清禾

叶松年：

说起来，清禾那丫头最近又在医馆忙得忘了时辰。

张辰宇：

她总是这样，劝别人休息，轮到自己就什么都顾不上。

叶松年：

你倒是了解她。

张辰宇：

从小认识，哪能不知道。

叶松年：

也是。

你们两个小时候，一个闲不住，一个总爱跟着操心，如今倒也没怎么变。

张辰宇：

清禾姐现在可是正经大夫了，我还在药铺里打杂呢。

叶松年：

呵，打杂怎么了？

人这一辈子，谁不是从一点一滴学起的。

叶松年：

清禾有她想走的路，你也有你的。别总拿自己同别人比较。

叶松年：

不过你若路过医馆，替我提醒她一句，忙归忙，饭总得按时吃。

张辰宇：

好，我记着。

首次闲聊完成。按钮恢复「闲聊」，之后按回访条件进入闲聊库。

## 七、叶伯的日常回访闲聊库

我建议先安排6段。第一次完成前面的两段闲聊后，每次满足回访条件，就可以新增一段。

它们主要展现青石镇的日常生活、叶伯年轻时的经历，以及他对辰宇逐渐成长的感受。

### 回访01：多留的一碗热粥

叶松年：

辰宇，吃过饭没有？

张辰宇：

还没呢，打算忙完再吃。

叶松年：

就知道你会这么说。

灶上还有粥，自己去盛一碗。

张辰宇：

叶伯，您这是特意给我留的？

叶松年：

特意什么？不过是早上煮多了。

张辰宇：

那您怎么知道我还没吃？

叶松年：

（继续整理药材）

你小子一忙起来就忘了饭点，我还不知道？

快去，凉了可不好吃。

### 回访02：那杆旧药秤

张辰宇：

叶伯，这杆秤用了多少年了？怎么还不换新的？

叶松年：

怎么，嫌它旧了？

张辰宇：

倒也不是。就是瞧着磨损得厉害。

叶松年：

这杆秤啊，比你年纪还大。

以前铺子生意冷清，买不起什么好家什。后来有了新秤，我也舍不得把它扔了。

张辰宇：

原来您也会舍不得旧东西。

叶松年：

人用惯了的东西，总有些念想。

不过如今它量得不如从前准，我也只拿来放着看看，不用来称药了。

叶松年：

留个念想可以，可不能误了正事。

### 回访03：镇上的熟人

叶松年：

方才镇西的老周又来买药了。

张辰宇：

他不是前几日才来过吗？

叶松年：

药倒是没用完。

说是路过铺子，进来坐坐，顺便打听镇上有什么新鲜事。

张辰宇：

原来药铺还能当茶馆使。

叶松年：

（笑）

这小镇啊，住久了，街坊邻里都是熟人。

有时候人家来一趟，不光是为了买东西，也就是想找个人说说话。

张辰宇：

那您岂不是每天都要陪人闲聊？

叶松年：

也好。能有人来坐坐，说明这日子还算安稳。

### 回访04：药铺的灯

张辰宇：

叶伯，您每天都这么早开门，晚上又关得晚，不累吗？

叶松年：

年轻时候不觉得，如今确实有些力不从心了。

张辰宇：

那往后我多帮您照看铺子。

叶松年：

你有这份心就好。

叶松年：

不过啊，开药铺这么多年，每到傍晚，看见街上人家一盏盏亮起灯来，心里总觉得踏实。

张辰宇：

这有什么特别的？

叶松年：

等你以后走过的地方多了，就明白了。

叶松年：

人有地方可回，有熟人在等，便是件好事。

这一段可以稍微有些情感分量，但不用刻意煽情。

### 回访05：年轻时的叶伯

张辰宇：

叶伯，您年轻时候，也总待在青石镇吗？

叶松年：

那倒没有。

年轻时，我也跟着商队走过不少地方。

张辰宇：

真的？您怎么从来没怎么说过？

叶松年：

有什么好说的。

那时候初出远门，见什么都觉得新鲜，吃过的亏也不少。

张辰宇：

您还吃过亏？

叶松年：

你以为呢？

我年轻时可不比你稳重多少。

叶松年：

只是后来走得多了，才知道世上的事不是光凭一股劲就能办成的。

张辰宇：

那有机会，您再给我讲讲外面的事。

叶松年：

行。等哪日得闲，给你说说。

但你小子听故事归听故事，千万别以为外面的路都像故事里那么好走。

### 回访06：长大了

叶松年：

辰宇，过来。

张辰宇：

怎么了，叶伯？

叶松年：

站直些，让我瞧瞧。

张辰宇：

……您这是做什么？

叶松年：

呵，好像又长高了点。

张辰宇：

您上个月也是这么说的。

叶松年：

是吗？

叶松年：

人上了年纪，日子一天天过得快，倒常常忘了年轻人长得有多快。

（拍了拍他的肩膀）

叶松年：

往后你有自己的打算，不必事事都来问我。

不过遇到拿不准的事，也别忘了回来商量。

张辰宇：

知道了，叶伯。

叶松年：

嗯。这回听着倒像是真的记住了。🙂

## 八、后续主线解锁的专属对话

这里先补充两段重要剧情，作为后续扩展的基础。

### 剧情一：即将前往青岚宗

解锁条件：主角即将离开青石镇、进入青岚宗相关剧情。

叶松年：

辰宇，仙门那边的事，我听说了。

想好了？

张辰宇：

嗯，叶伯，我想去试试。

叶松年：

那就去。

张辰宇：

可是药铺这边……

叶松年：

药铺还有我呢。你操的哪门子心？

叶松年：

当初教你识药，是盼着你有一门安身的本事，可不是要把你一辈子拴在这几排药柜旁边。

张辰宇：

叶伯……

叶松年：

到了仙门，规矩自然和镇上不同。

凡事多看、多学，莫要逞一时意气。

叶松年：

记着，修为高低是一回事，怎么做人是另一回事。学了本事，也别把从前学过的道理丢了。

张辰宇：

我记下了。

叶松年：

行了，去准备吧。

……得空的时候，回来看看。

这一段我不建议让叶伯特别伤感。

他的不舍藏在最后一句就够了。他真正希望的是辰宇能够走得更远。

### 剧情二：入宗后首次返回青石镇

解锁条件：加入青岚宗后首次回镇，到药铺与叶伯交谈。

叶松年：

辰宇？

哟，咱们的小修士回来了。

张辰宇：

叶伯，您就别拿我说笑了。

叶松年：

哈哈，出去了一趟，倒学会谦虚了。

叶松年：

怎么样？山上吃住可还习惯？

张辰宇：

还好，就是每日修炼的事情比以前多了不少。

叶松年：

那就好。

修行之事我不算懂，可既然进了宗门，就得认真学。

张辰宇：

您身体还好吧？药铺最近忙不忙？

叶松年：

都好，都好。

你不用每回回来都惦记这些。

叶松年：

不过既然回来了，今日就别急着赶路。坐下来，给我讲讲山上的见闻。

这段能让主角第一次以青岚宗弟子的身份回到药铺，却发现叶伯对他的态度并没有太大变化。

在叶伯眼里，他依然是那个从小跟着自己识药的辰宇。

## 九、对话触发和存档规则

我建议沿用苏清禾的机制，叶伯不需要另做一套对话系统。

| 对话内容    | 触发规则       | 完成后      |
| ------- | ---------- | -------- |
| 首次欢迎    | 第一次打开交谈    | 永久标记已读   |
| 日常欢迎    | 普通回访       | 简短轮换     |
| 药铺近况1～3 | 按顺序推进      | 全部归档     |
| 请教药理1～3 | 按顺序推进      | 全部归档     |
| 首次闲聊1～2 | 按顺序推进      | 全部归档     |
| 回访闲聊1～6 | 每次有效回访解锁一段 | 完成一段归档一段 |
| 河湾调查后续  | 实际获得相关探索信息 | 新剧情归档    |
| 入宗前、入宗后 | 主线条件解锁     | 各播放一次    |

### 按钮状态示意

| 初始按钮 | 阶段一完成后    | 阶段二完成后     | 全部完成后 |
| ---- | --------- | ---------- | ----- |
| 药铺近况 | 对照旧账      | 河湾药材       | 药铺近况  |

| 闲聊   | 说起清禾      | 闲聊         | 闲聊    |

全部完成后，按钮恢复原名，点击查看历史记录，而不是再次播放。

普通回访闲聊库的每一段可以在游戏时间跨过一天后解锁；如果出现重要主线对话，则优先展示主线内容，不消耗普通闲聊库中的下一段。

还有一个细节建议：如果玩家在某段聊天进行到一半时离开，下一次回来应该能够继续未完成的内容。 不应该因为中途退出就重头播放，更不应该直接视作完成。

## 十、我建议额外预留一处人物关联

叶伯和苏清禾各自有医药相关的线索，但两人的观察角度应当不同：

- 叶松年：从采收数量、药材形态、年份记录判断变化。
- 苏清禾：从病患恢复速度、用药效果、医案中发现异常。
- 张辰宇：通过实际采药和野外探索获得新的观察证据。

玩家如果同时完成叶伯的「药铺近况」和苏清禾的「医馆近况」，后续可以解锁一段将这些信息关联起来的对话。

这不需要现在就直接给出答案。

例如叶伯可以说：

> “清禾那边的医案，加上我这些年的收药记录，倒确实有些值得琢磨的地方。不过两件事是否有关，眼下还说不准。”

这样既体现NPC之间的联系，也避免主角尚未取得证据时，剧情就直接推断出了世界真相。

## 十一、叶松年的对话设计小结

| 首次欢迎词  | 1组        |
| ------ | --------- |
| 普通回访欢迎 | 5条        |
| 特殊欢迎词  | 4类        |
| 药铺近况   | 首期3段＋条件后续 |
| 请教药理   | 3段        |
| 首次闲聊   | 2段        |
| 回访闲聊   | 6段        |
| 主线专属对话 | 2段        |

我觉得这一版可以作为叶松年的序章及入宗初期对话第一版。

他与苏清禾应当带给玩家不同的感受：

苏清禾是会惦记着辰宇有没有吃饭、有没有受伤的青梅竹马；叶松年则是会一边数落辰宇、一边教他本事，最后目送他走向更广阔天地的长辈。

叶伯最重要的情感，不是舍不得辰宇走，而是明明舍不得，却仍然希望他能走得更远。

这一点我建议贯穿他今后所有阶段的对话。
