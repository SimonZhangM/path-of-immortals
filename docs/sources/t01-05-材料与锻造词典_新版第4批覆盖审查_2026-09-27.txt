# `t01-05-材料与锻造词典`
## 第4批｜生产动作收束、全类别升品与整体审校

## 一、先覆盖旧规则：现阶段只保留“制作”和“升品”

### 本次已确认的变更

> **取消归胚。已经制作完成的物品，不能还原成器胚、原部件或原材料。**
>
> **取消以“先归胚、再铸造”为原理的改铸／重铸。**
>
> **保留铸造／制作与升品。丹药、符箓、暗器同样可以升品。**

“改铸”和“重铸”此前用词有所交替，Codex整理时应一并处理，不能删掉一个名称，却用另一个名称保留同一套功能。

六类物品现在统一为：

| 物品类别 | 制作方式 | 升品 | 归胚／还原 | 改铸／重铸 |
|---|---|---:|---:|---:|
| 武器 | 器方＋四槽框架 | 支持 | 不开放 | 不开放 |
| 防具 | 器方＋四槽框架 | 支持 | 不开放 | 不开放 |
| 法器 | 器方＋四槽框架 | 支持 | 不开放 | 不开放 |
| 丹药 | 丹方＋药材 | **支持** | 不开放 | 不开放 |
| 符箓 | 符方＋载体／符媒／灵材 | **支持** | 不开放 | 不开放 |
| 暗器 | 器方＋主体／功能材料 | **支持** | 不开放 | 不开放 |

这里的“支持”表示**该类别存在升品机制**，不表示任意一件物品都自动拥有升到最高品级的完整路线。具体能升到哪里，仍由对应配方或谱系阶段表定义。

**仙品是品级，不另列为第七种物品类别。**它仍不进入普通打造与升品链；修复、解封、成长可以保留专项接口，但不能借“特殊重塑”的名称重新开放本次取消的还原、重铸。

这次也没有改变物品的出售、交易、任务提交等资格，不应把“不可还原”扩大解释成“不可处理”。

## 二、装备生命周期由循环收束成前进路线

原来的主结构：

> 制作 → 使用 → 归胚 → 换蓝图／材料 → 再制作

不再作为现行玩法。

新的主结构是：

> **材料或已有器胚 → 制作 → 成品 → 使用 → 升品 → 更高品级成品。**

这里需要保留三个区别。

**第一，原本就存在的器胚仍然有效。**天然掉落器胚、人工加工器胚、遗迹提供的器胚，仍然可以作为制作输入。撤销的是“把成品还原成器胚”，不是删除器胚本身。

**第二，升品不需要先生成一个可拿走的器胚。**可以在内部提升该器具的器胚规格，再形成更高品级结果，但玩家不会得到一个可自由转去制作其他装备的裸胚。

**第三，直接制作高品装备与培养旧装备仍可并存。**拥有合格高阶胚材、器方与生产资格时，可以按对应条目直接制作；升品则让已有装备继续使用，不强迫所有人从凡品逐级造起。

因此，材料来源表中的“旧器归胚产出”应停用，但“天然器胚”“人工器胚”不能一起删掉。

## 三、升品不能成为改铸的另一个名称

这是这轮最需要补清楚的边界。

你已经确认“不还原、不重铸”，但尚未逐项规定：**升品时能否更换已有本源、功能和器纹。**

如果继续沿用旧第2批里的：

> 升品时可以换本源、换功能路线、换蓝图，只要兼容即可。

那么实际上仍然保留了大部分改铸能力，只是把按钮改名为“升品”。这不符合本次简化方向。

### 我建议的常规升品规则

> **保留原器具身份和已经选择的方向；提高品级，按新阶段更新规格，并让玩家选择新开放的槽位。**

这条是**本轮审校建议**，不是冒充你已逐项确认的决定。

按这个建议，升品继承可以这样处理：

| 内容 | 常规升品建议 |
|---|---|
| 器方／谱系身份 | 保留，不借升品换成另一张蓝图 |
| 器型与基础攻击类型 | 保留 |
| 防具形态与甲型 | 保留，不借升品把盾变成身甲、重甲变成灵甲 |
| 品级 | 提高到该升品条目规定的阶段 |
| 器胚基础数值 | 按目标阶段的对应规格更新 |
| 已选本源 | 保留属性方向及材料特征身份 |
| 已选功能／谱系路线 | 保留路线，按目标阶段定义成长 |
| 已选器纹 | 保留方向，是否有进阶版本按明确映射处理 |
| 新开放槽位 | 允许进行新的定制选择 |
| 套装成员身份 | 同一成员升品不因品级变化而丢失身份 |

例如上品雷鸣弓已经选择A路线，升到灵品：

> 仍然是雷鸣弓A路线；更新基础规格；按定义获得该路线的灵品版本；新开放器纹选择。

不自动变成：

> 借升品改成逐风弓，或者免费把A路线换成B路线。

另一点也要注意：**提高品级不应把所有旧效果原样保留，再额外叠一份新效果。**旧版本应由目标阶段版本替换或按规定成长，避免升几次就叠出多份相同被动。

如果旧配置没有合法的高阶承接版本，应提示该升品路线尚未配置完整，不能悄悄删除玩家原能力，或擅自替换成另一种。

## 四、丹药、符箓、暗器升品：成品可以成为输入，但不能先拆回材料

此前第3批中：

> “消耗品不进行个体升品”“不是拿凡品丹药升级成良品丹药”

这些表述现在都应撤销。

新的方向是：

> **已有低品级消耗品＋明确的升品材料／条件 → 对应高品级消耗品。**

但它们不需要为了升品而引入装备的四槽，也不需要逐颗丹药维护一套复杂的持久个体档案。

### 三类可以共用一个升品框架

| 类别 | 升品输入 | 升品结果 |
|---|---|---|
| 丹药 | 指定低品丹药＋合格药材或其他规定材料 | 同一药品路线的高品丹药 |
| 符箓 | 指定低品符箓＋合格符媒、灵材等 | 对应高品符箓 |
| 暗器 | 指定低品暗器＋合格强化材料等 | 对应高品暗器 |

这里“同一条路线”不要求名字一字不变，但应有明确的升级关联。它不能泛化成：

> 任意旧丹药都能升级成任意新丹药。

### 输入数量与输出数量必须分别定义

升品不自动等于一换一，也不自动等于几件合一。

配方需要明确：

> 消耗多少件旧成品、多少辅助材料，以及基础产出多少件新成品。

例如，玩家库存有10张低品符，只选择其中4张参与某次升品：

> 未参与的6张仍留在库存；参与的4张按升品条目处理；最终高品符的数量读取该条目的产出规则。

这只是库存处理例子，不是在确认“四张低品换几张高品”。

### 已经消耗掉的东西不能升品

已服用的丹药、已释放的符箓、已消耗的暗器，不再是可用库存。

角色身上还剩几秒的药效，也不等于库存里仍有一颗可以升品的丹药。

因此，**升品对象是实际存在、未被消耗的成品数量，不是正在运行的效果。**

消耗品品级仍由对应的制作／升品阶段定义，不因为追加了一块高阶晶石，就自动变成同阶符箓。

## 五、升品的基础输入输出不能全部推给总项目T05

前三批反复强调“成功率、耗时、返还交给T05”，方向正确，但职责需要再精确一点。

`t01-05`至少必须定义：

> **升什么、允许从哪一级升到哪一级、基础需要哪些输入、正常完成时得到什么。**

总项目T05再负责：

> 谁能执行、用什么设施、怎样执行、耗时、成功失败，以及技艺如何修正消耗和产出。

所以，“一份升品配方基础消耗几颗旧丹、基础产出几颗新丹”不能永远没有归属。它属于具体升品条目的输入输出，T05可以再根据确认的技艺规则修正。

反过来，取消归胚也**不等于已经决定制作失败时一律不返材**。

这两件事应分开：

> **已完成成品的主动拆回材料：当前不开放。**  
> **制作或升品过程中失败、取消时怎样处理已投入材料：仍按T05流程规则。**

这样就不会为了删掉归胚，把正常生产失败处理也误删了。

## 六、四槽和品级规则仍然保留，但要补三处说明

### 1. “下品不开放打造”只直接约束已经确认的装备四槽体系

武器、防具、法器仍遵守：

| 品级 | 开放的装备定制槽 |
|---|---|
| 下品 | 不开放常规打造 |
| 凡品 | 器胚 |
| 良品 | 器胚＋本源 |
| 上品 | 器胚＋本源＋功能 |
| 灵品 | 器胚＋本源＋功能*＋器纹 |
| 玄品 | 器胚＋本源＋功能＋器纹* |
| 仙品 | 不开放常规打造 |

**不能把这张表直接套到丹药、符箓和暗器上。**它们具体从哪些品级可以制作、怎样升品，由各自配方阶段确定。

已有下品装备也仍可以作为升品起点，但新路径应是：

> 下品成品＋凡品阶段所需输入 → 凡品成品。

不再经过归胚。能否执行仍要有相应升品条目，不能仅因持有旧装备就自动学会全部制作知识。

### 2. 星号不是额外槽，也不能被读成高品级反而失去能力

灵品`功能*`、玄品`器纹*`仍表示一个槽内的进阶能力范围，而不是多个槽。

但玄品一栏没有给功能再写星号，**不应该由Codex直接解释为升玄后功能退回普通版**。目标阶段采用哪份功能规格，应由阶段表明确，不能靠星号有无推导降级。

具体进阶权限仍需对照03；本轮不补一套未经讨论的高级能力清单。

### 3. 本源里的轻量状态特征要区分“新增”与“增量”

比如：

> “雷印施加量＋1”

如果这件器具本来没有任何合格雷印施加行为，它是否有用，取决于效果定义。

不能悄悄把“施加量＋1”解释成“每次攻击新施加1层雷印”。

本源可以有你认可的轻量材料特征，但必须明确它是：

> **直接提供一次简单状态施加，还是修改已有施加行为。**

这样良品没有功能槽时，也不会出现描述看似有效、实际却找不到作用对象的本源。

## 七、基础法器有一个缺口：没有功能槽，不应意味着没有用途

之前一方面说：

> 凡品只有器胚；功能槽到上品才开放。

另一方面又把法器的主要用途都放进功能槽。照字面整理，可能会出现：

> 凡品戒指只有材阶和尺寸，什么都不会做。

这里应补清楚：

> **基础用途由器方／基础器具类型确定；器胚决定该阶段的基础规格；功能槽负责额外的主要定制机制。**

例如一件简单恢复法器，其基本行为可以是：

> 按基础轮转恢复某种资源。

这不要求先开放上品功能槽。上品以后，玩家才进一步定制“恢复后产生什么联动”“满足什么条件强化恢复”等机制。

同样，武器的普通攻击、防具的基础护甲，也不需要先装功能件才存在。

但这不是给蓝图免费塞复杂能力的许可。**基础动作、谱系固有特色、本源、功能、器纹的实际收益，仍然共同接受03的品级审核。**

---

## 八、两类器方逻辑可以保留，但路线映射要补一个防重复规则

现在这部分是05比较成熟的地方：

> **通用器方：合格功能件提供自身定义的功能。**  
> **谱系器方：合格功能件映射为蓝图预设路线。**

需要再写清楚：

**谱系映射是采用路线结果，不是“材料原功能＋路线功能”同时获得。**

例如晶核甲、晶核乙都映射为雷鸣弓A路线：

> 在同一品级、其他条件相同的情况下，它们提供的主功能应当都是A路线。

不能因为甲原本在通用弓里还有一种能力，就在雷鸣弓里额外保留那份能力。否则“多种材料映射到少数路线”的简化会失效。

本源槽仍可以保留材料轻量差异；这与功能槽的路线收束不冲突。

另外，一份材料如果同时匹配两条路线，必须明确让玩家选择，或由器方给出确定规则；不能看后台表格哪行在前就随机般地产生不同结果。

**蓝图不带品级，也不等于获得蓝图后自动开放所有品级。**它可以包含多个阶段，但当前可用阶段还要检查已配置内容、材料与技艺资格。

## 九、材料替换仍有价值，但必须分清“相容”与“最终属性”

这轮不需要重做材料Family、材阶和相性筛选，不过应补一条：

> **材料自己的元素、材料能够用于哪些配方，以及成品最终是什么元素，不是同一个字段。**

例如一种带火性的鹿角，如果只用作合格的结构性胚材：

> 不必自动把最终器具变成火属性。

如果它被选入开放本性的本源槽：

> 才按该槽定义解析元素及轻量特征。

如果使用固定雷系的谱系器方：

> 则必须先通过该器方明确的相容检查，不能靠“材料是火、蓝图是雷”临时猜一个火雷结果。

也不能把战斗中的元素克制环，直接复制成一套生产禁配表。生产相容性是配方要求，未声明的限制不自动存在。

此前火铃鹿角、苍角鹿角等例子中，苍角鹿的具体元素并没有正式做完，**示例不能被整理成一只已经定为水系的怪物或一份已定掉落材料**。

## 十、复合部件建议退出当前首版，避免又把四槽变复杂

第3批后半段，我主动补了：

> 一件特殊部件同时占本源与功能槽。

这个方向以后可以做，但它不是你本轮明确要求的内容，也不是05现在闭合所必需的。

结合你一直希望降低复杂度，以及这次再次删除归胚／重铸，**我建议把复合部件从当前常规方案移到“未采用候选”，首版先不做。**

普通情况下：

> 一个槽位使用一份明确的输入方案；同一份实际材料不能免费重复满足两个独立消费要求。

一种材料可以有多个用途，但表示“它可供选择的用途多”，不表示“一份就可以同时充当全部材料”。

这样玩家无需再理解跨槽占用、半启用、低品级只读取一半复合部件等特殊逻辑。

这项是审校建议，Codex应保留其建议状态，不冒充已经得到你确认。

## 十一、不可还原后，制作预览和升品预览变得更重要

取消还原会减少操作种类，但也意味着**制作前选错材料的代价更难撤回**。因此不能只删按钮，还需要把结果说明做清楚。

我建议制作确认页至少显示：

> 成品品级、蓝图／谱系、本源元素、轻量材料特征、功能结果或路线、器纹，以及实际消耗。

升品确认页再增加：

> 哪些保留、哪些数值改变、哪个槽位新开放、目标阶段是否改变某项已有能力。

玩家在**正式提交前**应能自由切换材料、比较结果、取消预览。预览取消不是“成品还原”，不应该消耗资源。

正式制作已经开始后的取消、失败处理，则仍引用T05。

这里不需要复杂评分系统。**让玩家准确看见“这次会得到什么、会失去什么”就已经很有帮助。**

同时，材料一旦投入成品，记录它用于追溯和计算结果，不等于它仍以另一件可使用物品存在于库存。升级时也不能把同一个旧器具同时当成“保留目标”和“另一份可重复消耗材料”。

## 十二、给Codex的回填清单：哪些旧内容必须覆盖

这份第4批应当作为**覆盖性修订**，不是新增一个与旧规则并行的章节。

| 位置或主题 | 必须进行的修改 |
|---|---|
| 第1批材料来源 | 删除“归胚产出”作为现行来源；保留天然、人工、采集、遗迹等来源 |
| 第1批下品后续价值 | 改为“已有下品成品可按升品条目进入凡品”，不再先归胚 |
| 第2批生产动作 | 常规动作收束为制作与升品，停用归胚、改铸、重铸 |
| 第2批寒霜剑转雷剑案例 | 移到历史，不再作为现阶段合法生产流程 |
| 第2批跨蓝图改铸、逐槽换路线 | 移到历史；升品继承采用单独的明确规则 |
| 第2批器胚保留、材料返还说明 | 区分“升品继承规格”与“库存还原”，不再输出可取走的旧器胚 |
| 第3批开头类别矩阵 | 六类均支持升品机制；所有类别当前均不开放归胚／重铸 |
| 第3批丹药、符箓、暗器章节 | 撤销“消耗品不能升品”，加入成品数量作为升品输入的规则 |
| 第3批仙品接口 | 保留专项修复／解封／成长，不以特殊重塑恢复普通重铸能力 |
| 字段、案例和审查项 | 同步停用还原产出、跨谱系重铸和普通归胚返材字段／检查项 |

旧内容可以完整保留在历史原文页，但现行表必须有明确的有效性标识。

尤其不要把“归胚返还率”改成0%，然后继续保留归胚操作。**当前是整个操作不开放，不是已经定为零返还。**

对于本轮提出的升品锁定旧路线、复合部件暂不采用等建议，Codex应另标“建议”，不能与用户本次直接确认的取消规则混为一类。

## 十三、修订后的反向检查

下表是逻辑审查要求，不代表已经运行过游戏测试。

| 场景 | 应得到的处理 |
|---|---|
| 良品寒霜剑尝试还原剑胚 | 当前不提供该操作 |
| 良品寒霜剑尝试同品改成雷系剑 | 不因保留旧改铸字段而放行 |
| 已有下品武器升到凡品 | 按升品条目处理，不产生中间可取走器胚 |
| 上品弓升到灵品 | 更新目标阶段规格，并按规则开放器纹选择 |
| 法器升品 | 可以有相应路线，但不能先还原出核心 |
| 低品丹药升品 | 实际旧丹药作为输入，按配方生成高品结果 |
| 一叠符箓只升其中一部分 | 未参与数量保持，参与数量与新产出分别记账 |
| 已发动消耗的符箓尝试升品 | 没有实际库存，不能作为对象 |
| 谱系功能件映射到A路线 | 采用A路线，不额外叠材料原功能 |
| 同套成员升品 | 不因品级改变丢失同一成员身份 |
| 取消尚未提交的制作预览 | 不消耗材料，不涉及成品还原 |
| 高阶晶石投入低阶消耗品 | 不能绕过具体升品条目自动抬高品级 |

## 最终判断：不重出三批，但必须合并成一套新正文

**不需要你再接收一遍完整第1～3批。**大部分材料、四槽、蓝图、谱系映射和器具规格仍然有效，重复输出反而容易继续产生措辞差异。

但Codex的最终整理不能是：

> 三批旧正文原封不动＋最后附一页“归胚取消”。

应该是：

> **第1～3批主体＋第4批覆盖修订 → 一份无冲突的现行05；旧版另作历史。**

当前最值得进一步确认的一条，是我在第三节提出的**常规升品保留旧蓝图、旧本源和旧功能方向，只新增阶段开放选择**。它能防止升品重新长成改铸系统。消耗品每次消耗几件、产出几件，则可以逐配方确定，不必现在编一个全局比例。

经过这次调整，05的重点更清楚了：

> **制作前有定制；制作后能成长；暂时不拆回、不跨路线重造。**

这样保住了你最看重的打造可玩性和低品装备价值，也确实减少了一整组玩家操作、材料返还与数据继承问题。
