# 七系功法复盘与待确认清单 · 2026-09-23

依据金、木、水、火、土、风、雷七份正式第一版、装备／功法核心架构、21状态规则和本轮用户指示整理。七系合计35本功法、56个可上阵法术。本文是评审与后续定案入口；除用户本轮明确修改的灵障30%外，以下建议均未自动采纳，不覆盖七系已确认规则。

## 1. 本轮已确认：灵障基础吸收率30%

普通防护资源仍命名为【灵障】。设进入灵障阶段的伤害为D、当前灵障值为S，未受特定法器修正时：

- 实际吸收A＝min（S，D×30%）。
- 灵障扣除A，剩余D−A继续后续防御结算。
- D＝20、S至少为6时，灵障吸收6，剩14；S＝4时只吸收4，剩16。
- 【雷盾】基础吸收率仍为60%；润脉／枯脉基础转移率、追击基础比例等其他50%规则不变。
- 特定法器可以提高灵障吸收率，既有最高100%的边界不变；修正合并方式仍未定。

灵障与雷盾同时存在时的先后仍待确认。建议按先雷盾、再灵障、最后护甲／气血逐级处理，每一层读取进入本层的剩余伤害。若采纳且两个盾值均足够，100点伤害先被雷盾吸收60，再由灵障吸收剩余40的30%即12，最终剩28，合计吸收72%，不是把60%和30%直接加成90%。这是候选结算顺序的算术例子，不是已确认的双盾公式；混合伤害还须沿用雷盾吸收额度优先分配给法术部分的既有方向。

## 2. 总体判断与评审范围

七系身份和内容数量已经足够进入首轮数值化：金靠兵器与伤痕，木靠生命／侵蚀／跨属性铺垫，水靠资源与冻结，火靠蓄势／灼烧／攻甲，土靠暴击攻防／重伤／反震，风靠闪避／追击／驱散／CD，雷靠蓄盾／引雷／连环／麻痹。不建议增加第三套Debuff或扩充基础法术数量。

仍有两类不同工作：一是定义“发生什么”的共用规则，二是填写“多强、多快、多贵”的数值。前者未定时直接批量填56个法术，容易在事件规则改变后重算。先完成本表高优先级边界，再从炼气期的小样本定标，最后展开高阶内容。

## 3. 优先处理的共用问题

### 3.1 土、风第四重可能覆盖第二重的投入

现行规则明确：土系坚韧／疲惫第二重提升至1.5%每层，第四重直接设为2%；风系轻灵／失衡同样如此。风系驱散第二重额外驱散概率10%，第四重最终20%，不是30%。

若每重可独立选分支、没有同路线前置要求，第二重选A、第四重选B，可以同时保有A的二重收益和B的最终强度；二、四重都选B，则早先的B投入在第四重后不再增加任何收益。问题不是“上限必须提高”，而是同向专修和混合选择的收益失衡。

**建议方案，待确认：**把四重改成增量贡献：概率每层再增加0.5个百分点，驱散额外概率再增加10个百分点。这样同向专修仍为2%／20%，未选对应二重时四重为1.5%／10%。备选方案是四重要求同路线二重，但会收紧混搭自由度。尚未修改土、风正式稿的既定数值。

### 3.2 功法、法术究竟如何占用构筑容量

已确认“学会的法术可独立上阵，不要求原功法同时上阵”。但总纲／状态专精的分支是学会即永久生效、需要选为当前修炼功法，还是需要功法本体占格，没有统一到35本书；可同时生效几本、同一法术能否重复摆放、每本／每术占几格也未定。

这会决定多灵根角色能否同时获得大量常驻被动，不能只用法术伤害平衡。还需一张“功法重数—境界解锁—分支选择”表，以及战外改选／洗点规则。后期法术是否占更多阵位，应作为容量成本与资源成本一起比较。

建议逐本标明“修炼资格、常驻效果、需要上阵的本体、解锁的独立法术”，再决定同时生效数量。对休闲玩家，建议允许在安全地点调整已解锁分支，具体成本后定。

### 3.3 手动、自动、预备式需要一份统一说明

核心架构仍写“主角法术到期不自动释放”，七系稿却已有独立上阵法术、自动／手动CD干预和自动待发机制；对话中也讨论过手自动可选。应统一最后口径，不能由每本书各自推断。

建议普通攻击／治疗法术允许选择自动或手动；预备式就绪后武装为“待发”，满足事件条件才发动。仍须决定：预备式在哪一刻支付灵力、待发期间是否继续轮转、事件发生但资源不足时保留待发还是重开CD、手动是否表示先由玩家进入待发。被麻痹跳过的机会是否扣资源也在同一表中确定。

### 3.4 武器型法术和追加伤害的结算

“法术来源＋穿刺型＋水属性”已经是确定的标签设计，不等于武器攻击。现有架构允许同包接受法术及穿刺两套系数，但尚未确定系数如何合并，也未定义属性克制、共鸣、暴击、护盾、破甲、护甲之间的完整顺序。

需要先确定：双标签系数如何组合；追击50%取第一次攻击哪个阶段的纯武器数值、是否重新经过防御／暴击；最高武器如何取值；混合攻击中的物理／属性包如何使用盾额度；0伤害命中是否触发命中型效果。

建议用少量例子确认整条流程：普通武器、武器附火伤、纯法术、武器型法术、追击、持续伤害、反击各一例。每个伤害包明确来源、甲型伤害标签、属性、是否主动、是否可暴击和可触发的事件。保留已确认的共鸣在攻击发出前快照，以及寒霜命中后先施加再触发；不要把寒霜特例自动推广到雷印等所有状态。

### 3.5 多来源灵障和破盾收益

除双盾先后外，金系【回锋剑幕／返剑】要求“剑幕被击破”，【兵甲化元／返锋】能消耗剩余防护，木／水功法又能把恢复溢出转灵障。若全部汇入一个普通灵障池，“谁的剑幕破了”与“能返还哪一笔盾”就没有自然答案。

建议对玩家显示一个灵障总值，内部保留来源额度，并给破盾反击设置明确的生效期与消耗条件；或者把返剑改为“授予一次下次灵障归零时触发的预备效果”。两种方案任选其一，不默认一次总池归零触发所有历史护盾来源。容量、生成量、来源退出后的处理与战后清除统一记录。

### 3.6 同时满足多个预备式的优先级

| 场景 | 尚缺的边界 | 建议方向，尚未采纳 |
| --- | --- | --- |
| 听风步与轻灵同时可闪避 | 谁先判，是否重复消耗 | 听风步用于普通可闪避攻击时优先处理；成功后不再判轻灵，只产生一次成功闪避事件 |
| 破岳式对上守岳式／坚韧 | 必暴与必抗、普通抗暴谁先 | 先确定命中与拟暴击，再由守岳式／坚韧处理；守岳式成功后不再消耗坚韧。必暴是否绕过普通抗暴必须明说 |
| 追风式就绪且目标有失衡 | 一次命中会有一次还是两次追击 | 默认同一原始武器攻击最多一次二次追击；追风式优先时不读／不耗失衡。允许多追击应由高阶效果明确给出 |
| 同一来源的多份待发效果 | 全部消费还是依次保留 | 单次事件按固定顺序消费一份，避免所有防御预备同时被一次弱攻击耗完 |
| 己方被致死且同时满足反击条件 | 反击能否在死亡后继续 | 先执行已授权的免死判定；其余依统一致死规则处理，不为每一种反击临时开例外 |

风系构筑描述中的“听风步闪避→追风式反击”应读作战术配合；追风式的正式触发仍是下一次己方武器命中，不能凭该箭头变成闪避后立即反击。

### 3.7 控制、CD推进和事件连锁

寒霜会暂停CD与就绪发动，麻痹让CD照转、到点跳轮，这些已经确定。但二者同时存在时，寒霜暂停的CD不会在这段时间自然到点，可能让麻痹失去本来要截断的机会。需要明确每种控制自己的持续时间仍走全局战斗时间，以及风系直接推进CD是否可在冻结期间把物品推进到就绪、是否触发麻痹跳轮。

还需统一：麻痹期间已就绪的手动物品／预备式能否发动；延后CD是否能打退已就绪物品；回风引能否作用自己；两件CD法器互相推进能否在同一时刻无限互触。建议先保留“延迟可超过原CD”的已确认战术空间，并用具体来源资格、资源成本和单次事件触发次数限制即时自循环。

高级寒霜一次触发多层时，建议在施加完成后固定本次可触发层数，每层最多访问一次；成功留霜不使该层在同次攻击内再次被处理，否则“清理全部”与“概率不耗层”可能形成重复结算。连续冻结按叠加还是刷新、Boss控制抗性、长控制的收益上限仍需决定，不能用单层0.5秒就认定整体控制短。

### 3.8 状态事件、计数和恢复需要统一的小边界

| 项目 | 需确认的规则与建议 |
| --- | --- |
| 状态施加与触发顺序 | 同次攻击新增雷印是否能立即引雷；雷击成环新增连环能否被同一主动攻击消费；混合火雷攻击缠绕扣一次还是两次；各派生包不得重复读取共鸣 |
| 连霆术 | 第二次闪电读取首次消费后的层数还是原始层数；两次是否均计入连霆不绝的每第5次；留印等返还是否按两次雷击分别结算。建议依实际效果逐次结算，不用视觉次数代替事件次数 |
| 计次数能力 | 凝霜每5次、连霆不绝每5次、蚀骨难消／盘根不绝每2次的计数归属、归零／换目标／离阵／战后是否重置。建议绑定能力持有者并明确战后清零；其他场景另定 |
| 持续时钟 | 流血5秒／灼烧10秒首跳、末跳、重施是否改变下一跳；重伤2秒开始是否立刻减层；驱散连续新增是否不断推迟那1秒。建议重施保留已经排定的下一次结算，避免越施加越不生效 |
| 重伤零成本 | 纯耗体武器是否被凭空增加灵力成本、免费恢复物品是否也要付资源。建议只增加行为本来需要的资源种类，避免0灵力角色所有行动锁死；这是建议，不是已确认豁免 |
| 无层数的驱散目标 | 持续药效／毒性免疫没有整数层，“驱散1层”是消除整个效果还是减少剩余跳数。建议一个独立效果实例算一个驱散单位，来源与剩余药效一起清理 |
| 恢复与转盾／反噬 | 重伤、满血溢出、木系生生不息、水系盈流成护、土系伤势反噬的先后和实际收益。建议被重伤阻止的治疗不再算溢出转盾；转盾按最终合法溢出，防止同一份治疗既被阻止又被转盾 |
| 无资源与归零事件 | 枯脉对不存在的资源是否转扣、枯极生寒是否只在正数降至0时触发、回澜自身仅有一项资源时如何分配；归墟对无资源敌人的规则已定，不需重问 |
| 舍入 | 资源1位小数、状态整数已定；0.25资源、按伤害转层、按比例保留状态如何取整仍未定。建议资源最终写回时统一舍入，整数层按每个效果明确取整；避免每一步反复舍入 |

### 雷系两项构筑风险

1. **纯雷法修被迫带武器。**现雷击暂按最高武器攻击×1.5，没有武器时无定义。即使带武器，最快最低成本的雷攻可能反复借用最慢重武器的高攻击，须一起衡量雷印产速和阵位成本。建议为无武器法修提供境界／法术基准，或者明确雷击取武器／法术基准中的合法值，具体选择待确认，不先替换1.5倍。
2. **内鸣与自动转盾的目标相冲。**按10层立即转盾，稳定可见雷蕴通常只有0～9层，【内鸣】可读取的常驻层数天然较少。可保留这种差异而提高内鸣单层贡献，或给雷盾转换共鸣另设明确效果；不能在通用共鸣中擅自把雷盾值当雷蕴层数。满盾时是否继续消耗雷蕴也会影响结果。

建议下一步先建立同境界的普通攻击法术标尺，再给每系选择一个攻击术、一个代表性机制术及少量配套物品。统一角色资源、阵位与投入，比较击败时间、剩余资源、状态覆盖率、实际有效控制时间和手动操作次数；随后补高阶专精、全套56术及七系混搭。

必须包含的组合验证：多武器＋御兵／百兵；毒蚀／流血／灼烧的同层与同产速对比；水系高频冻结＋风系CD推进；麻痹＋寒霜的控制竞争；雷系高频攻击＋高攻慢武器；多种溢出转盾＋重伤；驱散对持续药效；破甲高层对高频回甲。上述是将来的测试范围，本轮没有足够正式数值，也没有运行平衡模拟。

例如毒蚀初始N层逐跳减1、无追加时总基础损血为N(N+1)/2，而流血／灼烧使用固定持续时间和重施刷新。层数相同并不代表成本或总收益相同；留层、即时跳伤和持续补层还会改变结果。应以获得这些层数所花的时间、资源和阵位比较。
