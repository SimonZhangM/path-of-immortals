# 《修仙之路》NPC对话设计：钱万顺（钱掌柜）

青石镇 · 普通商铺｜序章至第一章对话第一版

钱万顺这个人物，我建议比叶伯、苏清禾更有江湖气息。

他的特点是：生意上精明，待人圆滑，话多但不说废话；看似什么都能拿来做买卖，却又不是见利忘义的人。

尤其你安排了主角在青石河湾救他的剧情，这可以形成很鲜明的关系变化：

普通商客 → 救命恩人 → 值得信赖的年轻朋友 → 第一章天河商域的重要引路人。

他不能一开始就对辰宇过分热情，也不应在获救以后天天把感谢挂在嘴边。真正的感激，应当体现为态度变化和关键时候愿意帮忙。

## 一、人物基础设定

| 项目     | 设定                   |
| ------ | -------------------- |
| 姓名     | 钱万顺                  |
| 称呼     | 钱掌柜                  |
| 出身     | 天河商域                 |
| 现居     | 青石镇，经营普通商铺           |
| 年龄     | 建议38～45岁，具体可暂不固定     |
| 性格     | 精明圆滑、健谈风趣、善于察言观色、讲信用 |
| 语言特点   | 市井商人口吻，爱用做生意的比喻，偶尔自嘲 |
| 与主角关系  | 最初是普通顾客关系，获救后逐渐建立信任  |
| 长期剧情作用 | 商路情报、货物来源、天河商域的人脉引荐  |

### 商盟背景：建议暂定「通远商盟」

我建议钱万顺曾在天河商域的通远商盟做过几年行商，后来独自在青石镇经营商铺，但仍与商盟中的旧友有联系。

这里需要注意他的地位。

他不应该是什么隐藏的大商盟盟主，也没有必要拥有能够调动整个商域的权力。

更合适的是：

- 熟悉天河商域部分商路和货物流转方式。
- 与通远商盟一位管事有多年交情。
- 知道如何查询货单、商号与材料来源。
- 能为辰宇提供可靠的接洽机会，但无法直接查明调查真相。

这样第一章主角受青岚宗委派，前往天河商域调查材料来源时，钱掌柜的人脉才会真正产生价值。

「通远商盟」目前作为建议名称，暂不视作世界观正式定稿。

## 二、三个固定话题

| 位置 | 初始按钮 | 主要作用                 |
| -- | ---- | -------------------- |
| 左  | 铺中买卖 | 镇上生意、商路状况、商队遇险伏笔     |
| 中  | 天河见闻 | 钱掌柜来历、商盟人脉、第一章材料调查伏笔 |
| 右  | 闲聊   | 市井趣事、行商经历、人物性格和关系变化  |

左、中两条剧情线都安排多段聊天，右侧首次连续两段闲聊，后续建立独立回访库。

三条话题完成后按钮恢复原名，点击查看聊天历史；新剧情阶段解锁后，再增加新内容。

## 三、欢迎词体系

### 1. 救援前：首次欢迎

钱万顺：

哟，来客人了！

小兄弟，随便看看。刀剑、护具、干粮杂货，店里都备着些。

我这铺子虽不大，东西可都是仔细挑过的。

买不买都不要紧，先瞧瞧嘛。😄

此阶段是正常商家态度。称呼「小兄弟」，不表现特别的私人关系。

### 2. 救援前：普通回访欢迎词

| 编号  | 钱万顺                             |
| --- | ------------------------------- |
| W01 | “小兄弟，又来瞧货了？今日可有想找的东西？”          |
| W02 | “进来看看！这几日刚整理了货架，找东西比以前方便多了。”    |
| W03 | “买东西不怕多比较，怕的是买回去才发现不合用。你慢慢挑。”   |
| W04 | “这天儿不错，出门的人多，铺子里也热闹些。小兄弟，随便看看。” |

### 3. 青石河湾救援后：第一次再见

这是钱万顺最重要的一次欢迎词变化。

钱万顺：

哎哟！这不是辰宇小兄弟吗！

快进来，快进来！

（绕过柜台迎上前）

那日在河湾，要不是你出手，我这条命怕是都得交代在山道上。

张辰宇： 钱掌柜，您平安回来就好。

钱万顺： 唉，做买卖这么多年，什么亏都吃过，差点把命赔进去，这还是头一遭。

说起来，那日还没来得及好好谢你。

往后到了我这儿，别那么见外。有事尽管开口，能帮的，我钱万顺绝不推托。

这段感谢建议只播放一次，完成后归入特殊剧情记录。

不直接发放灵石或永久折扣，避免提前改变已确定的经济与交易规则。

### 5. 第一章：即将前往天河商域

钱万顺：

辰宇兄弟，听说你要去天河商域？

这可真是巧了，那地方我熟！

不瞒你说，我年轻时在那边跑过几年商路，至今还有几个老朋友。

你若是有正经事要办，咱们坐下来慢慢说，说不定我还真能帮上点忙。

### 一个需要协调的剧情细节

此前序章有过「救出商人后，青石商铺开放」的设定。

现在你希望救援前也能和钱掌柜正常交谈，两者需要在落地前统一。

我更推荐：商铺初期就能进行基础交易，救援后恢复稳定经营，并解锁钱掌柜的感谢及后续特殊对话。

也可以保留旧设，让救援前的钱掌柜只在临时摊位出现。以下对话设计先按“救援前可以接触钱掌柜”来编排。

## 四、话题一：「铺中买卖」

商铺与商路剧情｜救援前2段＋救援后1段

### 第1段：做买卖，也得看合不合用

救援前 · 初始按钮「铺中买卖」

钱万顺：

小兄弟，我看你方才朝那边的兵器架瞧了好几眼。

怎么，想添件趁手的家伙？

张辰宇： 随便看看。钱掌柜，您这儿的东西，都是从外地进的吗？

钱万顺：

那倒不是。

青石镇周边也有不少好东西。只是有些货得从外头运来，来回一趟，车马、人工，处处都要花钱。

钱万顺：

就说这剑吧，价高的不见得就适合你，便宜的也未必不好使。

做买卖嘛，我总得把话说明白。卖出去是一次生意，往后还肯来，才算没白做。😄

张辰宇： 钱掌柜倒是想得长远。

钱万顺： 哈哈，做小本生意的，不敢不想远些。

按钮更新：「最近生意如何？」

### 第2段：最近生意如何？

钱万顺：

说起来，近来的生意倒还过得去，就是有几批货送得慢了。

张辰宇： 商队出了什么事？

钱万顺：

听过路的车夫说，河湾一带的山道最近不大安生，野兽露面的次数多了些。

倒还没听说出了什么大乱子，可赶车的人都变得小心了。

张辰宇： 您平日也走那条商道？

钱万顺：

走啊，怎么不走？

过些日子还得去接一趟货。

张辰宇： 那您可得当心。

钱万顺：

放心，我钱万顺跑了这么多年商路，知道什么叫小心驶得万年船。

（顿了顿）

不过话说回来，路上的事谁能算得准呢？能结伴就结伴，天色不好就早些落脚。

钱万顺：

货晚几天送到，顶多赔几句好话。要是人回不来了，挣再多也没处花。

救援前内容阶段完成，按钮恢复「铺中买卖」。日后救援完成后，该话题解锁新段落。

这里的钱万顺已经有商人的生存经验，也知道风险，却无法预料自己会在青石河湾遇险。

这样救援事件发生时，不会显得他是明知危险还毫无准备地往里闯。

### 第3段：那趟险些回不来的买卖

条件：已完成青石河湾商人救援事件。

钱万顺：

辰宇兄弟，说起那趟河湾的生意，我如今想起来还有些后怕。

那日事情来得太急，我只顾着护住人和货，转眼便叫野兽堵住了去路。

张辰宇： 那以后还走那条商道吗？

钱万顺：

走总还是要走的。

不过吃一堑长一智。往后能跟熟悉的商队同行，就不再独自冒险了。

钱万顺：

那趟货虽有些折损，好在人没事，账还能慢慢算。

张辰宇： 钱掌柜能这么想就好。

钱万顺：

哈哈，你倒反过来宽慰我了。

钱万顺：

说真的，以前我总觉得，做买卖最怕亏钱。

这回才知道，钱亏了还能挣，命可没有第二条。

张辰宇： 平安就好。

钱万顺：

可不是嘛。

（拍了拍辰宇的肩）

这份人情，我记着呢。

阶段完成后按钮再次恢复「铺中买卖」，以后可以随着商路变化补充新段落。

## 五、话题二：「天河见闻」

世界观与第一章伏笔｜初始2段、救援后1段、第一章2段

这一条我建议慢慢展开。

前期只是商人的故乡见闻，中期介绍他与商盟的联系，直到主角真正接到调查任务，钱掌柜的人脉才变成实用的剧情资源。

### 第1段：天河商域是个什么地方？

救援前 · 初始按钮「天河见闻」

张辰宇：

钱掌柜，听您的口音，似乎不是青石镇本地人？

钱万顺：

哟，小兄弟耳朵倒挺灵。

不错，我老家在天河商域。

张辰宇： 天河商域？我听说那里商贾云集，什么东西都能买到。

钱万顺：

哈哈，哪有那么夸张！

不过那边确实热闹，城镇之间商路相通，货船车队来来往往，做什么买卖的都有。

钱万顺：

在天河商域，别的东西不敢说，商铺、货栈和各家的招牌，你沿街走上一整日，都未必看得完。

张辰宇： 那您怎么跑到青石镇来了？

钱万顺：

地方大，生意大，竞争也大呀。

青石镇虽小，南来北往的行人不少，附近又有青岚宗。生意不算特别红火，但日子踏实。

钱万顺：

再说了，走过那么多地方，总得找个能安安稳稳睡觉的地方，不是？

按钮更新：「天河的商路」

### 第2段：天河的商路

这一段我建议让玩家第一次接触“货物来源可以追查，但并不简单”的概念。

钱万顺：

小兄弟，既然对天河的商路有兴趣，我给你讲件有意思的事。

你知道吗？一块矿石，从矿场出来到买家手里，有时能转过好几家商号。

张辰宇： 转这么多手，价钱岂不是涨了不少？

钱万顺：

那可不一定。

有人负责开采，有人负责收货，有人负责运送，还有人专门替大商号验货。

每过一道手，就多一道账。

张辰宇： 那要想知道一件东西最早从哪里来，岂不是很麻烦？

钱万顺：

嘿，这就问到门道上了。

若是正经买卖，收货有货单，转运有交接记录，有些还留着商号的货签。

可若中途换了包装、混了货，甚至转过几次私人买卖，再想追到最初来处，就没那么容易了。

张辰宇： 您连这些都熟悉？

钱万顺：

熟悉是熟悉，却也不敢说样样都查得清。

我年轻时在商盟里跑过几年货，最怕的就是账面上一切对得上，到了地方却发现货不对板。

钱万顺：

做生意最怕什么？

张辰宇： 亏钱？

钱万顺：

哈哈，亏钱当然怕！

可若连一件货从哪儿来、经谁的手都弄不清，那才是真正叫人睡不安稳的买卖。

初始阶段完成。按钮恢复「天河见闻」。记录普通见闻，不生成第一章的材料调查任务。

这段未来可以成为一个很自然的伏笔。

玩家初次听时，只觉得是商人的经验之谈；到了第一章调查材料来源时，才会想到钱掌柜懂得商路和账目。

### 第3段：通远商盟的老朋友

条件：商人救援完成，并已建立较熟悉的关系。

钱万顺：

辰宇兄弟，上回你不是问过天河商域的事吗？

说起来，那边我还有些老朋友。

张辰宇： 您以前不是在商盟做过事？

钱万顺：

不错，通远商盟。

那会儿我跟着商队东奔西跑，验货、押货、对账，什么活儿都做过些。

如今虽然离开了商盟，可有些旧友还在。

张辰宇： 商盟里也有您这样出来自己开铺子的？

钱万顺：

多了去了！

有的人愿意做大买卖，有的人想自己当掌柜。说到底，各人有各人的活法。

钱万顺：

其中有位周管事，跟我是多年的交情，办事很稳妥。

若是以后你有机会去天河商域，真遇上货物或商路方面的难事，我倒能替你引见一下。

张辰宇： 那就先谢过钱掌柜了。

钱万顺：

嗨，你我之间，还客气这些做什么？

不过话说在前头，熟人归熟人，该守的商盟规矩还是得守。

钱万顺：

我能替你敲开门，门里头的事，还得靠你自己去办。

记录「钱万顺与通远商盟的周管事有旧交」，作为将来的可用人脉线索。本阶段完成，按钮恢复「天河见闻」。

### 第4段：调查材料的来路

第一章 · 主角正式接受青岚宗材料来源调查任务后解锁。

钱万顺：

辰宇兄弟，听说你要去天河商域办差？

张辰宇： 嗯，宗门让我调查几种材料的来源。可线索不多，我正想来向您请教。

钱万顺：

哦？查材料来源？

那倒是问对人了。

钱万顺：

不过这事说难不难，说容易也不容易。你先告诉我，手上有什么凭据？

张辰宇： 有些材料的名称、特征，还有几条经手商号的线索。

钱万顺：

那就有得查。

不过你记住，最后把货卖出去的人，未必就是最初收货的人。

钱万顺：

尤其材料转过几次手以后，光凭铺子里的货账，很可能只查到上一家。

张辰宇： 那该从哪里入手？

钱万顺：

先查经手的商号，再对货签和转运记录。能找到最早的收货凭据，才好继续追。

钱万顺：

若有人故意遮掩来路，那就是另一回事了。

（钱万顺收起了平时的笑容。）

钱万顺：

辰宇，你这趟既然是宗门差事，想必有自己的缘由。

我不多打听。只是提醒你一句，查账容易得罪人，别凭一两句传闻便当面指认谁。

张辰宇： 我明白，会先查清楚。

钱万顺：

嗯，这才稳当。

按钮更新：「商盟中有谁能帮忙？」

### 第5段：商盟中有谁能帮忙？

张辰宇：

钱掌柜，您之前提过的那位周管事，还在通远商盟吗？

钱万顺：

在。前些日子还跟我通过消息。

他如今负责商号的一部分货账与往来记录，做事一板一眼。

张辰宇： 能否请您替我引见？

钱万顺：

这个自然可以。

钱万顺：

我写封信，你带去给他。不过能查到哪一步，还得看那批材料经过了哪些商号。

（钱万顺取出纸笔。）

钱万顺：

我会在信里说明，你是青岚宗派去办事的，也是我信得过的朋友。

张辰宇： 多谢钱掌柜。这次又麻烦您了。

钱万顺：

辰宇啊，这话可就见外了。

当日在河湾，你帮我的时候，可没先问我能给你什么好处。

钱万顺：

如今我能帮你一点，自然不会推辞。

（封好书信，递给辰宇。）

钱万顺：

只是千万记住，到了那边，凡事多留个心眼。

大商域里热闹归热闹，人多，事也杂。

张辰宇： 我会小心的。

钱万顺：

好。

等你回来，记得进铺子喝盏茶。到时再跟我说说，天河如今变成什么模样了。

此段可在第一章正式发放一封引荐信或设置引荐标记；具体采用哪种，由届时的任务与关键物品系统确定。

### 第一章这条线索的价值

我建议让钱万顺承担三个职责，但不超出他的能力。

| 他能做的          | 他不能做的       |
| ------------- | ----------- |
| 告诉主角该如何追查货物来源 | 直接给出幕后真相    |
| 提供通远商盟的人脉     | 随意调取整个商域的账簿 |
| 帮主角取得初次接洽的机会  | 保证所有商人都愿意配合 |
| 提醒商业交易中的风险    | 代替主角完成调查    |

这样钱万顺会是第一章真正有用的老朋友，而主角仍然需要自己完成调查。

## 六、话题三：「闲聊」

首次连续2段，之后每次有效回访解锁一段新的闲聊

钱万顺的闲聊，我建议和叶伯、苏清禾明显不同。

叶伯喜欢讲做人的道理，苏清禾更多谈生活与彼此的近况；钱掌柜则会谈生意趣事、旅途见闻，有时说笑，有时不经意间流露出丰富的人生经验。

### 首次闲聊01：钱万顺这个名字

钱万顺：

小兄弟，你瞧我这名字，钱万顺。

听着是不是挺吉利？

张辰宇： 是挺吉利。那您做生意岂不是一路都顺顺当当？

钱万顺：

哈哈，那可差远了！

我爹当年给我起这个名字，就是盼着我平平安安、万事顺遂。

结果呢？做买卖这些年，该赔的钱一文没少赔，该吃的苦也一样没落下。

张辰宇： 那这名字不是白起了？

钱万顺：

哪能这么说？

买卖有赚有赔，人有起有落。到头来还能坐在这儿，跟小兄弟说说笑笑，不也算是一种顺当？

钱万顺：

人呐，有时候得学会知足。😄

按钮更新：「开铺子的门道」。

### 首次闲聊02：开铺子的门道

钱万顺：

小兄弟，我考你一件事。

你说，开铺子最要紧的是什么？

张辰宇： 货物齐全？价钱公道？

钱万顺：

都对，可还差一样。

张辰宇： 什么？

钱万顺：

得认得人。

有的人一进门，就知道要买什么；有的人转悠半天，其实只是想找人打听几句话。

钱万顺：

你若只盯着人家的钱袋子，生意做不长久。

张辰宇： 那您是不是一眼就能看出客人想要什么？

钱万顺：

哈哈，那倒不敢说。

不过你第一次进铺子的时候，我就看出来了。

张辰宇： 看出什么？

钱万顺：

你不像是来随便花钱的。看货的时候眼睛挺亮，摸摸这个，又瞧瞧那个，心里八成还盘算着怎么搭配才划算。

张辰宇： 您连这个也看得出来？

钱万顺：

做了这么多年买卖，总得有点眼力不是？

首次闲聊完成，按钮恢复「闲聊」。以后通过回访库逐步解锁新内容。

## 七、日常回访闲聊库

先准备6段，其中前4段不要求完成救援，后2段在救援后才开放。

### 回访01：算盘与账本

钱万顺：

辰宇，你瞧这算盘，拨起来倒是轻巧，可账算错了，麻烦就大了。

张辰宇： 您也会算错账？

钱万顺：

怎么不会？

以前有回赶着出货，少记了一笔运费。等回过神来，白忙活了半个月。

张辰宇： 后来怎么办？

钱万顺：

还能怎么办？自己认了呗。

从那以后，每回算完账，我都要再核一遍。

钱万顺：

做买卖最怕的不是算得慢，而是错了还不知道。

### 回访02：那坛酒

张辰宇： 钱掌柜，您怎么总爱抱着坛酒？

钱万顺：

你说这个？

哈哈，摆出来卖的货！可不是我整天抱着喝。

张辰宇： 我还以为您特别喜欢喝酒。

钱万顺：

喜欢倒也喜欢，但喝酒得挑时候。

生意没谈妥之前，我可不敢多喝。

张辰宇： 为什么？

钱万顺：

怕酒一上头，把自家的价钱都给说低了！🍶

### 回访03：天河的雨

钱万顺：

昨夜那阵雨，倒叫我想起天河商域了。

张辰宇： 那边也常下雨？

钱万顺：

靠水路的地方，一下起雨来，河面雾蒙蒙的。远远望去，货船上的灯一盏接着一盏。

钱万顺：

年轻时候我最喜欢坐在码头边上，看那些商船进进出出。

张辰宇： 听着倒挺有意思。

钱万顺：

是啊。

不过要是轮到自己押货，最怕的也是下雨。路滑、货潮，哪一样都够人头疼。

钱万顺：

这世上的好风景呀，站在旁边看是一回事，真走进去，又是另一回事。

### 回访04：赔本的买卖

张辰宇： 钱掌柜，您做过最亏的一笔买卖是什么？

钱万顺：

最亏的？

那可得想想。

钱万顺：

年轻时我收过一批山货，卖家说得天花乱坠，我一时心急，没仔细验货就付了钱。

结果回去一瞧，里面好些都受了潮。

张辰宇： 那后来呢？

钱万顺：

后来呀，该赔的赔，该认的认。

钱万顺：

说来好笑，那回本想捡个便宜，最后倒花钱买了个教训。

张辰宇： 看来钱掌柜也不是一直这么精明。

钱万顺：

哈哈！谁不是一路吃亏一路学？

### 回访05：比货更值钱的东西

救援后解锁。

钱万顺：

辰宇兄弟，我前些日子重新清点了那趟商队的货。

折损倒比预想的少一些。

张辰宇： 那是好事。

钱万顺：

是啊。

不过如今再回头看，那几箱货也没那么要紧了。

张辰宇： 钱掌柜，您这回真是想开了。

钱万顺：

哈哈，想不开也得想开。

钱万顺：

以前总觉得货物越多、账上钱越多，这日子就越有奔头。

现在嘛，能平平安安地做买卖，能和熟人喝口热茶，倒也不错。

### 回访06：商人的朋友

救援后解锁。

张辰宇： 钱掌柜，您走过那么多地方，认识的人一定不少吧？

钱万顺：

是不少。

可你要问有多少真朋友，那还真不敢说多。

张辰宇： 为什么？

钱万顺：

生意场上，今天一桌酒，明天一笔账。

有些人见面热热闹闹，转头就忘了；有些人平日不常来往，真碰上事了，倒肯伸手帮一把。

钱万顺：

这人心呐，平时看不出来，遇上难处才知道。

张辰宇： 钱掌柜说得有道理。

钱万顺：

（笑了笑）

我也是这回才又想明白了几分。

## 八、再补一段第一章归来后的特殊交流

条件：主角已完成天河商域相关调查阶段，并返回青石镇。

钱万顺：

辰宇兄弟！你可算回来了！

快坐，快坐！

这一趟天河商域走得如何？见着周管事了没有？

张辰宇： 见到了。他帮了我不少忙。

钱万顺：

那就好！我就说嘛，老周这人虽不爱说漂亮话，办事却靠得住。

张辰宇： 这回多亏您引荐，不然光是找对人，就得费不少工夫。

钱万顺：

哈哈，我不过替你搭了座桥，路还得你自己走。

钱万顺：

怎么样？天河商域如今还热闹吗？

张辰宇： 热闹得很，商铺货栈一间挨着一间，来往的商队也多。

钱万顺：

听你这么说，我都有些想回去看看了。

（钱万顺笑着给辰宇添了茶。）

钱万顺：

来，把这趟见闻好好说说。你不急着走的话，咱们慢慢聊。

这段具体还要根据第一章实际发生的事件调整。目前只确定人物的情绪与交流方向，不提前编造调查结论。

如果主角没有提前听过商盟旧友这段对话，也不应该卡住第一章任务。 到时候钱掌柜可以在调查谈话中自然补充介绍周管事。

## 十、这套对话有三个值得特别保留的地方

第一，钱万顺不应当因为被救就失去商人的精明。

他会感激辰宇，也愿意帮助辰宇，但不会从此变成一个只会免费送东西、逢人便夸救命恩人的NPC。

他仍然会做生意、算账、讨价还价。

第二，天河商域要从早期就有存在感，但不要过早成为主要剧情。

玩家第一次听说它时，只知道那里商路繁盛；后来了解到通远商盟，最终在第一章真正需要调查材料来源时，才发现这段关系的价值。

第三，钱掌柜的人情关系应该双向发展。

他曾被辰宇救过，后来又帮助辰宇接洽商盟。到了更后面的章节，不妨也让钱万顺遇上需要自己判断和承担风险的事情。

他不是主角身边的工具人，而是一个有事业、有故乡、有旧友，也有自己人生选择的商人。
