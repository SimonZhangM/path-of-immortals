# Buff／Debuff统计说明表 · 2026-09-22

本表调取既有设计，不新增或修改玩法。规则来源：[9月18日战斗总设计第5～6节](combat-system-design-2026-09-18.md)、[9月19日毒蚀实现修订](combat-damage-toxin-2026-09-19.md)、[9月21日装备／功法核心参考](equipment-cultivation-framework-2026-09-21.md)。毒蚀时钟以9月19日明确修订优先；新装备具体数值仍留待内容设计，不把本次查询当作再次锁定平衡参数。

## 1. 统计口径

| 项目 | 数量／状态 |
| --- | --- |
| 核心属性 | 金、木、水、火、土、风、雷，共7种 |
| Buff | 7种，每属性1种 |
| Debuff | 7种，每属性1种 |
| 核心状态合计 | 14种，形成7对同属性正负状态 |
| 名称／释义登记 | 14种均已登记到关键词表；不等于14种战斗逻辑已实现 |
| 已接入核心状态战斗逻辑 | 毒蚀的施加、跳伤、减层、清除及免疫；生机抵消与境界层数上限尚未接入 |

雷盾是防护资源、雷击是派生伤害、麻痹与定身是控制效果，均不计入上述14种七系配对状态。“燃灵、血祭、濒危、噬血”是后续装备能力方向，不自动增加核心状态种数。

## 2. 七种Buff

| 属性 | 名称 | 主要效果 | 触发、消耗与清除 |
| --- | --- | --- | --- |
| 金 | 反锋 | 每层储存1点待反弹金属性伤害 | 物理攻击穿过雷盾等前置护盾、进入护甲或生命结算层时，全额反弹并清零；全被盾吸收不触发，不要求实际扣气血 |
| 木 | 生机 | 等待2秒后进入每秒结算，每次恢复当前层数的气血 | 每次恢复后减1层；进入运行后追加层数不重启等待，归零后重获重新准备 |
| 水 | 润脉 | 等待2秒后进入每秒结算，同时恢复当前层数的灵力与体力 | 每次结算后减1层；进入运行后追加不重启等待，归零后重获重新准备 |
| 火 | 附炎 | 每层储存1点火属性伤害，附加到下一次攻击 | 攻击发出时消耗全部层数，被闪避也不返还；作为该次主动攻击的一部分，可参与属性共鸣 |
| 土 | 坚韧 | 每层＋1%抗暴击概率 | 先判原攻击是否暴击，再判抵抗；成功把暴击变成普通攻击后清零，抵抗失败或原本非暴击则保留 |
| 风 | 轻灵 | 每层＋1%闪避率 | 成功闪避一次攻击后全部清零；未闪避成功则保留 |
| 雷 | 雷蕴 | 每累计10层转化为一次雷盾值 | 立即消耗10层，将生成盾值加入唯一雷盾池；可重复生成和累加，盾值／容量另定 |

## 3. 七种Debuff

| 属性 | 名称 | 主要效果 | 触发、消耗与清除 |
| --- | --- | --- | --- |
| 金 | 锋痕 | 每层储存1点待追加金属性伤害 | 下次受到物理／武器攻击时追加全部储存伤害并清零；默认法术不触发，明确“视作武器攻击”的例外按来源判定 |
| 木 | 毒蚀 | 首次施加后第2秒跳伤，此后每秒直接扣当前层数的气血 | 每跳后减1层；等待期及运行期加层均不重置计时；归零／清除后再施加重新等2秒 |
| 水 | 枯脉 | 等待2秒后进入每秒结算，同时扣当前层数的灵力与体力 | 每次结算后减1层；进入运行后追加不重启等待，归零后重获重新准备 |
| 火 | 灼烧 | 每层每秒造成1点火属性伤害，持续10秒，经过雷盾／护甲／生命结算 | 每秒不减层；追加时叠加层数并把共同持续时间刷新为10秒，到期整池清除 |
| 土 | 疲惫 | 每层＋1%被暴击概率 | 真正受到一次成功暴击后清零；被坚韧抵抗成普通攻击不算成功暴击 |
| 风 | 失衡 | 每层＋1%被命中率；被武器成功命中时触发一次二次追击机会 | 追击重新判命中，命中造成首次纯武器伤害的50%；机会触发即清零，不论追击是否命中；不复制附炎等附加伤害、不连锁追击 |
| 雷 | 雷印 | 达10层进入待引雷状态；下一次受到雷属性武器／法术攻击时触发雷击并施加麻痹 | 到10层本身不立即伤害；引雷后扣10层还是全部清零尚未定，不擅自选择 |

毒蚀设计为穿透雷盾与护甲，直接损失气血；现实现已验证绕过护甲／甲型且不触发反击，雷盾本身尚未接入。灼烧经过防护，不等同毒蚀。5层毒蚀无追加／清除时，在第2／3／4／5／6秒依次扣5／4／3／2／1气血，共15。

生机、润脉、枯脉的设计为先等2秒再逐秒运行，但首次精确跳动时刻、初始等待期加层、抵消转为反向状态时的计时，仍保留原文未决项；不能把仅对毒蚀落实的后续时钟规则自动当成三者都已实现。

## 4. 共通规则

1. **同属性正负状态1∶1抵消。**例如生机8＋毒蚀5→生机3；再加毒蚀6→毒蚀3。这是目标设计，通用抵消尚未接入。
2. **没有统一自然衰减。**木／水每次结算减1；灼烧按持续时间清除；反锋、轻灵等按自身事件消耗，不能统一套成每秒减层。
3. **容量分别计算。**Buff上限＝境界基础＋阵盘Buff上限＋法器相关上限＋其他特殊效果；Debuff上限＝境界基础＋法器Debuff上限，阵盘不增加Debuff容量。超量浪费，具体容量后定。
4. **属性共鸣只强化主动属性伤害。**按现有设计，每个有效己方同属性Buff层＋目标同属性Debuff层提供1%增幅；发出前快照。灼烧、反锋、锋痕、雷击、Combo等派生伤害不再次读共鸣；完整共鸣系统尚未实现。
5. **避免递归。**反锋／锋痕不相互无限触发，追击不继续触发追击；派生伤害与破盾控制之间的具体衔接另定。
6. **装备可以读取或消耗状态。**读取型保留状态获得收益；消耗型提前兑现伤害、控制或其他收益。具体武器、法器、功法效果在内容设计时配置，不将例子变为所有装备的通用效果。

## 5. 关联机制，不计入七系14种状态

| 名称 | 类别 | 当前设计 |
| --- | --- | --- |
| 雷盾 | 特殊护盾资源 | 雷蕴转化生成，只有一个可累加盾值池；同次多类伤害优先吸收法术，再吸收其他主动伤害；完全破裂对破盾攻击者施加麻痹 |
| 雷击 | 派生伤害 | 当前设计公式为阵盘中最高武器攻击×1.5，不再次读取雷系共鸣；阵盘归属、最高值取法、无武器处理等尚未定 |
| 麻痹 | 控制效果 | 敌方阵盘停止运转2秒；不自动扩大为角色法术、所有状态或全局时间全部暂停；重复控制与Boss抗性等待明确 |
| 定身 | 控制效果 | 使敌方相关战斗CD暂停数秒，具体范围、时长与抗性另定，不当作麻痹同义词 |
| 毒蚀免疫 | 防护效果 | 当前消毒散清除已有毒蚀并提供15战斗秒免疫，已实现；不是独立七系状态，关键词显示只识别其中“毒蚀” |

普通护盾同样属于防护资源。雷盾与普通护盾的承伤先后、灼烧破雷盾与麻痹的衔接，仍见战斗总设计的未决边界。

## 6. 当前实现与后续边界

实际核对：[14词注册表](../data/ui/combat_status_keywords.json)、[状态数据](../scripts/core/party_member_state.gd)、[战斗模拟](../scripts/simulation/battle_simulation.gd)、[效果系统](../scripts/systems/effect_system.gd)。14个名字、正负分类、说明及显示资源已登记；毒蚀战斗流程和消毒散清除／免疫已接入，当前生产怪物没有施毒来源。其他13种完整状态机制、七系抵消／容量／共鸣尚未落地；现有普通回复、反击和属性加成展示不能等同于这些状态系统已实现。

后续仍要精确化：锋痕是否需要穿盾、附炎识别哪些攻击来源、生机／水系的首跳与满空资源耗层、灼烧末跳与刷新时钟、暴击／闪避概率边界、50%追击取值及防御处理、雷印消耗、雷击归属、麻痹暂停范围等。本表保留已记录的规则与参数，同时保持这些未决边界，不作新裁决。
