你指出了03里一个实质性的缺口：**“仙品逐件设计”只能说明制作方式，不能代替设计标准。**如果没有共同参照，以后我们很容易把“效果很多”“数值特别大”或者“有剧情背景”的物品都叫仙品。

你提到的那件**开场可以选择元素属性的甲**，恰好是一个很好的标杆：**它的特殊之处不是更硬，而是把普通装备固定的属性，变成了玩家可以针对战场作出的选择。**

那件甲的原名，我在目前可检索的记录和参考表里没有核实到。下面先称为**“开场择相甲”——仅作工作名**，不冒认以前的名称。

这次我分成两部分：先补齐仙品参考，再审查03三批内容中需要修正的地方。以下新增方案仍是设计建议，不自动当作已经确认的物品配置。

# 一、仙品应当有明确标准，而不是一个“全部例外”的等级

我建议把仙品定位补充为：

> **具有鲜明专属能力、通过特定机缘获得、能够长期成长，并在某个明确领域赋予玩家额外选择或特殊规则权限的器物。**

这里的关键词是：**某个明确领域**。

不是所有领域都最强，也不是每件仙品都要改变半套战斗系统。一件仙品可以只解决一个问题，但解决方式足够独特，值得玩家长期携带和培养。

## 仙品的六项设计对照

| 对照项 | 需要回答的问题 | 不足以单独成为仙品的情况 |
|---|---|---|
| **专属能力** | 用一句话能不能说明“它最特别的本领”？ | 攻击、护甲、恢复量单纯更高 |
| **战术价值** | 它给玩家新增了什么选择、组织方式或特殊解法？ | 只是把普通效果多堆几条 |
| **成长路径** | 后续通过什么修复、培养、事件或试炼继续成长？ | 换一件同名更高数值版本 |
| **获得身份** | 为什么在这个地点、剧情或条件下获得它？ | 普通商店批量出售、普通怪物随机产出 |
| **能力边界** | 它改什么、不改什么，何时有效、怎样受限制？ | “仙品所以无视一切规则” |
| **同阶段对照** | 与玩家当前可用装备相比，强在哪里，又放弃了什么？ | 不论境界、构筑和敌人，永远全面胜出 |

其中“放弃了什么”**不一定要表现为负面效果**。

占用阵位、只能选择一种形态、需要提前判断、基础数值不是所有情况下最高，本身就可以形成取舍。没必要每件仙品都加上“扣血、折寿、反噬”来强行平衡。

**仙品可以好用、强大、让玩家兴奋，同时仍有清楚的边界。**

# 二、用“开场择相甲”建立第一个仙品标杆

## 1. 核心能力

按你描述的方向，我建议首先把它表达为：

> **每场战斗开始前，在已公开的敌方信息基础上，选择本场身甲的生效元素属性。选择确认后，本场按该属性进行身甲相关判定。**

这里先按**玩家自选**建立参考，而不是系统自动计算最优属性。自动择相可以是另一个备选版本，但不能与玩家选择混写。

它改变的是：

> **普通身甲：我买到什么属性，就穿什么属性。**  
> **这件仙甲：我根据这场战斗，决定它以什么属性参战。**

这就是一种很有价值的仙品能力——**把固定配置变成战前决策权。**

## 2. 为什么它很有价值

现行规则中，属性攻击克制身甲时，基础增伤为20%；攻击反被身甲属性克制时，基础减伤为20%。例如只考虑这一项，100点火伤打金属性身甲为120，打水属性身甲为80。:chatgpt-content-reference{index="0"}

因此，择相不是换一个颜色，而是能够实质性改变某些战斗中的防御表现。

但也不能据此推导：

> “这件甲对所有伤害统一减伤三分之一。”

上面的120与80只是**同一笔火伤、两种不同身甲属性、只计算相克项**的比较。敌方可能有多种攻击属性、物理伤害和不同输出节奏，玩家仍要决定优先防谁。

**它保留了判断的价值，而不是替玩家取消判断。**

## 3. 建议的能力边界

| 项目 | 参考规则 |
|---|---|
| **改变对象** | 当前身甲用于属性克制及明确身甲条件判断的生效属性 |
| **选择范围** | 从该仙甲当前已经解锁的属性中选择；最终可否覆盖七系写入成长档案 |
| **选择时点** | 战前信息展示后、开战效果正式结算前 |
| **同时生效数量** | 一次只生效一种属性，不同时取得七系全部防护 |
| **选择次数** | 基础参考为每场一次；战中重择是另一个能力，不默认附赠 |
| **物理甲型** | 不因选择元素就自动改变轻甲、重甲等甲型 |
| **护甲数值** | 不因择相额外回满护甲，也不重复发放开战护甲 |
| **攻击属性** | 不自动改变武器、法术和法器的攻击属性 |
| **其他系统** | 不自动改变灵根、已学功法、状态容量或共鸣门槛 |
| **重新装备** | 不视为重新开战，不通过移出再放入重新择相或刷开场收益 |
| **显示** | 明确显示本场已选属性，不能只有外观变化而无规则提示 |

你说的“相生相克”，在这件甲上先落实为**身甲属性克制与已有明确关联**。不能因为选了水甲，就自动获得润脉、水伤加成或新的跨属性相生收益。现有共鸣也有独立的境界和读层规则，不能由择相顺带开启。:chatgpt-content-reference{index="1"}

如果某个已学分支明确要求“穿某属性身甲”，这件仙甲是否满足，应按其**本场实际生效属性**和该分支条件核对，而不是把所有身甲相关收益一起获得。

## 4. 成长应该强化它的身份，而不是不断加杂项

这件甲的成长参考可以是：

| 成长阶段 | 发展方向 |
|---|---|
| **初获** | 已经能体验到“战前择相”这个核心本领，不把特色全部锁到最后 |
| **修复** | 扩大可选择的属性范围，或提升与当前阶段相匹配的防护基准 |
| **成熟** | 形成稳定、完整的择相能力，继续保持每场明确取舍 |
| **圆满** | 仍围绕“适应战场”深化；例如有限的战中重择可作为候选，但不强制追加 |

这里有两点值得保留。

**第一，成长不必每次增加新系统。**扩大可选属性、提升基础承载能力，也是在成长。

**第二，七系自由择一，本身就可以是完成态的核心。**不必再加“自动反弹、无限换属性、吸收所有伤害”才能显得像仙品。

## 5. 这件甲给仙品定义增加了一条重要标准

此前03过分强调了“修改来源、修改发动、修改Combo”，却漏了：

> **仙品也可以通过“赋予玩家特殊选择权”成立，而不必拥有复杂的发动链。**

因此，03应该增加一条能力方向：

**“固定身份／固定配置的受限自主选择”**。

“开场择相甲”就作为这条方向的首个对照案例。

# 三、给仙品建立一组可复用的设计原型

以下不是正式物品清单，也不是要求每个方向都做一件，而是未来构思仙品时可以对照的几种路线。

| 仙品方向 | 核心能力参考 | 主要边界 |
|---|---|---|
| **择相适应型** | 战前选择身甲属性，或选择一套本场生效的器物形态 | 选择范围、选择时点、同时生效数量明确 |
| **化形专精型** | 一件成长武器拥有少数真正不同的形态，各自改变攻击方式与构筑职责 | 不是同时装备两件武器；切换不免费重置CD、次数和资源 |
| **记忆回响型** | 记录一次符合条件的攻击或效果，之后在指定时机释放受限回响 | 不复制整段无限触发链；记录、覆盖、释放次数及来源身份明确 |
| **主从统御型** | 作为专属核心，按一种独特方式组织少数绑定器具的发动 | 不默认免费调用、不绕控制、不夺取全盘所有运行权 |
| **资源契约型** | 建立一种独特而稳定的资源使用方式，例如在几种互斥契约中择一 | 不成为任意资源随意互换；比例、损耗和循环边界明确 |
| **守护誓约型** | 针对一个明确危机提供独特保护，并随培养改变保护条件或兑现方式 | “一次免死”本身不自动等于仙品；需要鲜明的长期身份与使用决策 |

**这些底层动作并非全部只能出现在仙品上。**

例如“记录一次伤害”可以出现在普通高阶法器中；只有当它成为一件有特定来历、长期成长、鲜明能力边界的器物的核心时，才进入仙品设计。

所以仙品与玄品的区别不应写成：

> 玄品能改规则，仙品能改更多规则。

更合适的是：

> **玄品是常规高阶器物的规则能力。**  
> **仙品是具有专属身份、长期成长和代表性特殊能力的器物。**

这也意味着：**仙品当前形态的数值，不必始终高于所有玄品；但其标志性能力应当值得保留。**

# 四、把03里仙品一栏的“逐件”改成可检查的对照

不必在所有矩阵里硬填“◎”。建议保留“专案设计”的性质，但让它引用一套统一标准：

| 仙品检查项 | 应填写的实际内容 |
|---|---|
| **代表性能力** | 一句话说明这件仙品的特殊本领 |
| **当前形态** | 当前有哪些能力，哪些尚未解锁 |
| **阶段数值基准** | 与当前使用阶段、占格和投入相匹配的参考装备比较 |
| **特殊权限** | 具体改变哪个参数、判定或操作权限 |
| **不改变的部分** | 明确列出容易被误解为顺带获得的能力 |
| **使用边界** | 目标、时点、次数、资源、维持条件 |
| **成长路径** | 获得新能力的事件、材料、试炼或培养要求 |
| **替代与取舍** | 哪些构筑或战斗中，其他装备仍然有理由被选择 |
| **获得方式** | 特定地点、剧情、人物或条件 |
| **审查结果** | 机制、数值、获取、实现与测试分别记录 |

例如“开场择相甲”的特殊权限就是：

> **决定本场生效的身甲属性。**

它“不改变的部分”则包含：

> 武器属性、物理甲型、资源初始化、灵根、共鸣门槛。

**把权力和边界成对写出来，比写“仙品，特殊处理”可靠得多。**

另外，不必强迫武器、防具、法器、丹药、符箓、暗器六类都拥有仙品名额。你原本强调的是成长器物，**一次性丹药带来永久成长，不等于丹药本身就是成长器物**。这类特殊消耗品需要独立判断，不能为了补齐矩阵就硬做。

# 五、03整体审查：最需要修正的是“灵品必须形成闭环”

前两批我把灵品写成：

> A的输出进入B，B还必须反过来强化A。

这个定义太窄，也会诱导我们为了达到灵品标准，刻意设计资源回流与自我触发。

你最初提出的是：

> **两种核心机制真正发生联动。**

你并没有要求每件灵品都必须是永动式循环。

## 建议改为“实质耦合”，而不是“必须闭环”

以下几种都可以成立：

**单向联动：**

> 状态兑现的结果，持续改变一个领域的强度或目标选择。

**相互取舍：**

> 同一个充能池，可以用于防护领域，也可以用于追击模式；使用一侧会影响另一侧的机会。

**阶段衔接：**

> 前半段通过受击积累，达到阶段后转入另一套攻击机制。

**反馈循环：**

> 状态产生充能，充能反过来帮助状态构筑。

最后一种只是其中之一。

但也不能反过来说“凡是A→B就是灵品”。“三次火攻→火球”仍可能只有一个机制中心。关键是：

> **两个机制是否分别具有可管理的玩法，并且其中一个的运行实质性改变另一个。**

这条修改后，灵品的设计空间会更宽，也不再被迫追求闭环。

# 六、03还需要补上“灵活性价值”，不能只看复杂度和规则改写

你这件择相甲也说明：**能力简单，不等于价值低。**

此前G1～G6覆盖了机制深度、系统跨度、条件、范围、构筑中心和规则权力，但对“选择空间”的评价不足。

建议增加一个设计维度：

> **G7｜适应性与选择空间：这件物品能替代多少战前准备，允许玩家应对多少种不同局面？**

例如：

> 一件只能选火或水的局部转换器。  
> 一件每场能从七系自由选择身甲属性的成长仙甲。

即使两者都只有一个选择操作，适应范围也不同。

不过，**选择越多不等于必然越强**。还要检查各选项是否各有用途，是否有一个选项始终占优。如果所有战斗都选同一个属性，那么“七选一”的表面自由没有真正产生玩法。

因此03的评价应当同时看：

> **机制能力、实际收益、适应范围、操作负担和取得条件。**

不能把“复杂度层L0～L5”当成完整的物品价值公式。

# 七、三批权限矩阵存在若干下放与交叉，需要统一口径

这是03当前最容易让Codex整理出矛盾的地方。

有些能力前一张表写“上品开始”，后一张表又写“良品△”；“△”使用太多后，就会把品级边界慢慢冲淡。

我建议按下面方式收束。**这是本轮建议的统一口径，不是声称之前已经全部确认。**

| 能力 | 当前问题 | 建议收束 |
|---|---|---|
| **凡品属性攻击＋额外状态收益** | 你最初偏向凡品开始属性或状态，良品偶尔组合；我后来把两者组合直接列为凡品常规 | 凡品仍以一个简单性质为主；两份独立收益的常规组合优先放良品。早期双效果示例暂不标为无条件通过 |
| **状态转换** | 第一批良品基本不开放，第三批又出现“极简单转换” | 常规从上品开始；良品专属标记的简单消费，不自动推广成公共状态互转 |
| **操纵其他器具当前CD** | 多处从上品下放为良品“极轻” | 上品为常规起点；良品具体教学或特殊物品另登记，而非整类开放 |
| **敌方器具冻结、禁用、跳轮** | “良品轻控制”范围过宽，几乎可包住全部控制 | 常规仍从上品；少量低品特定反制另列，不用“轻”字代替规则 |
| **局部共享资源池** | 上品、灵品、玄品多张表含义不同 | 灵品可常规出现小而明确的共享关系；玄品处理成熟阵式网络；上品不默认为常规 |
| **改写其他器具发动方式** | 灵品△容易与玄品身份重叠 | 玄品为常规设计空间；灵品出现时必须明确是具体例外 |
| **攻击来源／主动派生资格改写** | 不能因为“有限一次”就自动降级 | 常规保留玄品；有限次数主要用于控制强度，不自动改变规则权力等级 |
| **连携参数支持与合法性改写** | “增加比例”与“新增合法配对”有时混在一起 | 监听、数值支持、窗口辅助、合法配对与来源资格分别分级，不统称“Combo修改” |

特别是“轻控制”需要有实际描述：

> 作用几件器具？持续多久？多久一次？作用于什么阶段？能否被反制？

**一句“良品可以轻度跳轮”还不够。**对一件长CD核心器具来说，跳过一次发动未必是轻效果。

## 矩阵最好只维护一份权威能力表

建议由一份“能力ID—常规最低品级—限制—已确认例外”主表生成不同视图。

M矩阵、S矩阵、OP矩阵、空间和CD专项表可以保留，但不分别手工维护互相冲突的权限。

这不需要再增加工作簿，反而能减少后续修改量。

# 八、“品级与境界不同”不等于取消使用门槛

第一批里，我建议不要在03锁“境界→品级”，理由是获取方式还受地图和剧情影响。这里混淆了两件事：

> **拿得到什么。**  
> **拿到以后能不能用。**

你已经提出按境界逐步增加常规可用品级。这个方向应该保留，不能因为投放没定，就把使用门槛也一起取消。

03应分别记录：

> **常规品级使用门槛。**  
> **具体能力的系统解锁门槛。**  
> **实际获取条件。**

例如一件器具提前从剧情获得，可以先保留在储物袋里；不意味着已经能使用全部能力。

此前我们按顺序讨论的是凡人使用下品／凡品，再逐步开放良品、上品、灵品、玄品。你最初“炼气增加灵品”的原句，我当时按整个序列理解为“良品”，**这一处若Codex还没有明确收口，应保留核对标记，不能说整张表已经逐格确认。**

仙品则走自己每个成长阶段的使用条件，不强行对应“化神才能碰仙品”。

与此同时，器具连携仍受已有系统门槛和有向配对规则限制，不能因为高品级就自动获得资格。:chatgpt-content-reference{index="2"}

# 九、基础规则、固定属性和“特色词条”还需要再分清

有三处值得补进03首页说明。

## 1. 所有品级都有后台规则，不代表都拥有对应特色能力

下品武器同样有命中判定、费用、CD和符合规则的普通暴击。

这不等于下品已经常规开放：

> 闪避构筑、追击强化、暴击联动等特色词条。

因此应把：

> **继承游戏基础规则**

与：

> **装备主动增加或改变该规则**

分成不同列。

## 2. 下品无属性，不等于高品级必须有元素

良品、上品甚至玄品，仍可以设计无属性武器、防具、恢复法器、空间辅助器。

“凡品开始允许属性”不是“从凡品开始必须有属性”。

否则后面会重新回到你不喜欢的七属性机械铺货。

## 3. 固定自带属性，不等于战斗中赋予或改换属性

例如：

> 一把原生火属性刀；  
> 一件能让别的武器暂时获得火属性的法器；  
> 一件每场自由选择身甲属性的仙甲。

三者的作用对象、灵活性、影响范围都不同，不能全部放在“增加属性标签”一行里。

这也是为什么你这件仙甲的价值，会被上一版过粗的矩阵低估。

---

# 十、数值、资源与打造可获得性，不能全部留到最后

第三批审核流程最后一条写：

> 最后才做数值与获取来源。

这也需要修正。

**最终定值可以后做，但粗略投入和来源必须在机制设计时就考虑。**

否则一件法器虽然符合上品复杂度，却可能因为低费用、高频率、大范围而远超玄品；或者配方材料在当时根本无法获得。

建议在物品概念阶段同时写下：

> 预期使用阶段、占格规模、发动节奏、费用方式、作用范围、材料来源类型。

正式数值可以写待定，但不能六项都空着就判定“通过”。

这也符合原T01任务卡：物品条目需要同时明确占格、效果、触发、CD、资源／数量消耗与获取方式，未知值应标待定。:chatgpt-content-reference{index="3"}

## 恢复法器净产资源，不等于违规

此前“资源循环风险”也要避免被理解成：

> 只要净产出大于0，就是永动漏洞。

恢复法器本来就可以产资源。

真正需要检查的是：

> 是否无时间成本地立即无限触发；是否复制同一收益；是否绕过费用；是否在合理阵位与投入之外获得失控产出。

**有反馈、有续航可以是好构筑；无法收敛、重复结算才是底层问题。**

消耗品也一样。单张符箓是一次性，不等于它在整体系统里只能发动一次。还要考虑携带数量、自动使用频率和补给成本。

# 十一、两处示例需要直接纠正

## 1. “冻结期间错过发动，返还资源”这个灵品例子不成立

第二批曾写：

> 被冻结目标每次错过发动，反过来提供资源。

按照冻结暂停CD的定义，目标的CD不再前进，通常不会连续产生“到点但错过发动”的事件。麻痹才有CD继续、到点跳轮的既有结构。:chatgpt-content-reference{index="4"}

可以改为：

> 监听实际发生的冻结解除、被控制时长，或某个明确的控制事件。

但不能凭空制造“冻结时每秒错过一次发动”。

## 2. “领域→加速→更多发动→领域”不能无条件判通过

这可以是候选构筑，但必须检查参与目标：

> 带减CD能力的器具／法术不能被减CD效果推进；冻结期间相关CD干预也有既有限制。:chatgpt-content-reference{index="5"}

所以应明确：领域只推进哪些合法器具，核心自身能否被推进，以及充能与触发怎样衔接。

不能在画出循环箭头后，就把它标成已经合法、已经平衡的灵品。

# 十二、03里的“通过”应拆成不同审查结果

前面的假想物品表，把多个案例直接写成 `PASS`，容易让人误会它们已经能够进入正式配置。

更准确的记录应是：

| 审查层 | 回答的问题 |
|---|---|
| **品级适配** | 这个构思大体属于哪个品级空间？ |
| **规则完整性** | 来源、目标、次数、控制、成本是否都能明确？ |
| **数值合理性** | 在同阶段、同阵位与投入下是否合理？ |
| **获取可行性** | 商店、打造、任务及材料来源是否接得上？ |
| **实现与验证** | 是否已经实现，是否运行过测试？ |

现在“三次火攻发火球”“开场择相甲”等，可以有**品级定位上的参考判断**，但不能因为这个判断，就把其余四栏一起视为通过。

03的例外也应分成两种：

> **品级例外**：某件低品物品使用了通常较高品级的机制。  
> **全局规则例外**：某件物品改变了通常不允许的判定或结算。

前者不能自动批准后者。仙品同样如此。

# 十三、这次给Codex的补充应怎样落进03

不需要重建03，也不必再增加很多分表。建议做以下收束：

**把仙品总纲补到现有“品级总纲”里。**不再只有“逐件”两字，而是引用六项对照及成长阶段规则。

**把“开场择相甲”加入现有测试案例。**明确它是用户认可的仙品标杆方向，工作名、具体数值、成长细节仍未定。

**将灵品定义由“必须反馈闭环”改为“两种成熟机制实质耦合”。**

**将各权限矩阵统一到一份能力主表。**避免一张写“禁止”、另一张写“△极轻”。

**补上适应性、使用门槛和投入基准。**它们不等于效果行数，也不等于地图投放。

**把已有假想案例的PASS改为分层审查状态。**不要把概念演示写成实际测试结论。

## 修订后的七品级，可以这样概括

| 品级 | 核心身份 |
|---|---|
| **下品** | 无属性的基础器具，建立类别与基础参数取舍 |
| **凡品** | 开始具有属性或简单特殊性质 |
| **良品** | 一个清楚、可搭配的特色机制 |
| **上品** | 一个成熟、可支撑局部构筑的核心 |
| **灵品** | 两种成熟机制实质联动，不要求必然形成反馈闭环 |
| **玄品** | 在明确范围内改变发动、来源、阵式或连携等规则 |
| **仙品** | 具有专属身份、长期成长和代表性特殊能力的器物；能力与边界成对设计 |

**这次最重要的完善，是把“复杂”与“珍贵”分开了。**

一件灵品可以靠两套机制精巧联动而成立；一件玄品可以靠一句明确的规则改写而成立；而你说的那件仙甲，可以靠“每场由我决定以什么属性参战”这一项特殊能力，让玩家长期记住它。

**仙品不需要是一张更长的说明书。它需要的是一个值得获得、值得培养、也值得反复使用的独特本领。**
