## 1. 战斗结构与玩家初始状态

战斗核心为**主角对单个敌人的1V1，阵盘自动轮转＋法术半手动操作**。武器、法器、符箓、丹药等主要按CD自动发动；主角法术CD完成后由玩家选择释放时机。敌方阵盘可提前观察，供玩家针对甲型、防具属性、种族、技能及阵盘配置调整己方装备。

灵兽属于支援角色，不是第二个独立战斗单位：没有自己的气血、体力、灵力、护甲等完整资源，不会成为敌方攻击目标。既有原型每方最多两名纯辅助配角、每名两个可任意组合主动/被动的特质槽；新稿未规定灵兽是否直接沿用人数和槽位限制，暂不据此修改配角模型。

当前已落地的玩家基础值：张辰宇，凡人；初始/最大气血50、体力50、灵力0；修为0/100，历练0。后续战斗胜利可获得修为与历练，奖励表与发放规则待设计。当前地图只初始化并展示这些数值，没有战斗奖励、升级或存档流程。

## 2. 伤害类型、甲型与防护资源

### 2.1 类型与伤害包

| 伤害类型 | 设计定位 |
| --- | --- |
| 穿刺 | 针对特定甲型 |
| 斩击 | 常规武器伤害 |
| 钝击 | 对重型防御更有效 |
| 法术 | 独立的法术伤害类型 |

甲型为无甲、轻甲、重甲、灵甲。**四种伤害对四种甲型的最终倍率表，本轮重新列为未定。**2026-09-13的16格矩阵仍是当时已采用的序章试算输入，不能作为新体系最终倍率，也不能抹去当时确认和测试的事实。

伤害包须区分两种情况：

- 武器附带法术伤害：例如长剑20斩击＋10火属性法术伤害，拆成两段分别按其规则结算；10火伤不继承斩击倍率。
- 武器型法术：冰剑、火矛、金针等可以让**同一个伤害包**拥有“法术＋穿刺”或“法术＋斩击”双标签，同时受两套规则修正；不是重复扣血两次。双标签的具体运算顺序与系数组合仍须写入完整流水线。

伤害类型、伤害属性、目标甲型、防具属性和种族是不同维度，不得用一个字段互相替代。高级多属性器具允许存在，但拆包、命中共享、取整及触发次数尚未定。

### 2.2 护甲

角色具有**当前护甲／护甲上限**，护甲是会被消耗的战斗资源，不是现原型中的固定每击减伤值。

身甲决定防具属性。其他护具不改变属性，只增加当前护甲、护甲上限或提供特殊效果。例如木属性轻甲提供10护甲，其他护具将护甲增加到15，防具属性仍为木。

**身甲是否同时决定甲型尚未确认。**“身甲同时决定甲型＋属性”是原文末尾的建议，不能写成既定规则；旧稿中按占格或装备结构确定甲型的方案不直接作为当前默认实现。

### 2.3 雷盾与承伤顺序

雷盾先于普通护甲承伤；在一次含多个伤害段的攻击中，**优先吸收法术伤害，剩余盾值再吸收其他主动式伤害**。

例：一次攻击含穿刺10＋火法术10。

| 雷盾值 | 雷盾吸收 | 后续进入甲型等结算的伤害 |
| --- | --- | --- |
| 10 | 火法术10 | 穿刺10 |
| 15 | 火法术10＋穿刺5 | 穿刺5 |

这里只锁定上述局部顺序。不能据此推断持续伤害、反击、Combo、雷击、灵兽挡伤或多来源同刻攻击全部如何过盾。原先“灵障”与新稿“雷盾”是替代、特例还是并存，尚需确认；旧灵障的挡异常、战后清理、上限规则不能自动继承给雷盾。

## 3. 七属性、七灵根与六种族

正式伤害属性：**金、木、水、火、土、风、雷**。无属性仍表示没有元素标签，不算第八属性。

七灵根为金、木、水、火、土、气、雷，**气灵根对应风属性**。属性与种族独立，允许雷属性妖族、火属性鬼物、木属性魔族等组合。

### 3.1 属性克制

采用1克1的完整七环：**雷 → 水 → 火 → 金 → 木 → 风 → 土 → 雷**。

| 攻击属性 | 克制的防具属性 |
| --- | --- |
| 雷 | 水 |
| 水 | 火 |
| 火 | 金 |
| 金 | 木 |
| 木 | 风 |
| 风 | 土 |
| 土 | 雷 |

关系确定，倍率未定。原文×1.20、×1.25、×1.30只是候选例子；未规定逆克制、同属性抗性或额外跨属性相生倍率。

### 3.2 种族特攻

六种族：人族、兽族、妖族、鬼物、器灵、魔族。

| 攻击属性 | 特攻对象 |
| --- | --- |
| 金 | 器灵 |
| 火 | 兽族 |
| 雷 | 鬼物、妖族、魔族 |
| 木、水、土、风 | 暂无固定种族特攻 |

人族没有天然属性弱点。种族特攻与防具属性克制可以同时成为选装依据，例如针对水属性防具的妖族考虑雷属性攻击；两者倍率及叠加方式未定。原文“雷属性水系妖族”的属性字段含义未解释，不能据此新增双防具属性机制。

## 4. Buff／Debuff

### 4.1 各属性方向

| 属性 | Buff方向 | Debuff方向 |
| --- | --- | --- |
| 金 | 强化护甲攻击／锋锐（具体含义待细化） | 破甲 |
| 木 | 生机、生命恢复 | 毒素、生命损失 |
| 水 | 降低自身灵力消耗 | 增加敌方灵力消耗 |
| 火 | 强化伤害 | 灼烧 |
| 土 | 降低自身体力消耗 | 增加敌方体力消耗 |
| 风 | 提高闪避 | 提高被命中率 |
| 雷 | 雷盾 | 雷击积累与触发 |

风Buff每层＋1%闪避，风Debuff每层＋1%被命中率。按原文口径：最终闪避＝基础闪避＋风Buff层数×1%－风Debuff层数×1%。怪物可以有基础闪避率；概率上下限和必中优先级未定。

风系技能可推进己方法器剩余CD、延后敌方法器剩余CD或修改阵盘相关CD。极少数顶级法器可干预全局时间；具体对象、范围和限制待内容设计，不视为当前已可用的时间能力。

### 4.2 抵消、衰减与容量

取消“稳定Buff”。同属性Buff与Debuff直接抵消：火Buff8层受到火Debuff5层后剩Buff3层，再受Debuff4层后成为Debuff1层。

| 状态 | 自然衰减 |
| --- | --- |
| 临时Buff | 每模拟秒减少1层 |
| 木、水、火、土Debuff | 每模拟秒减少1层 |
| 金、风Debuff | 每2模拟秒减少1层 |
| 雷Debuff | 不用普通自然衰减，采用积累／触发机制 |

达到最大层数后，新增超出部分直接浪费，不溢出、不储存。抵消、封顶与衰减恰好同刻的先后顺序尚未定。

上限按加法计算：

- Buff上限＝境界基础上限＋阵盘上限＋法器修正。
- Debuff上限＝境界基础上限＋法器修正，**阵盘不增加Debuff上限**。

阵盘负责Buff容量，未来可通过打造提升；打造系统本轮不展开。各境界数值、各属性是否分别计容量、降上限时如何截断等仍需细化。

### 4.3 同属性增幅

取消全局跨属性“相生”，只保留同属性强化同属性。每个有效的己方同属性Buff层或敌方同属性Debuff层，提供＋1%对应属性伤害：

`可造成属性伤害 = 基础属性伤害 × [1 + 0.01 × (己方有效同属性Buff层数 + 敌方有效同属性Debuff层数)]`

例：雷伤100、己方雷Buff5层、敌方雷Debuff10层，得到115雷伤，再进入属性克制等后续计算。可读取的有效层数上限可受境界限制，具体限制未定。“属性共鸣／同属性共鸣”是建议名称，本文用“同属性增幅”指代该机制，不冒充已确认的最终UI术语。

### 4.4 雷的特殊规则

雷Buff产生雷盾，来源可为雷系法术、护具、法器或特定技能；层数到盾值的映射、盾值规模与持续规则未定，不能将Buff层数直接当盾值。

雷Debuff积累至阈值后进入待触发状态；玩家下一次对目标造成主动式伤害时追加一段雷击。**“雷击伤害等于本次主动伤害”目前仅暂定**，阈值、取值阶段、消耗／重置、是否对敌方对称、是否能被反复触发都待细化。

## 5. 法术与Combo

### 5.1 法术发动

法术有独立CD；完成后进入可释放状态，由玩家选时机，不自动施法。施法前摇目前主要承担视觉表现。Combo窗口从**法术实际生效**瞬间开始，不从点击或动画起点计算。

法术槽数量、初始CD、下一轮CD起点、灵力成本、资源不足处理及暂停时的施放交互尚未全面设计。主角手动法术与灵兽主动技能应分别定义，不能把本条误用于关闭现有配角自动轮转。

### 5.2 两段Combo与伤害

元婴开放法术Combo：A生效后产生短暂机会，2秒内使用满足条件的B，B获得Combo。两秒窗口的截止边界、B点击与实际生效跨界时如何判定仍须明确。

Combo额外伤害按第二招本身的**实际有效伤害**乘百分比计算。例：B经过Buff／Debuff、属性克制、种族针对等修正后为130，若Combo倍率为20%，追加26；**20%为演示值，不是最终基础倍率**。

追加伤害为**法术型无属性伤害**，不再读取Buff／Debuff、不参与属性克制或同属性增幅，避免重复放大／递归。“实际有效伤害”究竟在甲型、雷盾、护甲、暴击、过量伤害截断的哪一步取值尚未完整定义；无属性也不等于无视护甲。

Combo关系由具体法术、功法、法器定义，不是通用元素表。例如“御风诀→炎爆术”是技能组合举例，不代表全局风生火，也不是已批准的正式技能清单。

无伤害技能可作起手，例如辅助、防御、治疗、控制→攻击；不要求A造成伤害。

### 5.3 境界边界与专属三连

| 阶段 | Combo能力 |
| --- | --- |
| 元婴 | 法术↔法术；法器不能作为正式起手 |
| 化神 | 加入法术→法器、法器→法术、法器→法器及连续Combo |

专属三段Combo采用少量、明确命名且有传承和视觉辨识度的设计：A→B→C按指定条件完成后，C转成专属终结式，否则C仍是普通技能。奖励方向可包括必中、暴击强化、定身、引爆Debuff、大量叠雷、恢复资源或改变CD；可配专属名称、特效、镜头、震动、人物切入。具体连携表、效果和演出都未定，法术数量遵循少而精。

## 6. 暴击、闪避与定身

已决定加入暴击；基础暴击率、倍率、适用攻击、与Combo基准的关系均未定。“主动攻击／法术可暴击，而持续伤害和Combo可能不能暴击”只是待选方向。

定身定义为**敌方战斗CD暂停若干秒**，涵盖法器、法术、阵盘相关CD；不是地图上的不能移动。时长、叠加、Boss抗性未定。毒、灼烧等持续状态仍运转是原文建议，未正式定案；入场等待、已就绪法术、撤退、全局时间是否受影响需另行明确。

## 7. 境界、灵根、修为与历练

### 7.1 境界逐层开放规则

| 境界 | 主要开放内容 |
| --- | --- |
| 凡人 | 基础武器、护甲、阵盘、CD |
| 炼气 | Buff／Debuff自身效果 |
| 筑基 | 属性克制 |
| 结丹 | 同属性Buff／Debuff增幅属性攻击 |
| 元婴 | 法术Combo |
| 化神 | 法器加入Combo、多段连携 |

境界成长不仅是伤害数字增长。跨境界作战时按哪方境界启用克制、增幅等规则，以及种族特攻何时开放，需后续确定，不能由上表擅自推导。

### 7.2 灵根

开局由玩家选择1～4种灵根，决定可学习的属性法术及初始修炼效率。

| 初始灵根数量 | 暂定修炼效率 |
| --- | ---: |
| 1 | 150% |
| 2 | 125% |
| 3 | 100% |
| 4 | 80% |

单灵根修炼快而覆盖窄，多灵根修炼慢而法术／Combo覆盖广。法器不受灵根限制，没有火灵根也可使用火剑、火符、火法器，只是不能正常学习火系法术。效率作用于哪些修为来源（是否含战斗奖励）未定。

允许后天补灵根。暂定设想是元婴通过补灵丹＋1、化神通过天地造化＋1；增加学习范围，不追溯修改初始修炼效率。具体获取、上限与选择规则后定。

### 7.3 修为与历练

修为用于修仙境界成长；当前凡人需求100、初始0，后续各境界阈值、突破条件、溢出规则未定。

历练**只能通过战斗获得，不是消费货币**。达到门槛可通过历练技能树解锁二连／三连、更复杂衔接及特殊战斗能力。它与境界开放表的组合条件、技能树分支及数值尚未定，不能把历练门槛直接当作绕过境界限制。

## 8. 灵兽支援

每只灵兽的属性在内容设计时固定，与主角灵根选择分开。灵兽无完整独立战斗资源、不受攻击，但可提供Buff／Debuff、护甲、气血上限、一次或一定量挡伤、主动技能及Combo节点。

培养、携带数量、技能槽、技能资源归属、自动／手动模式、挡伤与雷盾顺序、灵兽参与Combo的境界限制均未完整定义。当前两名测试配角仅能证明纯辅助和主动／被动特质的基础实现，不代表灵兽培养或Combo已落地。

## 9. 阵盘、储物袋与装备

### 9.1 存放层级与阵位

原文建议采用**仓库→储物袋→阵盘**：仓库是地点型大容量存放，储物袋是随身备用物品，阵盘是当前战斗配置。三层模型按建议记录，仓库及容量未实现、未定版。

阵位按逐行左到右、上到下结算。同一时刻多个物品CD完成时按阵位顺序处理。多格物品采用哪个格作排序锚、敌我双方先后、恢复／控制／致死的同刻优先级，尚待明确；不可直接把所有事件排成一个未经确认的列表。

### 9.2 战中调整与两种CD

战中允许从储物袋补给、替换和调整阵盘；符箓、丹药等由玩家选数量装入，用完释放阵位，可再次补入。新物品不能立即发动。

| 境界 | 新纳入物品的入场等待 |
| --- | ---: |
| 凡人 | 3秒 |
| 炼气 | 2.5秒 |
| 筑基 | 2秒 |
| 结丹 | 1.5秒 |
| 元婴 | 1秒 |
| 化神 | 0秒 |

本表替代旧设计3／2／1.5／1／0.5／0秒表。入场CD与物品轮转CD仍须区分；旧确认“先入场等待、后完整轮转”可作为衔接依据，化神0秒不等于删除物品轮转。

“随时调整”确认战中可补给，但新稿没有明确取消暂停门槛。**当前运行中编辑是否应开放、还是仍先暂停，待确认**，不能据文字直接移除现有暂停限制。战前无入场等待、内部移格保留进度等现原型行为本轮不修改；重入判定、暂停拟定方案提交、补充同种药堆与冷却的衔接见第12节。

### 9.3 装备成长原则

武器、防具、法器采用明确设计的固定内容，不做随机词条；不采用单件法器不断强化升级。成长主要靠获得新装备，旧装备可卖掉、分解或处理，相关经济系统未实现。

高级装备可具更高数值、Buff／Debuff、特殊CD、多属性攻击、特殊Combo和主动效果。阵盘可打造与法器不反复升级属于不同对象，不混为同一强化系统。

## 10. 战后资源与地图恢复

战后气血、灵力、体力、护甲等不自动全部补满，地图设置恢复点，形成连续探索资源压力。

“不补满”不等于已经确定所有资源原值保留：旧稿规定清除护甲／灵障／CD／Buff等临时状态，新稿是否改为跨战保留护甲仍需明确。胜利、失败、撤退分别保留／清除什么、返回地图位置、敌人重置、恢复点是否收费／限次／全恢复，尚待统一。
