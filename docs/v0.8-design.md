# V0.8 等级、交互音频与命中反馈

2026-09-07，实现前记录。本轮不实现修炼升级、等级属性加成或存档。

- 六种修仙等级从data/cultivation/*.json读取，使用稳定ID，包含名称、顺序、头像框及对应椭圆裁剪窗口。角色配置引用cultivation_rank；PartyMemberState保存当前等级ID，UI从注册表解析等级名称与头像框。辰宇凡人、角色2炼气、角色3筑基。野狗不属于修仙人物，不强加境界。
- 等级映射：凡人pt00、炼气pt01、筑基pt02、结丹pt03、元婴pt04、化神pt05。保留人物原头像，按当前边框窗口等比裁剪；等级变化时名称和边框同步更新，不修改基础属性。
- GameManager通过inventory_interaction信号发送place/invalid命令结果；实际鼠标拿起发送pick，原生拖放失败只在释放时反馈invalid，悬停检查不播放。音频节点统一播放三个gameplay-bag文件，支持阵盘和共享储物袋。
- 命中只消费模拟已有damage事件：受击方由target_id与side确定，数字为实际扣除气血value，颜色af3549。普通武器（含测试爪子）命中同步播放sword_slashing.ogg、短暂斜斩光痕及向下淡出的-X。完全减免显示-0；过量伤害使用实际扣血值。同刻多次命中保留独立数字，避免完全重合。
- 音频和命中特效都属于展示层，不读取墙钟推进玩法、不改变模拟速度、伤害或事件顺序。对反击、回复不播放剑击声；音量先设较低默认值，UI声音可重叠但有固定复音上限。
- 完成后运行现有headless/启动/真实渲染检查，并补充境界引用校验、音效触发与实际伤害飘字验证。结果与素材在本地交付，不提交或同步Git。
