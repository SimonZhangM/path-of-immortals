# 土系功法完整方案

## 一、土系总体定位

土系核心仍然是：

稳、重、震、压

稳：坚韧、抗暴击、防守反击。
重：钝击武器、重击、暴击。
震：岩锤、地脉震荡、定身。
压：疲惫、重伤、资源与恢复压制。

土系重点适配的武器：

钝击型：锤、鞭、棍等。

但并不限制土修使用其他武器。

当前克制关系暂按：

土克雷、火；被风、水克制。

## 二、土系三个核心状态

| 类型 | 状态 | 作用 |
| --- | --- | --- |
| Buff | 坚韧 | 每层提高抗暴击概率；成功抗暴后消耗部分层数 |
| Debuff① | 疲惫 | 每层提高被暴击率；真正被正常暴击后消耗部分层数 |
| Debuff② | 重伤 | 提高灵力/体力消耗并压低气血恢复，逐层消退 |

### 坚韧

基础：

每层 +1%抗暴击率。

成功抵抗暴击以后：

消耗 max（1，floor（当前层数÷2）） 层。

### 疲惫

基础：

每层 +1%被暴击率。

正常发生一次暴击以后：

消耗 max（1，floor（当前层数÷2）） 层。

但必须特别强调：

【破岳式】制造的必暴击不属于疲惫判定。

它：

不读取疲惫；
不消耗疲惫；
不触发“因疲惫而暴击”的相关功法效果；
疲惫层数原样保留。

### 重伤

每层：

灵力消耗+1
体力消耗+1
每次气血恢复-1。

恢复最低：

0。

不会因为重伤变成反向扣血。

重伤从0层获得：

等待2秒开始生效。

进入生效状态以后：

每秒减少1层。

此后再增加重伤：

直接加入当前状态池，不重新等待2秒。

## 四、《坤元地脉录》

土系技艺功法｜5重

定位：

勘脉、寻矿、采集、识别珍贵矿材。

具体矿材依然需要：

地图探索、矿点、特殊区域等途径取得。

### 第一重·察脉

**【寻脉】**

提高发现矿点、隐蔽矿脉的能力。

**【辨矿】**

能获得更详细的矿材种类、品质和潜在产出信息。

### 第二重·采蕴

**【丰采】**

提高矿点总体产量。

**【精采】**

偏向提高高品质矿材的获得能力。

### 第三重·识藏

**【寻珍】**

更容易发现稀有矿石和伴生材料。

**【识性】**

更容易辨识具有金木水火土风雷属性特征的矿材。

### 第四重·通脉

**【深采】**

提高深层、高级矿脉珍贵核心材料的产出。

**【广纳】**

提高复杂矿脉中各种伴生材料的总体收获。

### 第五重·开藏

**【天成】**

提高矿材品质上限。

**【丰藏】**

提高高级矿脉稀有材料的产量。

## 五、《厚土真解》

土系总纲｜5重

不提供具体主动法术。

### 第一重·识土

**【坤击】**

全面强化主动土属性攻击。

**【重兵】**

强化锤、鞭、棍等钝击类武器的纯武器伤害。

### 第二重·明势

**【乘克】**

提高土属性攻击面对被克属性时的克制收益。

**【逆克】**

土属性身甲受到克土属性攻击时，降低克制惩罚。

### 第三重·应鸣

**【内鸣】**

自身坚韧在土属性共鸣中的单层贡献提高。

**【外鸣】**

敌方疲惫+重伤在土属性共鸣中的单层贡献提高。

### 第四重·通玄

**【启式】**

土法作为连携起手时，强化其衔接能力。

**【承式】**

土法作为第二段或后续连携节点时，提高连携收益。

### 第五重·归真

**【坤岳同势】**

连续土属性节点进入同一条连携时，后续土系节点强化。

**【重器合流】**

土法与钝击型武器共同参与连携时，强化两者协同。

## 六、《镇岳沉元经》

土系状态专精｜5重

专门研究：

坚韧 / 疲惫 / 重伤

每重：

三选一。

1、3、5重改变机制。

2、4重强化效果。

### 第一重·立岳

**【余韧】**

坚韧成功抵抗暴击后：

消耗层数由约1/2降低为约1/3，且至少消耗1层。

让坚韧更容易长期维持。

**【疲势难消】**

目标正常受到暴击以后：

疲惫消耗量由约1/2降低为约1/3，且至少消耗1层。

注意：

破岳式必暴击仍然完全不涉及疲惫，因此不会触发本效果。

**【催伤】**

重伤从0重新施加时：

缩短首次2秒起效等待时间。

具体缩短多少后续数值化。

## 七、第二重·蓄势

三选一。

**【固岳】**

坚韧：

每层抗暴击率增加0.4个百分点：基础1%→1.4%。

**【困乏】**

疲惫：

每层被暴击率增加0.4个百分点：基础1%→1.4%。

**【沉伤】**

重伤三个效果：

灵力消耗增加
体力消耗增加
恢复削减

整体效果：

+10%。

资源可以保留到小数点后一位。

## 八、第三重·沉伤相引

**【岳势反镇】**

通过坚韧成功抵抗一次暴击：

给攻击者施加少量疲惫。

形成：

打我不成，反而让自己露出破绽。

**【乏极成伤】**

目标存在疲惫时，通过正常暴击判定真正发生一次暴击：

额外施加重伤。

特别规定：

破岳式产生的必暴击不触发这项能力。

这样破岳式和疲惫体系始终保持独立。

**【伤深养韧】**

敌人的重伤状态连续完成一定次数结算：

自己获得少量坚韧。

形成：

敌人越虚弱，自己越稳。

## 九、第四重·镇岳

**【岳体】**

坚韧：

每层抗暴击率再增加0.6个百分点。

只选本次强化时为1.6%/层；第二重、第四重均选坚韧时，1%＋0.4%＋0.6%＝2%/层。两次投入分别保留收益，不用第四重覆盖第二重。

**【疲极】**

疲惫：

每层被暴击率再增加0.6个百分点。

只选本次强化时为1.6%/层；第二重、第四重均选疲惫时为2%/层。

**【伤元】**

重伤效果：

再+20%。

如果第二、第四重都专修重伤：

最终总强化+30%。

## 十、第五重·玄岳归一

**【山岳不倾】**

通过坚韧成功抵抗暴击时：

暴击变为普通攻击以后，再进一步降低本次实际伤害。

这是最纯粹的：

坚韧防御路线。

**【疲势崩裂】**

通过正常暴击机制成功暴击疲惫目标时：

根据本次因暴击而消耗的疲惫层数，追加一段土属性派生伤害。

同样：

破岳式的必暴击不触发。

因此真正玩疲惫流的玩家，仍然需要：

堆疲惫 → 提高正常暴击率 → 兑现。

不会被一个必暴法术直接取代。

**【伤势反噬】**

目标发生气血恢复时：

重伤先正常削减恢复量。

被重伤阻止的那一部分恢复：

按一定比例转化为土属性派生伤害。

例如原本恢复20，被重伤压到12：

被阻止了8点。

高阶功法可以利用这8点中的一部分：

反过来形成伤害。

土系正面攻伐功法｜8重

整体修炼意象：

一锤 → 山岳 → 地脉 → 山河。

强调：

钝击、震荡、正面攻伐。

### 第一重·岩罡化锤

**【岩罡锤】**

凝结岩罡巨锤轰击目标。

标签：

法术来源
+钝击型法术伤害
+土属性。

### 第二重·重岳初成

**【重岳】**

提高岩罡锤的纯粹钝击伤害。

**【震乏】**

岩罡锤命中以后施加疲惫。

## 十二、第三重·岳印临身

习得：

**【坠岳印】**

以山岳重势镇压目标。

属于：

纯土属性法术伤害。

并拥有：

**【震溃】**

如果目标在攻击开始前已经存在疲惫：

根据疲惫层数追加一次土属性派生伤害。

不消耗疲惫。

### 第四重·坠岳化势

**【镇山】**

提高坠岳印本体直接伤害。

**【乘乏】**

强化震溃读取疲惫形成的额外伤害。

## 十三、第五重·地脉震鸣

习得：

**【地脉震】**

引动目标脚下地脉震荡。

造成：

土属性法术伤害

并附带：

定身。

定身：

暂停敌方阵盘CD。

### 第六重·震意分流

**【裂地】**

提高地脉震直接伤害。

**【沉岳】**

强化控制效果，并增加一定重伤施加能力。

这里将原来的“镇脉”强化名改成【沉岳】，避免和下一本功法的【镇脉诀】重名。

## 十四、第七重·山河倾覆

习得：

**【山河崩】**

以山河重势发动大型土系攻击。

标签：

法术来源
+钝击型法术伤害
+土属性。

固有效果：

**【崩体】**

如果目标在攻击前存在重伤：

根据当前重伤层数追加一次土属性派生伤害。

不消耗重伤。

### 第八重·撼岳归真

**【倾岳】**

大幅提高山河崩本体单次伤害。

**【伤崩】**

强化崩体对重伤层数的利用能力。

所以这本书最终可以走：

纯重击爆发

## 十五、《不动玄岳诀》

土系特殊战斗功法｜8重

核心特色：

预备式法术。

CD完成以后：

不一定立即释放，

而是进入：

**【待发】**

等待相应战斗事件。

进入待发不扣资源、不启动下一轮CD；真正满足条件并实际发动时才扣资源。资源不足或麻痹期间不能发动，不视为已使用。本节各预备式都支持手动／自动选择；手动如何进入待发及条件不足后的保留方式，统一见复盘清单，不为每本书另设隐含规则。

### 第一重·不动守心

习得：

**【守岳式】**

CD完成后进入待发。

下一次敌方攻击如果本来会暴击：

自动发动。

效果：

必定将本次暴击压回普通攻击，并进一步减少伤害。

守岳式：

完全独立于坚韧。

因此：

不判定坚韧；
不消耗坚韧；
不触发坚韧的成功抵抗事件；
坚韧原样保留。

### 第二重·岳守生变

**【镇身】**

进一步提高守岳式的即时减伤。

**【蓄岳】**

守岳式发动以后：

获得一定坚韧。

注意：

是攻击处理完成以后再获得，不参与刚才那次暴击判定。

## 十六、第三重·破岳蓄势

习得：

**【破岳式】**

CD完成以后进入待发。

下一次己方主动武器攻击：

自动触发并必定暴击。

如果使用：

锤、鞭、棍等钝击武器，

还可获得该功法本身额外的钝击收益。

**关键规则**

破岳式的必暴击：

完全独立于疲惫体系。

因此：

不读取疲惫层数；
不因为疲惫而提高概率——本来就是必暴；
不消耗疲惫；
不触发【乏极成伤】；
不触发【疲势崩裂】；
疲惫状态保持原样。

但它仍属于：

一次真正的暴击事件

因此可以正常触发其他不依赖疲惫的普通暴击机制。

这样不会让破岳式完全脱离整个暴击系统。

### 第四重·破势分途

**【崩击】**

提高破岳式对钝击武器造成的暴击伤害。

**【震伤】**

破岳式制造的暴击如果真正伤及目标：

施加一定【重伤】。

不使用疲惫作为中间环节。

所以：

一个走极致重击；

一个走必暴→重伤压制。

## 十七、第五重·镇脉待发

习得：

**【镇脉诀】**

CD完成以后进入待发。

等待敌人下一次尝试发动：

需要消耗灵力和/或体力的技能、法术或器具。

触发以后：

提高该次行动的灵力/体力消耗
+施加重伤。

**关键新增规则**

如果增加消耗以后：

敌人剩余灵力或体力不足以支付新的实际成本，

则：

该技能无法发动。

本稿正式采用：

发动机会视为已经被镇脉诀截断，该物品/法术直接重新进入下一轮正常CD。

否则如果技能仍停留在“CD完成”状态，就可能在下一帧不断尝试发动，形成异常循环。

所以镇脉诀真正可以做到：

压住敌方关键高耗技能，让它这一轮直接放不出来。

这是非常有土系特色的控制。

### 第六重·沉元化意

**【沉耗】**

进一步提高镇脉诀造成的本次额外资源消耗。

更容易：

直接让敌方技能因资源不足而发动失败。

**【伤元】**

降低部分即时额外消耗，换取更多重伤层数。

对应：

断你这一招

vs

让你后面越来越难受。

## 十八、第七重·玄岳反震

习得：

**【玄岳反震】**

CD完成后进入待发。

下一次物理攻击经过灵障／雷盾等护盾类规则后，真正进入自身护甲层并造成护甲损失时触发。

本次攻击正常完成以后：

根据护甲实际承受的伤害，向攻击者发动一次土属性法术反击。

如果攻击：

被灵障／雷盾等护盾类资源完全处理、没有进入护甲，

则不触发。

### 第八重·不动归真

**【借力】**

提高反震伤害对本次护甲实际承伤的利用效率。

**【镇敌】**

降低部分反震伤害，但命中以后施加疲惫或重伤类压制效果。

最终形成：

反震输出

vs

防守压制

两种路线。

| 《不动玄岳诀》 | 守岳式 | 待发，必抗一次暴击 |
|  | 破岳式 | 待发，下一次武器必暴击 |
|  | 镇脉诀 | 截断高耗技能、制造重伤 |
|  | 玄岳反震 | 护甲承伤后的反击 |

这8个现在分工非常清晰。

## 二十、土系的主要构筑

### 1. 钝器重击流

岩罡锤
+破岳式
+锤/鞭/棍

追求：

高单次暴击和钝击。

### 2. 疲惫暴击流

疲惫
→正常暴击率提高
→乏极成伤
→疲势崩裂。

这里必须依靠：

正常暴击。

破岳式不能替代这条Build。

### 3. 重伤压制流

重伤
→法术越来越贵
→恢复越来越差
→山河崩进一步兑现。

### 4. 镇脉封术流

镇脉诀
+重伤
+敌方资源压力

专门针对：

高耗大招、法修、重型器具。

### 5. 坚韧不动流

坚韧
+守岳式
+高护甲防具。

其中：

守岳式负责关键必挡；

坚韧负责日常持续抗暴。

二者互不抢状态。

### 6. 玄岳反震流

高护甲
→物理攻击真正打入护甲
→玄岳反震。

特别适合：

克制高频物理武器。

## 二十一、土系最后的设计语言

现在我觉得土系已经可以真正定成：

自己越来越稳，敌人越来越沉。

和其他四系的区别非常明显：

金——兵器与伤痕
木——生机与侵蚀
水——资源与时间
火——燃烧与攻坚
土——重量、暴击、资源压制与反震

尤其这次把【破岳式】彻底从【疲惫】里拆出来以后，我认为是更好的。这样土系实际上拥有两套完全不同的暴击玩法：

疲惫流：通过状态提高正常暴击概率。
破岳流：用预备式法术直接保证某一次关键攻击暴击。

一个是：

构筑概率。

一个是：

控制时机。

这两个同时存在，比让破岳式直接吃疲惫要有意思得多。
