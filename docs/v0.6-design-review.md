# V0.6 防御、触发效果与阵盘映射

2026-09-07，实施前记录；用户已确认以下规则，优先于历史V0.5范围说明。

- 铁甲/玄铁甲/青鳞甲基础防御1/2/3，多件相加，普通伤害max(0,攻击−防御)。战中装入或移动防具在2秒冷却完成后生效。
- 玄铁甲进场给佩戴者额外2防御，总计4；以装备实例为来源保存，卸下/进入调整冷却时移除，重新进场不重复累积。
- 青鳞甲受到普通攻击后反击1，无视防御、无体力成本；0伤害攻击也触发，致死攻击不触发，反击不再触发反击。
- 轮转on_activate、进场on_enter、条件on_attacked使用JSON效果描述。开战先让所有初始装备进场，再排攻击；战中装入以版本化enter事件在冷却截止时进场。防御为角色权威来源表汇总，模拟不读取UI。
- 冷却完成事件优先于同刻攻击/回复，其余事件保持插入顺序；避免在冷却到期时仍被视为未进场。反击在普通攻击之后的有限遍历内结算，再判断胜负。
- 储物袋每行4卡，竖排名字、中心图、数量与占格小图，底部圆角类别/品质标签。效果数值从同一JSON生成悬停详情，在储物袋和阵盘复用，避免硬编码文案与实际结算不同。
- 三个我方角色各绑定一份阵盘外观JSON，记录稳定ID、图片、参考画布尺寸、横纵格线坐标。纯表现映射将原图坐标等比缩放并居中，点击、放置预览、占格图片共用坐标。逻辑仍为4×4，不依赖图片；不实现阵盘更换/成长功能。
- 移除程序绘制的格子底色/边框/圆点及物品常态底板/边框，保留必要的选中、拖动合法性与CD反馈。敌方不增加未指定背景图。

验证：防御叠加/0伤害/卸装，初始与延迟进场、反复移动不累加、冷却时不反击、致死和0伤害反击、防反链、反击致死结算；原战斗与丹药回归。阵盘真实坐标中心/边界/非等尺寸画布、原生右键与拖放、四列卡片和悬停详情、多分辨率截图。新增素材仅接入用户指定的bag-bg-1/2/3.webp，backgroundtest.webp仍不替换。
