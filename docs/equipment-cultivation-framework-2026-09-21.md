## 1. 总体结构与设计原则

**灵根 → 功法 → 法术／武技 → 连携**构成长线修炼与主动招式体系；武器、防具、法器形成具体构筑，阵盘承载这些器具的自动运行。

| 层级 | 主要职责 |
| --- | --- |
| 灵根 | 决定正常可修炼的功法、可学习的法术属性 |
| 功法 | 决定长期修炼体系与具体流派 |
| 法术／武技 | 提供从功法等来源习得的具体招式 |
| 武器、防具、法器 | 决定具体装备构筑、输出与防守机制 |
| 阵盘 | 以独立CD、位置及事件组织器具自动运行 |
| 连携 | 高境界下主动衔接法术与器具 |

装备成长同时沿着**数值提升＋机制深化＋对阵盘规则影响增强**三条方向展开。属性决定战斗风格，不封锁攻击能力：金、木、水、火、土、风、雷都应有武器、防具、攻击型法器和攻击法术。

阵盘不按从左到右轮流行动。每件物品独立计CD，先结束者先发动；只有恰好同刻到期时才按阵位顺序判优先级。机制设计主要围绕CD、战斗事件、状态、位置、其他装备触发和敌方阵盘行为展开。

## 2. 三类装备的职责

| 类别 | 核心职责 | 适合的机制 |
| --- | --- | --- |
| 武器 | 把已有优势兑现为伤害 | 穿刺／斩击／钝击、附加属性法术伤害、状态利用／消耗、暴击、命中、追击、吸血、低生命爆发、生命献祭、连携终结、阵式组件 |
| 防具 | 决定受击后如何响应 | 甲型、属性、护甲与上限、受击监听、反锋／坚韧／轻灵、护盾／雷盾互动、破甲与低生命触发、抗暴、防守反击、资源转换、给法器充能、闪避推进武器CD |
| 法器 | 组织构筑并改变部分规则 | 攻击、防御、状态生成、护盾、CD操作、敌盘干扰、事件监听、邻接增益、领域、状态转换、阵式核心、化神连携、来源标签改写、大型属性攻击及少量顶级局部规则 |

职责是侧重点，不是绝对限制。身甲决定主要防具属性；其他护具主要增加护甲值、上限和特殊效果。

## 3. 八大核心机制库

| 机制 | 设计含义 |
| --- | --- |
| ① CD干预 | 推进己方剩余CD、延长敌方剩余CD；少量顶级效果可干预更大范围时间 |
| ② 邻接与事件监听 | 监听相邻物品、命中、法器发动、闪避、暴击、破盾等事件，获得充能或作出响应 |
| ③ 领域型核心法器 | 占用阵位，持续强化某属性、武器类别或整个流派 |
| ④ Buff／Debuff利用与兑现 | 读取、消耗或转换状态，换取伤害、控制或其他收益 |
| ⑤ 资源献祭与低生命收益 | 消耗生命／护甲／资源换取力量，或低生命时强化 |
| ⑥ 战斗属性构筑 | 吸血、暴击、命中、闪避、二次追击等 |
| ⑦ 阵式／套件联动 | 满足类别、数量、属性或组合条件，形成大型攻击，甚至改变原装备发动方式 |
| ⑧ 连携与攻击来源改写 | 器具参与高阶连携，或明确将某次法术视作武器攻击 |

机制库的具体使用方式：

- **状态读取型**不消耗状态，例如毒蚀越高武器伤害越高；**消耗型**提前吃掉状态换即时收益，例如消耗毒蚀造成伤害、消耗反锋强化下一击。保留状态与提前兑现之间形成取舍。
- **监听事件**包括成功命中、某类法器发动、某属性攻击、暴击、闪避、雷盾受伤／破裂、护甲归零、生命低于阈值等。原文“4次命中获得状态”为示例，不固定充能阈值。
- **邻接**指上、下、左、右阵位，关注指定事件是否发生，不要求邻居按固定次序行动；中心与角落可以有不同构筑价值。
- **领域**用一个宝贵阵位换全局强化，允许自身低输出；示例包括火属性主动攻击、剑类、雷印生成、命中或追击强化。
- **敌盘干扰**可随机、指定阵位、监听敌方法器次数、针对即将就绪的物品。它是直接推进／延迟CD；寒霜暂停阵盘CD，麻痹则让CD继续计时、到点跳过本次发动并重开完整轮转。
- **阵式／套件**可由多把剑＋大庚剑阵核心等组成。核心调用参与器具发动大型属性攻击；高阶可以暂时接管它们的发动方式。剑阵、箭阵、雷阵、火阵、防御阵均为方向示例，数量需控制。

**魔族装备**是一种可附着于不同属性的特殊风格，不是第八属性。三个关键词：血祭＝主动消耗生命或资源换力量；濒危＝生命低于一定比例强化；噬血＝仅按实际伤害敌方生命的部分吸血。护盾／护甲吸收部分不计吸血基数；原文30攻击、10盾、10甲、20%吸血得2生命是说明例，不锁定倍率。

**体修**是无属性武器、防具、肉身和纯物理为核心的功法路线，不是第八属性，原则上不要求对应属性灵根。可强化气血、护甲、暴击、反击、追击、低生命战斗等，发展重兵爆发、高速追击、防御反击流派。

## 5. 符箓、武器型法术与攻击来源

符箓每次发动消耗一张，释放预封存术式；可承载属性攻击、武器型法术、Buff／Debuff、定身、CD干扰、护盾与连携起手。符箓术式不要求使用者具有对应灵根，可临时提供未学会的能力。

火矛符、冰剑符等可以造成**法术＋穿刺／斩击等双标签伤害**，但默认来源仍是法术，不能仅因外形或标签就触发反锋、锋痕、失衡追击等只识别物理／武器攻击的机制。少量特殊能力明确写“视作武器攻击”时，才进行来源规则改写。用户已确认法术相克与穿刺等双标签修正按加成／减成相加，基础只计一次；具体倍率及与其他阶段的结算顺序另定。

## 7. 灵根、功法与法术成长

七灵根为金、木、水、火、土、气、雷；气灵根对应风属性。玩家开局自选1～4种，限制正常修炼的功法和学习的法术属性，**不限制使用对应属性的武器、防具、法器、符箓**。这是灵根资格边界，不表示免除既有境界／品级限制。

功法是长期修炼体系，不要求每次提高境界立即淘汰。七系属性总纲必须上阵才生效；状态专精学会即直接生效，不需要上阵。战斗功法解锁的法术独立上阵，不要求原功法同时上阵；每种法术只有一个，最多上阵一个。技艺功法依各系用途处理，具体占格、多总纲容量与境界门槛另定。

| 成长层 | 含义 |
| --- | --- |
| 长期修炼 | 功法基础效果、状态生成、伤害等随修炼增强 |
| 境界深化 | 达到一定境界，对同一本功法自动理解到新层次 |
| 关键突破分支 | 七系正式稿已细化为总纲／技艺各重二选一、状态专精各重三选一、战斗功法对应强化重二选一，覆盖早期每本仅1～2次关键分支的建议；分支选定不可直接重选，须特定丹药整本重置；分支前置与具体容量另定 |

万剑诀“千锋”（多次剑气／状态积累）和“归一”（单次高伤／连携终结）是分支例子，不是已经配置的功法。法术／武技随功法逐步习得，**学会后原则上不再单独升级**；通过境界、属性机制、状态、装备、功法效果和连携成长，避免增加法术等级与熟练度等平行成长轴。

同属性可有不同功法流派，例如火系的赤阳诀偏附炎爆发、焚天经偏灼烧压制、离火剑经偏剑术与连携；属性决定大方向，功法决定流派。

法术主要来源于功法，也允许少量秘术（宗门／遗迹／传承）、悟法（天地异象／古阵／剧情）、种族／血脉术。法器附带术由法器发动，不算角色学会，不受角色灵根限制。

## 8. 主动法术与高阶连携

所有道具和法术均支持逐项手动／自动选择，并有快捷按钮统一切换。自动模式在CD完成且满足条件时发动；手动模式完成CD后等待玩家发动。法器附带术与角色学会的法术仍区分来源，不因操作模式相同而混为一类。

实际发动才扣资源；预备式待发期间不进行下一轮CD，资源不足或麻痹期间不发动。麻痹中轮转CD到点仍按跳轮规则处理，镇脉增耗截断导致重开CD的特例保留；手动待发授权和模式切换细则见复盘清单。任何功法分支一旦选择不得直接改选，只能吃特定丹药重置整本，丹药内容与修炼进度处理另定。

| 境界 | 连携范围 |
| --- | --- |
| 元婴 | 法术与法术；第一法术实际生效后，在约2秒内衔接指定第二法术 |
| 化神 | 武器、法器等器具正式加入，可有法术→武器、法器→法术、法器→法器及更复杂连续连携 |

第二法术获得基于自身实际伤害的额外**无属性法术连携伤害**；辅助、防御、治疗法术也能起手，不要求第一段造成伤害。“约2秒”保留为暂定窗口，具体倍率及“实际伤害”的精确口径仍待内容和结算设计。

少量指定三段连携可有独立招式名、头像切入、镜头与专属法术特效，不据此扩张为大量同质连携。
