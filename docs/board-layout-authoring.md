```json
{
  "id": "base.board.frost",
  "name": "霜兽阵盘",
  "texture": "res://assets/bag-bg-1.webp",
  "source_size": [1024, 1024],
  "x_lines": [114, 315, 512, 709, 909],
  "y_lines": [114, 315, 512, 709, 911]
}
```

- source_size是整张原图的像素宽高，包含透明边缘。
- 原点在图片左上角，x向右、y向下。x_lines列出左边界、内部格线、右边界；y_lines同理。3列有4条x坐标，4列有5条，至少须两条。
- 坐标必须递增、在画布范围内。可以非等距，例如第一列较宽；目前只能表示横纵对齐的矩形格，不支持斜格或自由形状。
- 图像按控件区域等比缩放并居中，BoardLayout将所有坐标应用同一缩放与偏移。鼠标定位、物品占位、合法放置和预览使用同一映射。
- 每个物品的逻辑size仍来自物品JSON。1×2物品跨两个完整逻辑格，图标在对应矩形内保持纵横比显示；不会拉伸图片强行填满。
- 角色JSON用board_layout引用稳定ID。辰宇/角色2/角色3目前对应frost/roots/leather。

新增或替换阵盘底图时：核对实际原图宽高（含透明边缘），逐图测量格线坐标，维护独立JSON并在角色配置引用；不能只按3×3或4×4套同一份坐标。运行`./tests/run_t01.ps1 -Script res://tests/board_alignment_preview.gd -Render`，核对尺寸、格位映射和格线叠加预览。纯视觉标定不跑鼠标／拖拽链路，只有修改交互时才检查对应交互。当前没有可视化校准编辑器，也不会自动从图片识别格线。

阵盘格线偏差只修对应BoardLayout，不使用物品全局偏移补偿。物品在阵盘、拖拽、卡片与说明中共用MapItemArtwork；兽心已移除旧horizontal_center=0.425及Alpha重心覆盖，统一使用可见包围盒的几何中心。其他物品已配置的视觉校准保留，不因阵盘标定批量清空。手绘石缝可有弯曲；现有矩形格线取其分隔位置，不要求逐像素描出不规则边缘。

本轮三张图的坐标按素材手工校准。装饰外框/透明边距不可放置。选中外框和拖放反馈仍由程序绘制，但常态格子边框、底色及物品底板已移除。
