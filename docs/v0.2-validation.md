## 验证方式的边界

原生拖放用无窗口 Godot 的 `Input.parse_input_event` 注入按下、移动、释放事件，经过实际 `_get_drag_data / _can_drop_data / _drop_data` 链路。只对 Viewport 使用 `push_input` 不会更新全局虚拟鼠标位置，因此不能拿它代替鼠标事件入口。

隐藏的真实渲染窗口读取系统鼠标位置，不适合上述虚拟鼠标驱动；本次未操纵用户鼠标进行桌面手动测试。渲染模式验证相同拖放回调、键盘输入和画面，无窗口测试验证原生拖放路径。
