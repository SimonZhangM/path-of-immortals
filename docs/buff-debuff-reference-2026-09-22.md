### 3.3 数值和时钟说明

全部资源结算统一支持小数点后1位，Buff／Debuff层数必须为整数；第二位小数的舍入方式和环节在实现前统一。四种半数消耗：当前层数N≥1且成功触发时，消耗max(1，floor(N÷2))层，剩余N−消耗量。触发前→剩余为1→0、2→1、3→2、4→2、5→3、10→5；最后1层会消耗完，0层不触发。

**专精增量：**坚韧／疲惫／轻灵／失衡第一次每层＋0.4个百分点、第二次＋0.6个百分点；基础1%，单选为1.4%／1.6%，同选2%。驱散额外拆1层概率首次＋10、第二次＋15个百分点，同选25%，不影响正常基础驱散。

风系事件补充：角色基础闪避率为0%。轻灵与听风步各自独立判定和消耗，但成功后都产生“成功闪避事件”；失衡与追风式各自独立，成功命中的追击都产生“二次追击成功命中事件”。追风式保证追击发动机会，追击本身仍独立判命中；同一原始攻击默认最多一次二次追击，追风优先且不消耗失衡。明确高阶武器可设计3次追击，不默认递归。首击100→系数120→防御后扣血70时，基础追击为120×50%＝60，再过防御。必中／不可闪避与必闪的优先级尚未确定。

润脉／枯脉同一次结算只进行一次50%单向转移，不反向递归；转移后另一项仍装不下或扣不动的余量直接作废。润脉本轮应回5灵力＋5体力而体力已满时，最多回7.5灵力；灵力仅缺6时实际回6，转移后剩余1.5作废。枯脉10层、灵力115／体力2时，体力扣2，余下8折半转扣灵力，灵力共扣14，最终101／0；灵力仅剩12时最终0／0，转扣中无法扣除的2点作废。奇数折半可为x.5，不截整数。

毒蚀设计为穿透雷盾与护甲，直接损失气血；现实现已验证绕过护甲／甲型且不触发反击，雷盾本身尚未接入。灼烧经过防护，不等同毒蚀。5层毒蚀无追加／清除时，在第2／3／4／5／6秒依次扣5／4／3／2／1气血，共15。

生机、润脉、枯脉的设计为先等2秒再逐秒运行，但首次精确跳动时刻、初始等待期加层、抵消转为反向状态时的计时，仍保留原文未决项；不能把仅对毒蚀落实的后续时钟规则自动当成三者都已实现。

## 4. 共通规则

1. **同属性正负状态1∶1抵消，按Debuff生成时间先后。**同刻两种随机决定先后，先抵消完该时间节点的一种再到另一种，该节点处理完才到下一节点，Buff耗尽则停。程序须记录每批生成时间／序号，不能仅保存总数；共同持续时间刷新不改生成先后。
2. **没有统一自然衰减。**生机／毒蚀／润脉／枯脉按各自结算减1；重伤2秒起效后逐秒减1；缠绕／连环每次触发效果后减1。流血叠加共同刷新5秒，灼烧共同刷新10秒到期清除，寒霜无自然衰减，破甲保持10秒后逐秒减层；驱散采用1秒结算及余层5秒窗口。
3. **每种Debuff独立上限，不共享属性总上限。**Buff上限＝境界基础＋阵盘Buff上限＋法器相关上限＋其他特殊效果；每种Debuff上限＝境界基础＋法器Debuff上限，阵盘不增加Debuff容量。超量浪费，具体容量后定。
4. **属性共鸣只强化主动属性伤害，并合计目标同属性两种Debuff。**例如6＋8按14层读取，再与己方同属性Buff按有效层计算，每有效层1%增幅；攻击发出前快照。派生伤害不再次读共鸣；双Debuff增加总读取量，境界读取上限在后续数值设计校准，不直接沿用旧单Debuff上限。
5. **派生伤害默认不触发二次属性机制，具体技能／器具明确例外除外。**雷击默认不触发连环，灼烧默认不触发破甲，连环闪电默认不利用缠绕；连环不自触发，追击不递归。寒霜的“高级法术多层／清空”必须由主动来源明确标注，不从视觉多段或派生伤害自动取得。正常防御承伤仍在，派生伤害破盾麻痹衔接另定。
6. **装备可以读取或消耗状态。**保持21种核心状态，后续创意进入装备、法器、功法、法术、暗器和连携；不继续扩展第三套Debuff。具体来源明确触发、读取／消耗和特殊例外，不把例子变成通用效果。

## 5. 关联机制，不计入七系21种状态

| 名称 | 类别 | 当前设计 |
| --- | --- | --- |
| 雷盾 | 特殊护盾资源 | 每10雷蕴消耗并生成一层独立雷盾；整次吸收min（各层余值之和，伤害×60%），按生成先后逐层扣除，每破一层各触发必中麻痹。每个尚存雷盾按10层计入内鸣，读取不扣盾；单层值／总量主要由境界决定，混合伤害优先吸收法术 |

| 麻痹 | 控制效果 | 持续1秒，物品CD照常运行；期间CD到点跳过发动并重开完整CD轮；就绪／待发也不能发动，未发动不扣成本。普通麻痹必中且重复施加只刷新到至少1秒；明确高阶能力可在剩余时间上追加 |
| 剑幕 | 金系专属护盾 | 基础30值、40%吸收；护主提高至50值；生效后优先扣剑幕，耗尽消失，返剑分支发动一次15点金属性攻击，两分支不默认并得 |
| 定身 | 控制效果 | 使敌方相关战斗CD暂停数秒，具体范围、时长与抗性另定，不当作麻痹同义词 |
| 毒蚀免疫 | 防护效果 | 当前消毒散清除已有毒蚀并提供15战斗秒免疫，已实现；不是独立七系状态，关键词显示只识别其中“毒蚀” |

灵障是由灵气形成的通用防护资源，“护盾”只作机制大类称呼。基础吸收率为30%，实际吸收量＝min（当前灵障值，进入该阶段的伤害×吸收率），剩余伤害继续结算；特定法器可提高吸收率上限及实际吸收率，最高100%。雷盾是基础吸收率60%的特殊护盾。雷盾存在时灵障不承伤，雷盾全部耗尽后从下一次攻击才启用灵障。同击不叠加两者吸收。伤害100、两层雷盾各50时，共吸60：第一层扣50破裂、第二层扣10余40，剩40进入护甲。法器必须明确修改哪一种护盾的吸收率；灵障容量／生成／生命周期、同类型修正合并见战斗总设计。特殊护盾只保留一种类型，雷盾同类可叠层，剑幕与全部雷盾相互替换，旧盾值作废；雷盾被替换仍触发麻痹，剑幕被替换不据此触发返剑；移除的雷盾不再贡献内鸣。灼烧先经过护盾类规则再进入护甲／气血；灼骨等具体功法只强化真正进入生命层的灼烧，不强化灵障、雷盾或护甲承伤。

**水雷衔接：**麻痹尚未结束时新增寒霜冻结，新冻结＋50%；寒霜冻结尚未结束时中新麻痹，新麻痹＋50%。基础0.5秒寒霜变0.75秒、1秒麻痹变1.5秒，不追溯延长原控制。仅存寒霜层数不算正在冻结；控制时间不套资源1位小数限制，重复／刷新合并后定。
