# V0.4 阵型、双方战斗与体力

2026-09-06，用户确认后实施。默认我方后排角色2/3在左、前排辰宇在右；敌方一只野狗，头像和背包在敌方区域分别居中。只有主角背包正常大小，队友固定缩小，点击人物不再改变大小或位置。战斗与暂停均不可移动物品；重新布阵重置资源、时间、日志，并允许编辑我方所有背包。

## 规则

- 三人两种阵型：前1后2（辰宇前、两队友后）、前2后1（两队友前、辰宇后）；二人只有前1后1；单人无前后排。默认三人前1后2。敌方朝向镜像：靠屏幕中心为前排。
- 目标优先前排，同行优先靠上的存活成员；前排全灭后选择后排。阵亡者不再发动装备；单人作为唯一目标。
- 野狗气血100、体力100、灵力0，爪子每3秒伤害5；玄火剑每3秒伤害10。两种武器每次成功攻击扣攻击者5体力，低于5不发动，不自动恢复。不新增铁甲防御或灵力消耗。
- 敌方全灭胜利，我方全灭失败；双方均无可继续发动的装备时平局。单方耗尽仍允许另一方继续攻击。结束冻结在实际事件时刻。
- 同刻事件保持确定性：我方按成员顺序、背包实例顺序入队，然后敌方；逐事件结算，致死后清理/跳过死者事件，不允许同刻尸体反击。攻击目标每次发动时重新解析。

## 实现边界

- 新增 FormationRules 纯数据规则，队伍人数和阵型决定前/后成员序号及目标顺序。显示与模拟共同读取该规则，不能从控件坐标推断前后排。
- BattleSimulation 改为接收双方 PartyMemberState 队伍和各自阵型；GameState 持有权威成员引用、结果、按阵营统计及每个装备实例的轮转状态。移除已不适合双向战斗的单木桩兼容字段/接口，更新相关测试。
- 配置新增野狗、爪子和 stamina_cost；Registry 校验成本和资源上限，允许体力/灵力为0。稳定旧内容 ID 保留，旧木桩 JSON 留作历史内容，不再用于主场景。
- EffectSystem 为双方复用 damage 扣血逻辑。BattleSimulation 负责体力门槛、目标选择、事件排程和结算；UI不扣血、不扣体力。
- 新增 TeamPanel 复用我方/敌方的头像及背包排版；1/2/3人均可布局，空角色不绘制。InventoryView 明确绑定阵营与成员，队友缩略背包在布阵时直接拖放，不再通过选中放大；敌方背包只读。
- 人物画面适度放大并向下留出间距；头像/属性组合的大小固定由主角/队友身份决定。爪子使用简单原创SVG占位图。
