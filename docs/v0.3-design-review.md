# V0.3 三人队伍与背包轮转表现

用户授权：先改我方为三人，辰宇（炼气初期）、角色2、角色3；各自三行气血/体力/灵力，数值居中于条内，条宽为旧版约三分之一；布阵或暂停可选角色，大背包与右侧上下两个缩略背包按角色原顺序排布。移除装备详情、轮转说明、拖放说明和“法器自动战斗”。使用用户提供的背景和武器原图，去掉原代码绘制的背景。保持 1080p 和现有空格/速度控制。

实施约定：

- 三人使用独立 Character 定义、PartyMemberState 和 InventoryState，当前最大气血/体力/灵力均为 100，不新增消耗或恢复规则。角色2、角色3先配同样的剑和甲用于交互验证。
- 选中角色索引属于 GameManager，运行中禁止切换，布阵、暂停、结束时允许查看。根据最新移动问题反馈，暂停也允许摆放，恢复战斗后锁定；GameManager.can_edit_inventory 统一阶段判定，inventory_access_changed 使拖放数据失效，不重置模拟。未选中角色按原索引升序显示，满足 1→[2,3]、2→[1,3]、3→[1,2]。
- InventoryView 绑定明确角色索引。缩略背包仅用于显示及点选角色，不允许直接拖拽。切换大背包后递增拖放代数，防止旧拖放载荷落进另一人的背包。
- BattleSimulation 从三人的背包创建主动装备排程，按稳定实例 ID 保持独立轮转时间。选中状态只影响显示，不能暂停或重置未选角色的装备。三个测试剑均每 3 秒造成 10 伤害，100 HP 木桩预计在第 12 游戏秒击破；敌方三人展示与攻防规则本轮暂不扩展。
- 轮转完成度来自模拟时间和实例下一次到期时间。图片从下向上揭开：线上方灰色蒙版，下方原图，分界为横向虚线。大小背包使用同一表现算法，暂停立即冻结，触发后重新开始，布阵/结束时显示清晰原图。
- 属性条宽固定为 200 设计像素（原约 600 的三分之一），每个角色一张可点击卡片，三条分三行，数值叠加居中；背景用 TextureRect 覆盖，必要文字区域用半透明面板保证可读。

验证重点：三人布局隔离、三种排序、卡片与缩略背包点击、运行中禁切换、暂停切换不改模拟与装备、拖放跨角色隔离、多武器稳定顺序与倍速一致、蒙版进度/方向/暂停/重置、大图和缩略图画面、用户原图路径及删除旧说明内容。

2026-09-06 布局修正：选中组合位于左侧容器，其他两个 66% 组合按角色索引在右侧垂直排列。组合基础尺寸 464×216，头像保留 216×216；名字从头像上方移至旁边的属性栏上方，按蓝框定位。头像区总宽和背包区总宽共用一个计算值。大背包 548×548，小背包约 222×222；垂直空白撑开，使两侧网格顶/底对齐，标题在网格上方单独绘制且不拦截鼠标。顶栏计时使用 0.5 锚点和对称偏移，不受两侧内容宽度影响，速度控制在右侧。生命、体力、灵力色为 AF3549、8CD259、5598EB；最后一项由用户 7 位输入暂按前六位解释。
